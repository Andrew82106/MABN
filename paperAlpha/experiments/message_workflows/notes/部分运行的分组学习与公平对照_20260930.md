# 部分运行的分组学习与公平对照

本轮补充 API MAS 监测器的训练接口：流程中某次调用失败，不应删除其他已完成回复，也不能把未得到的结果填成安全负例。新的部分分组训练保留真实有效的局部事件，共享消息只计一次。事件概率模型仍是原来的 25 系数模型，没有增加隐藏状态或改变安全策略。

这是一项数据利用与训练目标的升级，不是新的检测成绩。原始重复消息采集计划、完整消息对评测和所有历史结果保持不变；本扩展单独冻结、单独输出。

## 已有失败记录能支持什么

此前采购队列共 24 个流程，15 个完成、9 个失败。只读复核原始记录发现，8 个失败在规划者回复之前，另一个得到规划者回复后在第一名买方调用失败；9 个失败流程都没有买方回复或模拟执行。因此它们不能提供新的买方行为标签，也不能验证本轮部分发布结果的训练收益。

失败全部在原验证划分中，不能把唯一已得到的规划回复挪去训练。训练完整率为 12/12，验证为 3/12；fieldcamp 全部缺失。错误集中于相邻调用时段，而领域和调用顺序混杂，不支持“任务更难导致失败”的结论。依据是 `results/exclusive_purchase_api_20260920/` 的逐条日志与原评测，不重跑、不补采、不修改旧成绩。

## 保留哪些标签

新接口显式区分共享结构、已见共享标签和两个预定续跑槽位。某个审核结果缺失，不会因此把审核节点错认成需要重复生成的下游节点。

- 两个独立审核者中只有第一位完成，保留第一位的真实标签。
- 审核完成，某次发布只有一位完成，保留该发布标签；另一位没有二元标签。
- 审核完成，但所有发布都失败，仍可学习审核内容这一部分。
- 全组没有有效回复，只记录覆盖情况，不声称它提供了训练信息。
- 提供方响应身份不合格仍排除整组，不与普通调用失败混为一类。

每个被学习的事件必须有真实可见的父事件。不能从另一次续跑借父节点，也不能补造缺失父值。当前重复协议满足这一条件；一般的“父结果缺失但子结果可见”需要显式边缘化，本接口拒绝这种输入，不假装已经支持。

原始失败类别、请求、回复和未尝试状态留在采集日志中。训练只接收已核验的内容标签，失败、拒绝、截断、未尝试都不进入二元内容标签。有效消息中明确没有追踪编号，才是内容标签 0。

## 为什么目标函数这样写

设同一次审核输出为 H，两个下游续跑分别产生 A1、B1 与 A2、B2。如果 B1 未得到有效结果，观测内容的工作似然为：

`P(H | 前缀) × P(A1 | H,前缀) × P(A2 | H,前缀) × P(B2 | H,前缀)`。

共享 H 只出现一次，没有 `P(B1=0)`。在当前图的条件独立假设下，对未观察到的末端 B1 的所有可能值求和得到 1，所以只计算已观察局部因子，与完整展开图上的边缘化一致。该论证依赖观测集合的祖先完整性，不能无条件推广到任意缺失图。

损失为 `所有有效局部负对数概率之和 / 预定训练组数 + λ × 参数平方和`。四折留一任务开发比较每折原定 36 个上游组，两个监督模式都用 36 作分母，包括无信息或身份排除组在内。这样数据纳入方式改变时，不会同时偷偷改变正则项相对于总数据项的强度。没有标签的组不产生内容梯度；全部没有标签时明确不可训练。

这不是完整 API 日志的似然：没有对调用是否尝试、是否完成、是否拒绝建立概率模型。忽略缺失要求在所建模的已观测条件下，选择机制不再依赖未见内容等假设；协议本身没有证明它。尤其，完整原文上成立的可忽略缺失，在只保留字面出现位和少量线索后未必成立。

因此，更多局部标签不自动修复选择偏差；这些局部规律组合后的概率，也不自动等于全流程完成条件下的联合风险，更不是所有尝试流程的无条件风险。

## 怎样公平比较

同一份采集结果做两个明确的开发分析：

1. `complete_pairs`：仅使用旧资格允许的共享标签和完整发布对。
2. `all_observed`：增加身份合格的真实部分共享、单侧发布及只有审核结果的组。

每个模式均比较精确事件 BN、保留同一边际但去掉联合依赖、去掉上游特征后重训、独立实现的同信息 GLM。所有可学习方法使用同一批标签和固定分母；同信息 GLM 与基础 BN 等价是应通过的检查，不是希望打败的弱基线。

两种正则 0.001 和 0.03 全部报告，不根据结果挑选。任务所有布局、重复和续跑留在同一折。评分始终只用原统计资格允许的完整发布对，审核前和审核后分别预测，不用某位发布失败时的未知另一位构造联合真值。两种监督模式的逐组比较绑定相同输入和相同实际回复。

如果某折旧模式完全没有训练标签而新模式有，旧模式不训练也不评分。因此还要报告两模式是否具有完全相同的评分集合，并只在共同组上汇总配对差异。共同集合为空时，不输出“效果提升”；各自的全量平均不能直接比较。

这里的 `complete_pairs` 是使用固定 36 分母的新匹配对照。若原冻结评测只用存活组数作分母，本轮不宣称复现其数值，也不覆盖它。只有两种新监督模式之间的配对差值可以用于这次数据利用比较。

覆盖报告分别记录原资格、新的有信息组数、空组数、身份排除组数、共享标签数和完整／不完整对中的发布标签数。不完整对不提供联合评分；本轮也不将缺失率变成一个未经验证的新安全预测目标。
