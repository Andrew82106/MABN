# 跨属性实验诊断与系统依赖风险范围

这次工作分开回答两个问题：旧模型为何在新目录上预测失准，以及各 Agent 的动作概率相同但相关关系未知时，系统风险还剩多少不确定性。前者尚未修复；后者已有可运行的全图分析组件。没有重新训练、改变默认参数或新增 API 请求，也没有改写旧成绩。

后续核验补充：当前证书检查已修复非有限数和维度检查，失败采购流程也补了部分执行重放；[新验收记录](../../message_workflows/runs/repeated_message_history_audit_20260930/REPORT.json)确认旧 48 份证书、24 流程及分数不变。本文的 121 份源码一致性仅描述原冻结时刻，修复后的两个核验脚本与旧快照不同。实际 240 查询中有 144 个恒零、每份的系统与预算查询重合，且没有未知授权块；480 个端点不能解释为独立机制覆盖。

它属于项目主线的系统风险图层：文献与策略知识给出违规条件，局部 BN 给出动作概率，新组件检查这些局部概率在不同联合关系下能够支持怎样的系统风险判断。它不是新的因果发现算法，也不是已完成全部双层网络。

## 新流程暴露的实际差距

9 月 20 日完成的前瞻实验包含 24 个新流程、72 次 API 请求，全部完成；每条流程先保存预测，再调用两个买方 Agent。9 月 30 日重新核验原始记录与冻结预测，没有重新采集。模型仍只用此前 12 个完整流程训练。

| 冻结方法 | 风险判断正确 | 动作预测正确 | 风险 Brier 越小越好 |
|---|---:|---:|---:|
| 属性 BN 正则 0.001 | 20/24 | 33/48 | 0.11589 |
| 属性 BN 正则 0.03 | 24/24 | 29/48 | 0.06579 |
| 预先规定的优先级规则 | 24/24 | 47/48 | 0 |

同属性、同监督的独立分类器与对应 BN 数值相同，不能把差异归功于 BN。规则也不是原生 MAS 监测方法的完整复现；这仍是小型自编采购流程，不是通用部署或全面领先证据。

旧数据总把高价与长保修绑在一起。换成只变价格或反转价格与保修关系后，正则 0.001 的模型分别错 7/12、4/12 个动作；保持旧相关关系时则为 12/12。旧训练中候选属性差的矩阵秩为 3，新目录提高到 6。这支持“原训练覆盖不足”的诊断，但不证明某项属性对 Agent 有因果作用：新目录还同时改变了描述和商品编号。

只变保修的场景里，A 买任一件都是 50，B 买任一件都是 70，总预算是 110。因此，在双方都购买的前提下，选哪件都超预算。两个模型各有 4 次动作猜错属于这种策略等价替换，最终风险评分无法检验这些动作细节。必须继续保留独立的中间动作评测，不能改成只考风险后宣称模型改善。

规则也有一个值得保留的错例：博物馆高质量任务中，A 在保修相同的两件商品里选了 65 的商品，文本理由是用更高价格呼应质量优先；规则预测选 35。B 实际选 45，真实总额为 110，仍不超预算，故规则的系统判断保持正确。这个记录说明规则并非总能预测 Agent 的实际行为，不能把合理选择直接当成行为真值。

## 新增的全图依赖分析

原模型给出一个点预测，但同时假设不同动作槽位条件独立。新组件保留每个槽位的完整选择概率，允许槽位之间采用其他相关关系。所有未知授权事实的联合分布作为一个整体保留，不能拆成每个 Agent 各自独立的授权根；动作与未知授权之间的关系也允许变化。

对同一组可执行联合状态，记每个状态的概率为 q，配置策略对该状态的违规判断为 R。计算：

`下界 = min Σ q(w)R(w)`，`上界 = max Σ q(w)R(w)`。

约束是 q 非负、总和为 1，而且每个动作槽位及共享授权块的边缘分布保持不变。互斥候选不允许在一个状态中同时执行。系统风险直接查整张策略表，不把各风险通道的概率相加。

例如两个动作各有 50% 的发生概率，危险要求两者同时发生。独立假设给出 25%；若二者总是错开发生，风险为 0；若总是一起发生，风险为 50%。单独看各 Agent 的概率无法区分这三者。

这是已有的边缘分布约束思想和线性规划在当前风险图上的工程实现，不宣称数学新颖性。理论背景见 [Marginal and dependence uncertainty](https://arxiv.org/abs/1709.00641)，求解接口见 [SciPy 线性规划文档](https://docs.scipy.org/doc/scipy/reference/optimize.linprog-highs.html)。实现同时保存达到上下界的联合分布与对偶解，用独立标量运算检验约束和最优性残差，而非只相信求解器的成功标记。

## 在既有流程上的诊断结果

两个冻结模型、24 个流程，共输出 48 份范围分析，覆盖 240 个策略查询和 480 个上下界。原始点预测全部保持不变；独立证书的最大误差为 4.45e-16 以下。

| 模型正则 | 平均范围宽度 | 最大范围宽度 | 跨过 0.5 的流程 |
|---|---:|---:|---:|
| 0.001 | 0.11617 | 0.41415 | 2/24 |
| 0.03 | 0.26384 | 0.45215 | 8/24 |

例如只变价格的节约型 workshop 流程，正则 0.03 的原预测约为 0.20479；固定局部概率、仅改变相关关系，风险可在 0 到 0.45215 之间变化。这是对模型假设敏感性的分析，不是实际观察到了这些相关关系。

**这些范围不是统计置信区间，也不保证覆盖真实风险。** 局部动作概率错了、漏了候选动作或策略、观测提取错误，范围仍可能错。不能拿二元结果是否落在范围内作为“覆盖率”；概率范围不是单次结果范围。这批数据已经暴露，此次新增分析是事后诊断，不算新的前瞻验证。
