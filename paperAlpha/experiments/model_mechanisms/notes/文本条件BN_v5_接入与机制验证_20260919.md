# 文本条件BN v5：接入与机制验证

## 结论：计算链路接通，效果尚未验证

新增可选研究模型`TextConditionedCapabilityBN-v5`，把类型化文本观测接入可学习的局部状态转移，再沿实际通信传播，最后进入系统风险输出。已使用原真实API任务的47条观测和28次文本提取进行完整回放；没有新API调用、独立安全标签或性能对照。

这是“文本观测→概率网络”的建模原型，不是最后的知识驱动分层风险图。**默认文本权重仍为0，屏蔽文本类别对默认分数没有影响；固定非默认参数下有影响、相应参数有梯度，证明的是链路可训练，不是已经学会检测。** 新版不继承旧71参数模型的评测分数，也不替换150参数v4。

## 1. 为什么采用条件转移，而不是硬标签

上一轮提取保留了118项有原文支持的候选，但仍存在暂缓/禁止混淆和数值分类错误。不能将这些结果当作真实恶意、信息采纳或可信授权；也不能把同条消息中的多个重叠主张作为独立证据相乘。

本版采用一个明确的建模选择：每条消息或工具返回形成**一个整体的观测向量**，条件化一次节点状态更新。它没有独立的语义真值层或提取误差混淆矩阵，因此称为条件状态模型，不称为已经完成了观测似然校准。

状态`C_i`在v5中的含义改为“节点过程风险假设”，不再解释为已恢复的信息采纳/感染状态。改变含义必须显式换版本，不能沿用v4的解释证明。其边际概率仍是由终态监督可学习的潜在量，未证明可识别性、语义正确性或因果关系。

这一选择使粗粒度观测可以进入训练，但不会替代后续角色专属风险模板、明确来源/授权关系或机制级语义监督。

## 2. 文本怎么进入网络

`JournalTextCompiler`按原始运行日志前缀重建可见文本窗口，重新逐项核验提取结果，绑定实际记录ID、Actor和原文哈希。调用者不能提交一个自称已验证的概率、批准或风险标签代替原始提取。

每个文本记录有86个二值特征：

- 19种主张×4种表达方式，共76项，只记是否出现，不按条目数量投票。
- 条件引用、数值引用、候选关联、无法完成比较、部分条目拒绝、提取未穷尽、无支持主张、提取未定、提取不可用、可见历史截取，共10项。

同一句话两个额度可以都保留在证据中，但不会把“出现上限”重复累计两票。提取失败和空结果分开：没有抽出主张不等于安全，失败也不生成伪造的危险标签。关联提议不变成已证实来源边或因果边。

**当前仍不使用具体金额、单位、对象绑定或条件是否满足。** 原文证据被保存，不表示其所有含义都参与评分。新增反例测试证实：其余条件相同时，将400改为40000而保持同样主张类型，v5特征与分数不变。这是明确暴露的能力缺口，不是未来版本要维持的正确性质。

## 3. 局部状态更新的实际方程

对当前文本所属节点i，记整个观测向量为x，文本通道k为“通信”或“工具返回”：

```
q_c = sigmoid(b_k + a_k * c + w_k · x),   c∈{0,1}
P(C_i_new=1 | C_i_old=c, x) = q_c
```

每个通道有偏置、前一状态系数、86项观测系数，共88参数；两个通道新增176项，总参数326。

给定其他节点、来源及历史状态R，精确更新为：

```
P_new(C_i=1,R) = q_0 * P_old(C_i=0,R) + q_1 * P_old(C_i=1,R)
P_new(C_i=0,R) = (1-q_0) * P_old(C_i=0,R) + (1-q_1) * P_old(C_i=1,R)
```

它是归一化的条件状态转移，允许概率上升或下降；不是把一个分类结果设成隐藏状态，也不是对独立证据逐项做贝叶斯似然相乘。`R`保留在完整联合分布中，没有把Agent边际概率相乘来近似联合状态。

该Markov条件假设是我们的工程建模选择；没有文献或实验在本轮证明它完整描述现实危险形成过程。同一来源的改写、跨记录反复转述仍可能影响状态，**二值组特征不等于已经解决重复来源相关性**。

## 4. 与通信、动作和系统层如何连接

一次文本事件的计算顺序固定为：

1. 用该条文本整体观测更新实际发言者/工具使用者的过程状态。
2. 如果是内部通信，再通过已有可学习消息转移影响接收节点；外部接收者不升格为MAS节点。
3. 动作派发时保存当时的过程状态与授权风险的联合历史。
4. 用原15项可见统计、8项联合状态汇总进行全图风险读出。

授权变量A仍按具体动作、能力、角色及可信检查状态计算。文本中的“已批准”只作为有噪的文本协变量，不成为`authorization_checked`事件，不修改动作权限状态，也不替代真实检查器。

动作历史仍采用三态精确压缩，保持`P(C,Z,H)`而非`P(C,Z)P(H)`。局部转移只改C，保留其他变量与历史的边际分布，因此之后的文本不能改写已经记录的派发历史汇总。现有授权因子独立性和读出条件未改变；如果增加累计额度、跨动作相关性或历史检查修订，仍需重新推导。

为了兼容扩展参数，基础压缩器仅将读出系数切片明确限定为原23项，数值和梯度机制未改变。关闭v5文本转移时，同输入、同前150项参数与v4在本轮9组参数×47前缀上分数差为0，旧版完整测试也继续通过。

模型内部保留了一些旧信息状态字段名以复用计算，但v5输出明确改称`process_concern_hypothesis`及`process_concern_at_dispatch_hypothesis`，并注明继承的information/overlap汇总名在本版本的含义。不得用它声称真实污染或因果传播。

## 5. 训练范围

继承等任务权重、任务内各前缀分摊的终态二元交叉熵；解析梯度穿过局部条件转移、消息、动作历史压缩与全图读出。采用原L-BFGS-B优化接口。

“联合训练”只指这个BN内的参数，不包含API提取模型、提示词、离散图结构或自动DAG。手工组件夹具只做优化目标能下降的数值检查，未用真实任务伪造终态标签做拟合。
