# 同监督结构对照：联合依赖收益与训练覆盖

本轮属于项目“知识组合图 → API运行数据学习与验证”中的方法归因。继续原有MAS风险监测目标，不用小样本高分替代完整目标，也不把数值正确等同于检测有效。

## 1. 为什么补这组对照

上一轮BN使用审核等中间事件标签，直接四分类/整图树只使用最终两位结果；它们的分差不能全部归因于BN结构。本轮为普通局部分类器提供与事件BN完全相同的20个最早训练截面、58个实际未来事件标签、25列有效局部特征和工作流图。

新比较器也按DAG分解联合分布，因此数学上仍是BN。它们是拆解贡献的强控制实验，不冒充QuadSentinel等原生MAS方法，也不声称“非BN算法击败BN”。

数据仍是两批已暴露的人工设计API开发材料：40流程，20训练/20验证，64预测截面。验证只有2个危险流程；审核验证12个流程全部最终无违规。无新API请求、不读旧保留测试、不修改原划分和历史结果。

## 2. 具体方法与公平性

新模块 `structured_event_baseline.py` 不调用原BN的设计矩阵、训练目标或推断引擎，独立构造同样的局部有效特征：工作环节对应的偏置、可见支持、可见反对、上游出现均值、多上游全部出现。

- 局部GLM：两个既定正则.001/.03。目标与事件BN一致，按每流程的完整未来事件联合似然计算，优化同一25参数形式。
- 局部HistGB：同一事件监督和特征，沿用小树配置。它有自己的树结构与正则；相同信息/标签不等于相同归纳偏好或数值训练预算。
- 无上游特征：分别重新拟合GLM和树，将上游均值/全部出现两类特征置零，其余特征与标签不变。这是消融，不是强基线被暗中削弱。

每个含上游的已拟合模型再比较三种推断：

1. 精确联合：枚举未来事件状态；共同的中间事件只保留一次。
2. 均值近似：将上游的预测概率代入局部函数，多父节点“全部出现”用独立乘积近似，末端作独立组合。明确承认这不是精确推断。
3. 同边际去依赖：先精确推断，保持两个末端各自概率不变，只移除末端之间的依赖。它与均值近似不是同一消融。

训练时使用真实中间标签作为后续事件的父状态，是完整轨迹似然的正常计算；预测时不传入任何后来标签。所有方法复用同一当前权限真值表，不通过删权限弱化对照。缺失历史、部分未来监督、超过18个自由事件会明确拒绝；不是任意规模或缺失数据训练已完成。

共6个新拟合、12种评分方法、768组预测。全部配置预先冻结并报告，不按验证分数挑新默认。原来的14方法成绩原样保留。

### 结论一：简单事件BN与局部GLM在这里等价

两个正则下独立拟合的25个系数和训练目标均与上一轮事件BN完全相同；128个输入/配置比较中，联合概率最大差5.56e-16，8位运营风险分数差0。因此不能把同一种条件分类器的两种实现名字当作算法创新。

### 结论二：补上中间监督以后，树模型明显变强

原整图终点监督树Brier约.037996；新局部事件监督树约.010916。但它们同时改变了参数共享、局部表示和图式组合，不能说全部提升都由中间标签造成。真正可以确认的是：先前只看整图终点监督树，不足以支持我们的结构优越性。

### 结论三：当前数据没有支持关系建模优势

保持同边际时，依赖影响很小；GLM均值近似甚至比精确联合更低误差。去上游特征后，GLM与树的总验证误差都下降。

但这不证明“关系没用”：改善主要来自没有正例的审核验证组。该组GLM误差由.015510降至.008650，树由.018193降至.004925；分支验证反而略有变差，GLM约.000246→.000252，树约.00000118→.00002050。去上游后的训练误差也更高。不能因这个偏斜小验证集而删除项目系统关系主线或更换默认模型。

上一轮强规则仍为0误差，本轮没有超过它。

## 4. 训练覆盖告诉我们什么

58个未来标签中：审核18个（6正）、发布40个（10正）；准备、执行和派发均没有未来标签。它们在图里出现过、或者其历史状态被观察过，不等于学到了这些环节的预测能力。

25列设计矩阵的秩只有8，审核/发布各4。正则可令优化解唯一，但不代表数据独立约束了25个参数；不能据此声称五类工作环节都已经跨任务学习充分。去上游后秩6。

这要求下一轮新增工作流和数据覆盖真实未来工作环节，并让相同局部线索下出现不同的联合依赖后果。不能继续仅增加系数或对这20条验证反复优化。更不能为了让复杂模型赢而按模型预设分布生成所谓真实Agent结果。

## 6. 对下一版模型的约束

1. 固定保留同信息、同中间监督的局部分类器对照，区别局部概率函数、知识策略、共享关系三者贡献。
2. 对每个概率模板报告未来监督覆盖；没有数据支持的环节不能描述为已学会。
3. 下一批应检验中间事件的不确定性与跨Agent依赖，而不只是“当前已知动作是否越过确定阈值”。保持正常对照和不同依赖强度，不能人为要求正结果。
4. 在新数据之前不继续按这20个验证样本选结构；保留现有模型、结果与MAS原生对照，不宣布总体领先或完成目标。
