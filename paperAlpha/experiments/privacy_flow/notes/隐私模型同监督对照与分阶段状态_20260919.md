# 隐私模型：同监督对照与分阶段状态

## 本轮结论

完成两项实际工作，不只追加设计建议：

1. 对相同逐值风险结构使用不同监督，并补充逐值 HistGB；验证独立隐私流 BN 的逻辑回归等价形式。
2. 新增 `PrivacyStageBN-v1`：执行者与最终答复阶段各有自己的披露状态，再用一个可正可负的统计关联连接。与没有这条关联的同结构模型作对照。

**所有新训练和评价只使用原训练 2,133 条、验证 1,026 条；没有读取原测试文件或原测试结果。**本轮是基于开发诊断提出候选并选参，不是新的独立测试成绩。旧数据、模型、分数、API 运行均保留，没有提交或推送。

新的阶段关联模型在后截止点验证 Brier 为 .17680，与树模型 .17675 接近；较早截止点仍落后。它是值得继续验证的隐私片段，尚未替代整体 MAS 框架。

## 1. 为什么先补监督对照

上一轮 BN 使用逐值的执行者 W 和最终答复 F 标签，而任务分类器只学习最终是否有泄漏。不能把不同监督下的全部差异归因于贝叶斯图。

### 真正保持预测结构不变的对照

`DirectObjectRisk` 对每个受限值计算 sigmoid 概率，使用固定 OR 组合为任务风险。保持输入、参数数量、初值、优化器和组合公式不变，只换损失：

- `endpoint`：只接收一个任务结局标签，不接收逐值标签。
- `objects`：接收每个受限值的最终标签。

早截止点使用类型、该值在协调者消息中是否出现、第一时刻上下文；晚截止点再加入执行者是否出现。晚截止点还保留个体 C 信息，比旧链模型的最终局部因子输入更丰富；所有信息原本都在相同可见监测包中。

每组四个正则强度、两个初值。先按训练目标选初值，再按验证端点 Brier 选正则，所有 32 次拟合保存。另跑两个截止点各三个逐值 HistGB 候选，共 6 个；它们使用相同字段输入与最终字段标签，同样 OR 组合。

这里的监督比较不等于完全相同的有效正则强度：字段损失按每条轨迹求和，任务损失每条只有一个项；固定数值正则时二者的相对比例也改变。为此保留全部同正则对照，不只挑最优结果。

### 监督对照结果（均为验证集）

| 方法 | 协调者消息后 Brier | 执行者回复后 Brier |
|---|---:|---:|
| 同一逐值 GLM＋OR，仅任务标签 | .212341 | .181553 |
| 同一逐值 GLM＋OR，逐值标签 | .219221 | .185395 |
| 逐值 HistGB＋OR | .220133 | .189787 |
| 旧独立链 BN | .221586 | .186045 |
| 旧共享状态 BN | .220097 | .186046 |
| 旧任务 HistGB | .209569 | .176753 |

细标签没有自动带来更好的端点概率预测。较早截止点四个相同正则对照中，逐值监督的端点 Brier 都更差；较晚截止点则随正则改变，有胜有负。

不能因此断言细标签无用：局部标签有利于核验节点含义，而只监督端点不能保证内部每项概率具有忠实语义。两种监督的字段 NLL、Brier、排序及阈值指标也并非一致胜负。例如早截止点逐值监督的平均字段 NLL 较低，但 Brier 较高。全部指标已保留。

这也否定了“只要给简单分类器细标签就能解释上一轮全部收益”的过早判断。目前真正支持的是：需要分别比较输入表示、监督目标、字段组合和时间连接，不能把它们捆成一个归因。

## 2. 独立 BN 与普通逻辑回归的关系

旧独立模型的条件联合分布为：

```
P(W,F | C,x) = ∏_j P(W_j | C_j,x) P(F_j | W_j,x)
```

两个条件分布都是逻辑回归，且使用互不重叠的参数。因此其带正则训练目标严格分解为两个独立 GLM 目标之和。预测时进行相同的 W 边际化与 OR 组合，结果也相同。

新增 `SeparatedTransitionGLMs` 不调用 BN 推断引擎。相同参数下，两截止点全部验证预测差为 **0**，目标差约 5.55e-16，梯度差 0。两个 GLM 分开重拟合后，预测最大差约 4.3e-5 / 5.0e-5，是优化精度差异，不是算法性能优势。

所以不能把“使用 BN 引擎”本身当创新。这个控制仍表达同一概率结构，不应包装成一个数学上完全不同的新 baseline。真正的方法问题仍是知识、观察范围、局部状态和跨 Agent 依赖应该如何建模。

## 3. 新结构：局部状态分开，关联另学

上一轮一个 G 同时表示执行者和最终答复的共同披露倾向，且两个影响都被限制为非负。拟合把 G 对最终答复的影响压成 0。

这存在两种解释：没有共同关系；或同一个状态同时代表两个不同工作阶段过于受限。新原型检验后者，不预设它一定有效。

令：

- U：执行者阶段的高披露倾向。
- V：最终答复阶段的高披露倾向。
- C_j、W_j、F_j：与旧模型相同的三个阶段逐值出现变量。
- x：仍然只用第一截止点可得的上下文。

```
P(U=1 | x) = sigmoid(a · [1,x])
P(V=1 | U,x) = sigmoid(b · [1,x] + γ U)
P(W_j=1 | C_j,x,U) = sigmoid(原局部线性项 + δ_W U)
P(F_j=1 | W_j,x,V) = sigmoid(原局部线性项 + δ_F V)
```

δ_W、δ_F 非负且可以恰为 0，固定两个局部状态的相对含义；γ 可正、可负、可为 0。因此“执行者倾向”和“最终答复倾向”不再被强制为同一件事。

两个对照只差一个参数：

- `independent_stage_bn`：γ 固定为 0，54 参数。保留各阶段内部的逐值共同倾向。
- `coupled_stage_bn`：γ 可学习，55 参数。其余输入、监督、参数化及优化都相同。

γ=0 不表示整个系统没有 Agent 间信息传递：两者仍有 W_j→F_j 的逐值连接。它只消去**额外的阶段潜在状态关联**，不能把它称为完全无 MAS 结构的模型。

模型精确枚举四种 (U,V) 组合。第一截止点还消去未知 W；第二截止点以实际 W 更新四种组合的权重。每个组合内先做 OR，再混合，不把相关的字段风险简单当独立相乘。

知识和来源约束仍沿用 `RB013 / AgentLeak` 隐私片段：接收者、策略、实际可见消息、执行者直接读取 vault 的事实及记忆副本去重。**U、V 及 γ 是新的统计建模假设，不是文献已确认的因果边或实际内部状态。**当前仍只有固定的两个待预测阶段，没有自动实例化任意职责 DAG。

## 4. 训练、结果和不能过度解释的地方

新实验先冻结源码与协议。两种阶段模型均用三个正则强度、两个初值，共 12 次拟合，全部收敛并保存。训练仍为相同的 W/F 逐值联合似然。各正则先按训练目标选初值，再按两个截止点平均验证 Brier 选正则。

两种阶段模型都选中 λ=.0001、seed=0。对照如下：

| 同一验证集 | 较早 Brier | 较晚 Brier | 较晚 NLL |
|---|---:|---:|---:|
| 两阶段局部状态，无额外关联 | .217119 | .182106 | .541535 |
| 两阶段局部状态，可学习关联 | .215933 | .176804 | .513113 |
| 旧任务 HistGB | .209569 | .176753 | 见原验证结果 |

这组新模型之间输入、监督和最佳正则相同，能更直接检验额外关联的作用。晚截止点四个验证任务中，关联版三个改善、一个变差：金融从 .19937 变成 .20360；企业任务从 .20579 改为 .18842。早截止点也为三个改善、一个变差。

选中模型 γ≈−1.4835，δ_W≈2.5528、δ_F≈2.9061。负 γ 只表示**在该拟合模型中、给定上下文和变量定义后的潜在状态关联**。不能解释成“让执行者多泄漏能减少最终泄漏”，也不能证明最终 Agent 实施了纠错或安全审查。

以下限制必须一起报告：

- 新模型尚未超过所有比较方法；早截止点明显落后于任务 HistGB，晚截止点 Brier 几乎相同但仍略差。
- 新模型的最优正则位于本轮搜索边界；没有证明找到了全局最优。混合潜状态仍有可识别性和局部最优问题。
- 对旧共享模型 .18605→新模型 .17680 的变化，不能全部归于结构，因为旧模型没有搜索 .0001。真正同强度结构对照见上表。λ=.001 时，新无关联/有关联模型晚 Brier 分别为 .182587/.182338，收益较小；λ=.01 时最终局部状态关闭，关联基本无作用。
- 关联版早截止点平均字段 Brier 为 .034559，比无关联版 .034366 略差。端点改善不意味着每项解释概率都改善。
- 这些验证数据已经被用于诊断和选参，只有四个验证任务模板；不能报告独立泛化、显著性或原版 MAS 方法领先。

## 6. 对完整模型升级的影响

保留“每个工作环节有自己的风险状态、关系另行学习”的候选方向，不能继续把一个统一的风险位当作所有 Agent 的共同状态。也不能因为 BN 表达了关系，就不再比较等价的传统模型。

下一阶段仍要面对更大的原目标：补字段语义/请求用途等有证据的知识条件，检验跨任务与不同工作流，形成隐私、授权、额度片段的统一组合接口，并完成真正可用的 MAS 原方法比较。不同风险目标不能随意相加；当前新隐私模型未与其他片段统一训练。

原测试已在上一轮查看，本轮不再用它指导迭代。新候选需要新的未参与设计的任务验证；不能把这里的验证数值改名为测试成绩。现有成果是模型设计与开发证据的推进，不是整体论文模型已经完成。
