**没有证明分支结构带来收益。**验证集上，Logistic 概率误差略低，简单可见授权规则仍零误差；三个已训练 BN 版本几乎相同。选中模型的最终状态系数恰好为0，新分支状态没有影响最终出现预测。

本轮补的是项目“知识约束的局部图 → 分支组合 → API运行监测”的一个可学习片段。任意职责 DAG、异构风险模板组合、多风险统一目标、跨工作流泛化和原版 MAS baseline 仍未完成，不把总目标缩成隐私授权分类。

## 1. 结构与变量

继续使用固定四角色流程：规划者 → {执行者a，执行者b} → 发布者。输入必须是两份实际执行者回复、绑定后的发布者请求及当前授权前缀，不读取最终答复。

- C_j：第j项在规划文本是否出现。
- W_ji：第j项在第i个执行者实际回复是否出现，保留完整“值×执行者”矩阵。
- M_ji：宿主声明第j项是否分配给第i个执行者。**不是权限或已认证能力**。
- U_i：每个执行者独有的二值披露倾向；系数共享，状态不共享。
- O_j：任意执行者出现该项，即 W_ji 的确定性 OR。
- V：发布阶段的二值披露倾向。
- E支持/E反对：发布者实际输入中的可见授权线索；缺依据是参考类别。
- z：监测器当前授权证明图中的共同不确定事实。
- A_j(z)：该项发布不满足已配置引用政策。
- F_j：未来最终答复是否出现该项。
- H_j：F_j AND A_j，系统查询为至少k个H_j成立。

外部可见线索不是模型内部信念。角色状态是统计建模选择，不是识别出的因果机制。

## 2. 参数化

```
P(U_1,...,U_m | x) = ∏i P(U_i | x)
logit P(V=1 | U,x) = bV(x) + γ × mean_i(U_i)
logit P(W_ji=1 | C_j,x,U_i,M_ji)
    = worker_design(C_j,x,kind_j)·θW + δU×U_i + α×(1-M_ji)
logit P(F_j=1 | O_j,x,V,E_j)
    = final_design(O_j,x,kind_j)·θF + δV×V
      + β支持×E支持_j + β反对×E反对_j
H_j = F_j AND A_j(z)
```

默认参数：39个已有阶段/出现参数＋3个未知授权事实参数＋2个可见线索系数＋1个非归属执行者出现偏移＝45。去掉U→V关联后为44；合并分支旧模型也为44，但二者结构不同。

γ、α和两个可见线索系数可以为正或负；两个状态“较高披露”增量非负。α不硬性禁止非归属执行者出现某项。知识结构不自动保证事实成立或安全。

给定上下文x，U_i初始独立，这是明确的简化假设，不是发现了执行者真实独立性。规划者的未观测共同错误、分支间消息、动态授权变更未被这个固定片段完整表示。

两执行者与发布者共8种状态组合，先用完整W矩阵更新状态分布；在每种状态和每种共享授权情形下计算违规数量分布，最后加权汇总。不能先取单项边际再独立相乘。

当前只接收固定两执行者、全部完成后的前缀。接口未扩展成任意m的自动工作流，不能因为数学记号用m就宣称已支持任意规模。

## 3. 可解释图不是展示用附图

每个U_i、每个W_ji、宿主归属、O_j、可见线索、授权事实、F_j、H_j及系统计数目标均可导出为有条件概率表的可执行图。

独立的标量枚举器验证：

- 生产预测等于图上求和；
- 训练联合似然也等于图上全部已观察W、F、授权标签的联合概率，不只校验预测；
- 同一授权依据只建一个事实节点；
- F的父节点没有当前授权A，当前事实不偷渡进行为预测；
- 两个执行者交换名称、实际消息及归属后，系统概率不变；
- 相同合并出现记录但不同分支分布，在非零状态关联参数下可导致不同预测。

最后一项只是结构表达能力的机制检查，不是实际 API 数据证明了这种效应。导出图中的上下文固定为当前观测，不把更改节点的演示称为因果干预。

## 6. 为什么新分支结构没有贡献

已选完整BN：

- 最终状态增量 δV = **0**。
- U→V系数 γ 约3.12e-7。
- 非归属出现偏移 α 约−9.1809，反映这批执行者只持有各自资料；不是安全发现。
- 可见支持系数约7.7535，可见反对系数约−1.3874。

δV为0时，最终出现预测不再依赖V，连带切断U_i通过V影响最终输出的通路。这是**学出的模型没有使用分支状态**，不是计算实现仍然合并分支。

额外诊断在不更换已选模型的前提下，对28个执行者/阶段参数作4组构造扰动，复算16个真实输入，最大概率变化约1e-15。扰动不是新训练或API实验，仅确认上述结构退化。

数据方面，全部16个流程的W矩阵都是同一个对角形式；最终行为都遵循可见授权支持/反对/缺依据。训练分类器矩阵16×53，加截距秩仅8。这里不能识别丰富的角色差异、分支相互作用或未知授权概率。

因此不能因分数接近0就结束研究，也不该为了保留复杂结构而强迫相关系数非零。下一步需要有独立研究依据的工作流/信息分配/权限关系变化，以及同信息强基线；不能专挑按BN规则设计的数据来制造优势。
