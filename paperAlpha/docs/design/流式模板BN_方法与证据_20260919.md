# 流式条件模板 BN：实现与证据

日期：2026-09-19。此文区分**实际实现、开发结果、原定完整目标**，不以历史满分替代当前证据。

版本补充：本文记录49参数的模板BN及其两轮完成实验。后续69参数联合两层原型、进行中的新对照及最新差距见[联合两层BN：实现与开发评测](联合两层BN_实现与开发评测_20260919.md)，不要把两版结构或分数混用。

## 1. 固定目标与当前差距

原定目标仍然是：文献风险知识 → 工作流节点的可解释子 BN → 跨 Agent 运行图的可学习态势层 → 联合训练的 API MAS 监测器。不得把一个更容易测的分类头改称完整目标已实现。

| 要求 | 当前证据 |
|---|---|
| API 可见输入，不依赖权重/内部激活 | 逐事件接口已实现；当前主要使用结构化字段，原始文本提取未完成 |
| 运行时前缀，不预读未来 | `EvidenceStream.push` 及反事实前缀测试；旧 temporal 结果另行撤销资格 |
| 文献到可组合概率图 | 四组JSON规范已接入核心，可编译命名父变量/共享CPT/OR无环图；还不是全部风险目录自动编译、自动职责分组 |
| 每个工作流节点的角色相关子 BN | 当前是动作级/全局共享条件表，角色专属结构与完整工作流拼装仍缺失 |
| 可学习跨 Agent 全图层，端到端 | 当前路径按确定规则提取，门控不可训练；全局仅四个布尔变量，未完成原定结构 |
| 系统风险评估 | 已完成本次开发集终态分类；没有现实安全保证 |
| 真正的提前监测 | 前缀等任务权重监督已实现；本次控制误报后的提前召回仍为0，不能声称预警成功 |
| 强 MAS 方法对比与外部有效性 | 本次只比较同一证据上的 BN/Logistic/HistGB，非原论文 MAS baseline 复现 |

## 2. 输入与图语义

`push(event)` 只观察新到的事件。工作流 W 和 allowed_tools 必须由调用方明确提供，不能从整次运行的未来消息/动作推断出来。

- W 表示声明的工作流，不是因果图；运行图只来自实际消息。
- runtime-only **忽略 edge_kind**。v3 生成器用 W 产生该标记，保留它会让“不知道 W”的设定偷带规范信息。
- 没有 W 时，不评价规范外边；此时特征 0 表示没有可断言的偏离，不能解释成已经确认合规。是否有 W 单独保留在证据中。
- 来源优先用明确 `source_id` 去重；没有此字段时只使用入口 Agent 代理。两个不同 Agent 不代表两个独立材料来源。v3 缺少 source_id，不能评价独立来源辨认。
- 消息必须先于下游动作才能构成该动作的证据。后来的输入不能沿早先的消息倒流。
- 权限分为未知、观察到无异常、观察到异常；“无异常”不等于被证明授权。
- 同一 action_id 的 proposal 和 dispatch 合并；重复传输按 event_id 去重；无效更新不能污染状态。
- 验证递归拒绝标签、隐藏效果及风险机制元数据，但这不是对任意字符串内容的万能泄漏审计。

## 3. 概率模型

四类模板选取命名的父变量状态，查对应的 Bernoulli 条件表：

| 模板 | 父变量 | 表项数 |
|---|---|---:|
| authorization | 权限三态 × 能力三态 | 9 |
| information_flow | 观察到路径 × 多来源键代理 × 权限三态 | 12 |
| workflow_deviation | 直接偏离 × 上游偏离 × 权限三态 | 12 |
| global_context | 不可信消息 × 未知消息 × 偏离消息 × 多个受影响 Agent | 16 |

共49个参数位置，并非49个都在数据中出现。动作级模板在观察到高权限动作提议/调用后才实例化；不预先知道未来谁会用工具。

设第 j 个表项的概率 q_j = sigmoid(theta_j)，快照中该表项激活 c_j 次。在**给定观察父变量后，各模板风险独立**的模型假设下：

`P(Y=1 | 当前快照) = 1 - product_j (1-q_j)^c_j`

等价地，`H = sum_j c_j softplus(theta_j)`，`p = 1-exp(-H)`。训练使用任务级二元负对数似然和固定弱先验；解析梯度经有限差分核验。没有将任务标签当作每个 Agent 的真实标签。

**可解释范围：**可以精确指出每个表项对模型 H 的贡献，以及对应动作与通信证据，但不能据此证明各局部真实风险。不同参数分解可能产生相同系统概率。本次所有设定都发现设计矩阵秩小于活跃表项数；弱先验只是选择一个解，不能解决局部真值的不可识别性。共享证据也可能违反独立假设。

当前为参数点估计，不是完整贝叶斯后验；不输出伪装成可信区间的上下界。

### 知识模板编译已接入

`configs/risk_templates_v1.json` 定义四组模板的父变量、状态语义、条件表布局、适用范围、正常对照和证据缺口；`template_registry.py` 校验文献ID与风险条目关联。核心的模板规格、49个表项名称与索引现在从该规范读取，不再维护另一份硬编码规格。

`TemplateBN.explain(snapshot)` 会编译“观察父变量→动作/全局Bernoulli风险→系统OR”图。同一动作共享权限父节点，同类动作共享条件概率表；源码仍负责事件触发和证据提取，JSON触发说明还不是任意风险机制的自动执行引擎。

`results/template_graph_examples_20260919/graphs.json` 保存真实开发轨迹 `ind-v3-000100` 的4个时刻图与文献关联。选样只按可见模板覆盖，不使用标签；全部14个前缀的图边缘概率与已存预测一致。这证明编译与数值一致，不证明角色子图自动发现、因果真实性或精度提升。

## 4. 本次冻结开发实验

结果：`results/streaming_template_bn_20260919/`。

- 4,000条已有合成轨迹；公开 W 按重命名不变的拓扑签名分为2,364组。签名可能保守合并不同拓扑，不会因为改名将同构图拆开。
- 固定三个种子，分别划分 fit/validation/test；同一组不会跨分区。同一套划分用于所有方法和可见性设定。
- 4种设定：有/无 W × 有/无权限观测。所有方法拿到相同49维模板证据，屏蔽操作一致。
- BN、Logistic、HistGB；额外分别去掉四类模板并重新训练。每个方法的阈值只由 validation F1 选择。
- 既有数据已反复查看，所有分区仍然属于**开发材料**，不是独立确认性测试。
- 多次留出相互重叠，标准差是划分敏感性，不是独立重复试验置信区间。

| 设定 | BN F1 | Logistic F1 | HistGB F1 | BN AUROC |
|---|---:|---:|---:|---:|
| runtime-only，权限可见 | 0.666±0.023 | 0.672±0.018 | 0.665±0.026 | 0.791±0.007 |
| runtime-only，权限屏蔽 | 0.581±0.010 | 0.581±0.010 | 0.581±0.010 | 0.686±0.013 |
| W已知，权限可见 | 0.663±0.022 | 0.671±0.019 | 0.657±0.020 | 0.789±0.007 |
| W已知，权限屏蔽 | 0.584±0.009 | 0.583±0.010 | 0.580±0.006 | 0.687±0.012 |

结论是**尚未领先**。加入 W 的现有偏离模板也没有稳定增益。不能因为知识条目变多，就默认模型更准。

消融中，runtime-only权限可见的BN：去掉授权后AUROC从0.791到0.717；去掉信息流到0.770；去掉全图上下文到0.763。这是特定数据/训练设定下的贡献诊断，不是因果效应或已证明的统计显著性。

## 5. 预警证据必须单独说

终态分类器在 runtime-only、权限可见的三个留出里，高权限调用前的召回均为0；负任务任一时刻报警比例约为29%–32%。说明终态F1不能代表提前预警好。

这些分数用终态标签拟合后直接套到前缀，只能称“终态分类器的前缀诊断”。没有验证其预测概率或阈值适合连续监测。

数据没有独立违规时间戳，因此不能计算真实危害提前量。首个高权限工具调用仅是可观察参考点，合法工具调用也可能发生。真正的预测目标、前缀训练与任务级连续误报控制必须另做实验，不能复用旧的高分证明。

### 前缀监督实验已完成

`results/prefix_forecast_v1_20260919/` 精确复用相同三组分割和四种可见性设定。训练目标明确为 `P(最终任务风险标签=1 | 当前前缀)`，不是“当前已经违规”或固定时间后的危害。每条训练轨迹的全部前缀总权重为1，避免长轨迹占主导。

各方法只用 validation 负任务的全轨迹最大分数选择报警阈值，使**验证集经验**整任务任一时刻误报率不超过10%；测试集不参与选阈值。该阈值不是总体误报保证，也不同于首轮终态F1最优阈值，不能直接比较两轮F1来断言模型退化。

无工作流、权限可见的三种子均值：

| 模型 | 等任务权重前缀Brier（越低越好） | 测试整轨迹误报率 | 首个高权限调用前召回 |
|---|---:|---:|---:|
| 终态训练BN | 0.2643 | 5.71% | 0 |
| 前缀训练BN | 0.2172 | 5.71% | 0 |
| 前缀Logistic | 0.2088 | 5.98% | 0 |
| 前缀HistGB | 0.2086 | 5.84% | 0 |

全部四设定、四方法、三个种子的提前召回都为0。结论是前缀监督改善了概率误差，但当前证据表示和评分模型在此误报约束下没有实现有效提前预警。不能仅归因于数据不可预测或某个单一模块；工具提议之前只有四个全图布尔量参与当前评分，角色能力、实际语义与可学习动态层仍然缺失。

独立审计器 `scripts/audit_prefix_forecast_run.py` 从冻结源码和48个已存模型复算了591,584个验证/测试前缀分数，最大绝对误差0；同时核对了所有哈希、划分、验证负样本阈值和指标。证明范围是实现与存档一致，不是外部有效性。

## 6. 可复现与验收

配置、划分、参数、预测、解释保存在独立运行目录。`source_snapshot/` 保留该次运行的精确源码与配置，后续修改工作区代码不会冒充旧版。

运行 `python -B paperAlpha/scripts/audit_streaming_run.py` 可验证源文件与输入哈希、划分隔离，并从冻结源码重算 BN 的测试/前缀分数和验证集阈值。第一次审计通过：12组运行，66,052个方法-任务评分的指标核对，88,696个BN前缀评分重算。基线仅核对已存分数的指标，没有再次拟合基线。

知识编译整合后的测试为84项通过（两条依赖弃用警告）。下一轮应继续实现原定的知识约束节点子图及可学习动态层，同时补充多动作、角色/能力明确且带独立结果标注的轨迹。不能以当前分类器通过单元测试，宣称大框架完成。已有MAS原方法的真实接入边界见 `MAS原方法复现入口核验_20260919.md`。
