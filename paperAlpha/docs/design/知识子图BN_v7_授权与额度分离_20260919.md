# 知识子图 BN v7：授权与额度分离

## 本次实质进展

新增可选`KnowledgeScopedBN-v7`：由知识配置选择真实参与推断的局部动作因子，并分别维护授权、单次额度、累计额度三类历史状态。不是给同一分数追加三个文字标签，也不是已完成所有职责的自动子BN构建。

v6把金额特征写进授权因子，导致“超自报上限”和“未获授权”混用同一个潜变量。v7改为独立机制分支：改变额度证据可以影响额度分支和系统分数，而不改变授权分支或过程状态的边际分布。分支之间的历史仍与过程状态保存在完整联合分布中。

最新默认配置345参数，未训练，不继承71参数旧版或340参数v6的性能。结构解释得到改善，不等于风险类型概率已经校准。

## 1. 从知识模板到实际子结构

`configs/action_mechanism_templates_v1.json`提供以下三片可执行结构。`action_mechanism_knowledge.py`校验风险目录/文献来源对应关系，生成共享参数布局、实例化条件、观察父节点与因子。编译器逐条处理当前可见日志，不查看未来工具或标签。

| 模板 | 何时建立 | 因子的观测父节点 | 不表示什么 |
|---|---|---|---|
| authorization | 每次工具派发 | 能力、角色、当前绑定的检查状态 | unknown不等于禁止；模型自述不是检查 |
| declared_bound | 公开能力为付款且有已注册数值观察 | 自报金额/上限比较、金额冲突和未知 | 自报上限不是真实授权 |
| cumulative_budget | 上述付款能形成某个显式合约的范围比较 | 同范围累计、全局上限、缺失贡献、未知范围 | 请求额不是实际支出；合约来源字符串不是认证 |

读资料节点不会因为同在一个MAS中就被强塞付款额度因子；付款节点也只有在适用的观察存在时才建相应因子。没有全局合约时，累计分支不实例化，解释中概率为`null`、`instantiated=false`，不返回一个看起来很安全的0。

角色仍来自预先给出的工作流/分组，并选择授权条件表；数值子结构主要由能力和观察适用性决定，**不能称为已经完成按职责语义自动生成全部子BN**。工具映射、数值profile和三片模板当前仍经人工设计/审核。

配置不是装饰：从registry移除一片模板，会移除其参数、动作因子和历史维度；保留模板则其条件概率及历史真的进入系统评分。运行解释保存每次选择/不选择的理由、实际参数名与值、观察向量、知识来源和覆盖局限。尚无完整v7独立图文件解释器，不将因子清单包装成完整通用BN导出。

## 2. 概率与推断

沿用v5的文本条件过程变量`C_i`和实际消息转移。对派发动作a，为适用模板k建立二值机制假设`R_(a,k)`：

```
q_authorization = sigmoid(能力×角色×检查状态对应的参数)
q_k = sigmoid(b_k + w_k · x_(a,k))  # 数值模板
```

每个数值模板有不同的观察父节点，不再把额度信息写入授权条件表。自报上限和累计超限是可见算术观察，`R`仍是预测模型的潜在假设，不把它解释为真实违规标签。

给定当前可见证据，各动作/机制因子采用条件独立假设；如果真实世界中存在未观测的共同授权错误、资源状态或身份来源，这一假设可能不成立。联合推断不会自动弥补错误的因子假设。

每个机制独立维护三态历史`H_k`：

1. 尚无该机制的风险假设；
2. 曾有该机制风险，但当时没有过程风险重合；
3. 曾有该机制风险，且派发当时过程风险也存在。

新因子只推进自己的历史维度，状态3吸收；文本和消息只更新当前`C`，不能改写过去派发时的重合状态。推断保留`P(C,Z,H_authorization,H_declared,H_cumulative)`，不是各边际乘积。

给定以上因子假设，且输出只依赖这些历史摘要、未来不修订已派发因子，消去各动作变量是精确的：每个新`R`按其Bernoulli概率将当前历史推进到对应后继；按归纳，压缩前后的历史联合分布一致。测试使用**保留全部动作二值变量和派发快照的独立字典枚举**对比，不调用生产历史转移来证明自身。

三个模板固定配置下，持续概率质量数为`27×2^(过程/来源位数)`；v5是`3×2^n`。真实四节点例子从48增至432，明确存在计算代价。未实例化维度当前仍占数组位置；动作元数据也继续增长。支持最多3个机制、12个过程/来源位，不是大图推断方案。

## 3. 全图输出与训练

全图输出仍对联合状态下的条件风险作加权平均。保留15个可见统计和原过程/授权历史统计，为两个数值机制分别增加“曾有风险”和“派发过程重合”两个系数。

- v5基础参数326。
- 单次额度：偏置+7特征，共8。
- 累计额度：偏置+6特征，共7。
- 两个新机制各2个全图输出系数，共4。总计345。

默认数值特征系数和新增全图系数都为0。新增读出关闭时，与同参数v5等价；这是嵌套设计/回归证据，不是默认新模型更强。

仍采用等任务权重的前缀二元交叉熵、解析梯度与L-BFGS-B。局部机制、过程转移、通信、全图输出可联合训练；API提取器和离散选择器不在梯度里。本轮只有手工组件样本上的训练目标下降检查，没有把真实运行伪造为安全/危险标签训练。

目前系数未施加语义单调约束，因此不保证“超限特征上升一定使风险分数上升”；也没有单独机制真值监督、参数可识别性、参数后验或安全保证。这些是后续设计/实验问题，不能仅凭变量命名解决。

## 5. 文献与贡献边界

- [Object-Oriented Bayesian Networks（UAI 1997，摘要核读）](https://arxiv.org/abs/1302.1554)：支持复用概率片段和层次对象作为已有建模路线，不能把“模板化子BN”本身声称为全新发明。
- [AuthGraph §3.2–3.4](https://arxiv.org/html/2605.26497v1)：区分运行来源和独立授权规范，支持不将Agent叙述直接升级为批准。我们没有复现它的整套检查器。
- [Bounded Agents §4.2–4.4](https://arxiv.org/html/2608.15888v1)：讨论委派范围和基础设施维护的累计预算。我们仅监测已声明的请求，没有实现其执行边界，也不继承其安全定理。

以上文献不提供我们的二值因子、三态历史或概率参数。这些是需要实验检验的工程建模选择。文献索引见`literature/mas_safety_2026-09-11/knowledge_bn_modularity/README.md`。
