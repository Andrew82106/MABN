# 联合两层 BN：实际结构与开发评测

本文件记录 `DynamicJointBN-v1`，不要与49参数的 `TemplateBN` 或历史 TwoLayer/Fusion 的分数混用。它是原定两层目标的新原型，不表示整个文献知识编译、文本理解和现实 MAS 评测已经完成。

完成补充：12组现已全部训练结束并通过冻结复算审计，最终结论见[12组开发评测结论](联合BN_12组开发评测结论_20260919.md)。下文第一组/六组阶段记录保留为历史进度，不代表实验仍在运行。

## 1. 实际实现

- 第一层：明确声明的工作流节点或 Agent 分组，每个节点一个二值潜在风险状态；来源、接受影响、授权三类条件概率机制。
- 第二层：按实际消息时间顺序更新节点的联合状态分布，再用命名全图特征预测任务最终风险。
- 来源、节点接受影响、授权、消息传播和全图评分参数一起训练。不存在先给每个节点贴上整任务标签再独立训练的步骤。
- 精确联合推断保留同源分叉、汇合的依赖，不把两个转述当成两个独立风险源。
- 可选显式 `workflow.agent_to_node` 分组、`roles` 和工具能力清单。角色或能力不从未来运行记录推断。

代码：`src/paperalpha_monitor/dynamic_joint_bn.py`。评测：`scripts/evaluate_dynamic_joint_bn_v1.py`。冻结配置：`configs/dynamic_joint_bn_v1.json`。

## 2. 概率语义

来源变量记为 Z，节点在事件 t 后的潜在状态记为 X_i,t。X 是模型中的风险假设，不是已观测违规、真实内部恶意或经过识别的因果状态。

每条事件只触发相应局部更新：

- 新来源：Z 按来源可见分类对应的 Bernoulli 概率初始化。
- 首次进入某节点：`X_i' = X_i OR (Z AND adoption_gate)`。
- 敏感动作首次出现：`X_i' = X_i OR authorization_gate`。
- 实际 i→j 消息：`X_j' = X_j OR (X_i AND transmission_gate)`。

各 gate 的概率由可训练 logit 经 sigmoid 得到。接受影响条件表按角色×来源分类索引；授权表按角色×权限观测索引；传播表按消息分类×是否符合规范通信×是否委派索引，另有消息分类置信度系数。

给定截至当前的事件，维护来源和节点状态的**联合分布** μ_t(s)。同一个来源只分配一个 Z。消息可以在分叉处分流、在下游汇合，但不会将 μ 强行拆为独立节点边缘概率。

最终输出：

`p_t = Σ_s μ_t(s) · sigmoid(β_obs · f(E_≤t) + β_state · g(s))`

其中13个可见特征包括节点/消息数量、消息分类占比、是否有规范图、规范外通信、来源数量、敏感动作、权限异常、能力资料可见性等；4个状态特征为风险节点占比、共同风险节点对占比、有敏感工具能力节点的风险占比、规范末端节点的风险占比。

规范末端只表示图中的终点，不代表拥有高权限。工作流的边只帮助解释实际通信，不会凭空传播风险。没有 W 的设定忽略从 W 衍生的 `edge_kind`。

## 3. 学习目标与规模

目标是“当前前缀条件下，任务最终标签为风险的概率”，不是当前已经违规，也不是固定未来时间窗风险。

对每条任务的全部非空前缀计算二元负对数似然，每条任务总权重相同；加入固定弱正则。L-BFGS-B 使用解析反向梯度，来源/局部状态/传播/全图输出联合拟合。梯度与有限差分比较通过。

共有69个参数：来源3、接受影响15、授权15、传播18+置信度1、全图输出17。当前版本不同角色共享结构、使用不同条件表，不是每类角色已有完全不同的知识子图。

成本随节点和来源的二值变量总数指数增长。配置最多10个变量，即最多1024个联合状态；**不是最多10个 Agent 再加任意多个来源**。超限明确失败，不偷偷改成独立近似。大图推断仍待设计和独立验证。

## 4. 本次冻结实验

输出：`results/dynamic_joint_bn_v1_20260919/`。启动时固定全部4种信息可见性×3种子，共12组；不根据测试表现更换种子、缩减数据或挑选完成结果。

- 精确复用 `streaming_template_bn_20260919/manifest.json` 的4000条合成开发轨迹、拓扑组隔离和 fit/validation/test ID。
- 各方法都看同样的可见事件、工作流和权限信息；表示可以不同。
- 完整模型 `joint_bn`。
- `no_messages`：关闭潜在状态的消息传播，保留直接可见的消息统计；测试传播模块的额外价值。
- `no_latent_head`：风险输出仅使用13个可见特征；潜在状态不再影响预测。
- `template_bn_prefix`：旧49参数模板BN在相同前缀监督下重新拟合。
- `logistic_flat_prefix` / `histgb_flat_prefix`：13个可见统计＋49个按时间提取的模板计数，允许利用跨Agent路径和工作流信息；不是限制为单Agent的弱对照。
- 各方法的报警阈值仅由验证集负任务的全轨迹最大分数确定，经验连续误报率不超过10%。测试误报率允许超过10%，该协议不是总体安全保证。
- 所有模型、参数、逐前缀预测、收敛状态和训练时间均保存；评测脚本、模型包、配置、知识目录在运行前留存源码快照。

这6种方法是同观测对照和架构消融，**不是已经复现的原论文 MAS 监测方法**。旧基准已多次查看，仍属于开发证据。

## 5. 第一组完成结果（其余组运行中）

仅 `runtime_only__observed`、种子20260919；并非12组平均，也不是最终结论。完整进度以结果目录的 `metrics.json` / `REPORT.md` 为准。

| 模型 | 等任务权重前缀Brier↓ | 终态AUROC↑ | 整任务任一时刻误报率 | 首次高权限调用前召回 |
|---|---:|---:|---:|---:|
| 完整联合BN | 0.2010 | 0.8262 | 11.11% | 6.47% |
| 去掉消息传播 | 0.2023 | 0.8187 | 11.31% | 10.43% |
| 去掉潜在状态输出 | 0.2042 | 0.8194 | 4.56% | 0 |
| 旧模板BN | 0.2172 | 0.7772 | 6.55% | 0 |
| 增强特征Logistic | 0.2032 | 0.8193 | 7.94% | 1.80% |
| 增强特征HistGB | 0.2004 | 0.8173 | 8.53% | 4.68% |

能支持的结论：该组新版的概率误差优于旧模板BN；传播相对消融只有小幅增益；HistGB概率误差仍更低；新版出现一些提前报警，但测试误报也更高。**不能宣布全面领先，不能把不同测试误报水平下的召回直接当成预警优势。** 没有独立危害时刻，表中的提前指标只以敏感工具派发为参考。

第一组4个BN模型均收敛。`AUDIT_first_run.json` 从冻结源码与模型重算6个估计器、77,232个验证/测试前缀分数，最大误差0。审计只覆盖第一组，不覆盖未完成组，也不证明训练数据来源、模型假设或现实有效性全部正确。

## 6. 知识与解释的实际边界

- 性能实验冻结版的局部结构由Python定义。后续已将四种条件模板接入 `joint_risk_templates_v1.json`，由知识规范生成参数布局、表项选择和可执行时间展开DAG；与冻结版的148,648个前缀输出一致。见[知识模板与可执行图](联合BN_知识模板与可执行图_20260919.md)。尚未让整个风险目录自动编译成不同角色的专属子结构，不能将局部接入误称完整自动知识编译。
- 当前数据没有明确角色/能力清单，角色实际均为unknown；没有 `source_id` 时用入口Agent代理来源。因此本轮不能验证角色差异学习，也不能证明现实同源材料识别。
- 当前观测主要是结构化分类与权限记录，原始文本语义提取未接通。`data_class=clean`不是对文本安全的证明，传播概率不强制为0。
- 局部概率不保证可识别，参数点估计不是完整贝叶斯后验；命名参数只提供结构可读性，不保证语义完全忠实。
- 每个节点当前只有一个合并风险状态，尚未分开信息污染、越权、泄露、资源耗尽等风险类型；输出主要是任务级风险概率。
- 潜在状态只累积、不恢复；审核通过、撤销授权、清洗资料和任务纠错尚无对应状态恢复机制。
- 来源初始分类与一次授权注入不进行后续完整证据修正；同action的proposal/dispatch不重复注入，新的权限检查只更新可见统计。
- 本轮性能评测的冻结版接口编译整条轨迹后逐前缀过滤。后续已增加真正逐事件更新的 `JointRiskStream` 与JSON日志入口；148,648个前缀对冻结版的分数差异仅为浮点舍入，联合状态差异为0。详见[在线接入与一致性](联合BN_在线接入与一致性_20260919.md)。真实框架挂钩、部署服务与原始文本解析仍未完成。
- 尚缺真正MAS原方法同协议比较、外部轨迹验证、完整知识生成、多种风险输出、大规模推断和自动DAG提取。不能将本轮完成定义为整个项目完成。
