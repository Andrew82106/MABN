# 共享授权节点 BN：联合结构与可学习性

## 本轮结论

新增可选原型 `SharedAuthorityJointBN`，把上一轮只留在解释里的共享授权依据，变成真正参与系统计算的随机节点。多个动作复用同一未知授权时，不再被当成独立事件；局部引用链与全图状态可以联合训练。

**本轮证明的是结构表达、数值正确性和受控可学习性，不是 MAS 安全领先。**没有新 API 调用，没有更换原模型分数；同信息 Logistic 在人工训练频数表上仍稍好，独立真实评测尚未完成。

## 1. 为什么必须改结构

上一轮三 Agent 分支诊断只改变一个子授权的父引用：两动作共用同一授权根，或分别依赖两个根。原 451 参数模型的 13 项局部关系特征完全相同，因此任何固定参数下都不能利用这个差别。

本轮不再把授权图先压成每个动作的固定长度特征，而是保留：

- 有外部来源、任务、委托人和观察窗口绑定的授权事实身份；
- 每个动作引用的授权路径；
- 同一路径上全部条件同时满足；
- 多个替代路径中任一个成立即可。

这是在既有授权片段上进行概率结构升级，**不是已经实现了任意职责子 BN 或整个 MAS 工作流自动发现**。

## 2. 从记录到概率节点

`AuthorityProofGraph` 使用已有 `DelegationSnapshot`，重新按原始记录检查候选链，不接受未来记录、被改动的动作绑定或篡改后的路径。

1. 在外部观察契约成立时，明确的无效链为假；完整有效链为真，不人为留一个非零“越权概率”。这只是“当前动作提供的授权引用是否满足配置政策”，不是实际伤害概率。
2. 对已认证、路径可解析，但更新记录可能缺失的授权，建立未知失效变量。重复使用同一事实共用一个变量；身份键包含观察窗口、任务、委托人及原始授权记录。
3. 对未认证、缺失父链或动作绑定不全的候选，保留动作范围内的独立未知变量，不凭未认证文本把两个对象合并成同一授权。
4. 若已确定有一条有效替代路径，其他无关未知路径不影响该动作，也不消耗额外随机变量容量。
5. 根授权、委派记录、不可解析引用三类未知量各有一个可学习 logit，经 sigmoid 得到失效概率。当前不是每个 Agent 各拟合一个参数，也没有参数后验或独立概率校准。

令 `U_g=1` 表示某个共享依据在当前建模窗口中存在未知失效，则动作 a 的引用支持为：

```
supported(a) = OR_{引用路径 p} AND_{p 中未知依据 g} (NOT U_g)
failure(a) = NOT supported(a)
```

路径中已证伪的条件直接使该候选路径失效。没有引用意味着不满足本实验明确规定的“必须提供引用”政策，**不能据此断言系统不存在其他未被引用的权限**。

可信观察服务、根身份、记录认证与完整性均由外部适配器负责；字段里写了 `authenticated_actor` 不等于已完成密码学认证。

这些记录必须实际存在于 Agent 框架或工具日志中，不能假定任意模型 API 会返回授权元数据。只有文本转述时不能启用已认证共享链，其他文本/行为监测支路也不能因此被省略。

## 3. 第二层如何真正用到共享关系

仅输出每个动作的边际风险仍会丢失相关性。这里枚举共享事实的可能状态 u，在同一个 u 下运行整个已有过程状态/风险历史过滤器，再做加权求和：

```
p_t = Σ_u P(u | 已声明的观测条件)
          Σ_s P(s_t | u, 到当前的事件)
              sigmoid(原全图评分(s_t) + γ1·失败动作占比 + γ2·失败动作对占比)
```

两个新增全图量在每个共同状态 u 内计算：

- 失败动作占比：`m/n`；
- 失败动作对占比：`m(m-1)/(n(n-1))`，不足两个动作为 0。

它们不是把各动作边际概率相乘。新增两个系数在训练时约束为非负；不据此声称整个旧全图头具有全面单调性。

条件化在 u 后，动作引用失败为确定值，进入原授权历史；文本/消息过程状态及其他知识风险历史仍被联合保留。先分别求边际再相乘，不等价于这套计算。独立字典穷举测试保留全部动作及派发时过程状态，对照了生产代码的历史压缩。

参数布局为 **378 个既有系统参数位 + 3 个未知事实参数 + 2 个联合态势参数 = 383**。旧两个工具分类头的 73 个参数没有加入本模型。由于本通路改成显式引用证明，旧局部授权条件表、职责和 13 项关系权重不再决定其概率；保留参数位是复用系统引擎的工程布局，**不能声称 383 个参数都在本实验中学到了有效知识**。下一步应整理失效参数位，而不是拿参数总量当贡献。

## 4. 已实际验证的区别

假设每个根有 .2 的未知失效概率，子委派记录在该窗口中完整可见，且不同根独立：

| 结构 | 每个动作的边际失效 | 至少一个动作失效 | 两个动作同时失效 |
|---|---:|---:|---:|
| 共用一个根 | .20 | .20 | .20 |
| 各自独立的根 | .20 | .36 | .04 |

代码精确恢复这些值。多个替代路径也正确处理：一个动作可用两条独立根路径时，两条都失效的概率为 .04；若两条路径实际共用同一根，则仍为 .20。

系统头已接入这些区别：在强调“同时失效”的受控配置下，共享根的系统分数更高；强调“至少一个失效”时，可以是独立根更高。不能把“共享关系”简化成总应增加风险的惩罚项。

## 5. 学习实验：只报告其应有的资格

训练前冻结源码、模型定义、频数表和配置。频数表来自上述明确假定的 .2 概率规律；它们是合成频数约束，**不是 35/55 个独立任务，更不是 API 数据或独立测试集**。

### 引用政策目标

对“至少一个动作失效”拟合：共享结构 2 正/8 负，独立结构 9 正/16 负。

- 5 次迭代收敛；目标 .651088→.609699。
- 学到的根失效概率为 .20000052。
- 这里只监督引用查询，不能因此开放未训练的系统结果头。

### 系统结果目标

另设“两个动作一起违反引用政策才发生模拟级联结果”的端点标签。共享结构 2 正/8 负、独立结构 1 正/24 负，另有完整正常/完整无效各 10 个频数权重。

- 17 次迭代收敛；含正则目标 .531051→.191802。
- 9 个参数实际变化，其中根参数和两个全图态势系数均参与学习。
- 单独拟合的根概率不等于此弱监督系统拟合中的根概率；后者潜变量仍未获得可识别性证明。

| 同一人工训练频数表 | 原始 NLL↓ | Brier↓ |
|---|---:|---:|
| 共享授权联合 BN | .175874 | .047179 |
| 同信息图统计 Logistic | .170101 | .046573 |

Logistic 能看到动作数、明确无效动作数、未知根/委派/引用数、候选路径数、共享事实最大使用次数与总使用次数，没有被限制成看不到共享结构的弱基线。规则对完整情况确定判断、未知情况拒绝给确定答案，保留未知，不删难例。

这些只是拟合描述，**无独立测试、无胜率结论**。信息传播与共享参数同时有非零梯度的检查使用明确标注的手工来源/消息轨迹，不能冒充原真实 API 语义通路已被激活。

## 6. 时间、覆盖与计算边界

- `AuthorityWindow` 要求外部提供窗口身份和起止序号。未知事实假定在窗口内固定；不能假装已经建模持续变化、可能漏收的撤销过程。
- 每个动作的证据和引用证明按当时前缀固定。之后收到的撤销会影响后续动作，不会回写旧动作的证明或已输出分数。新未知事实在完整批量图中被边际化，不改变它出现前的前缀结果。
- 完整性可按授权 ID 声明，但必须来自适配器预先给定的观察契约，不能根据评测标签指定哪些记录可信。
- 不同原始授权事实默认条件独立。共享同一授权已解决；同一发证服务整体故障、不同根共同受攻击、跨窗口隐藏状态演化仍未解决。
- 缺父链时仍退回动作范围的未知量；即使多个可信子记录指向同一缺失父记录，目前也没有完整建模该缺失对象的共同属性和各子链的范围相容性。因此不能说所有缺证据依赖都已处理。
- 精确成本为 `2^(未知事实数) × 2^(过程/来源位数) × 3^(风险历史数)`。默认最多 8 个未知事实，联合状态上限 65,536；超限明确失败，不悄悄退化成独立模型。
- 新流接口只读当前前缀，但当前会重新计算整个前缀，不是高效增量缓存。长期、大规模 MAS 部署仍需改进。
- 旧 API 数据只做结构回放：完整正常引用得到 0、完整撤销得到 1、缺根使用未经训练的未知先验 .5。前两者是配置引用政策的确定性判断，后者不是实测风险概率；不复用训练“同时失效”的系统头去给这些单动作任务报新准确率。
- 仍保留 `evidence_insufficient`、`calibrated=false`、`proves_safety=false`，不自动阻断。

## 7. 理论来源与创新边界

共享随机事实、逻辑规则和 BN 组合并非新理论。[KU Leuven ProbLog 官方语义说明](https://dtai.cs.kuleuven.be/problog/tutorial/basic/08_rule_probs.html)区分了所有对象复用同一随机选择与为每个对象独立实例化随机选择；这直接提醒本项目必须正确绑定“同一授权依据”的身份。[官方 BN 教程](https://dtai.cs.kuleuven.be/problog/tutorial/basic/02_bayes.html)给出了用随机事实与条件规则表达 BN 的方式。本实现没有调用或完整复现 ProbLog 的求解器。

[OOBN 作者摘要](https://arxiv.org/abs/1302.1554)介绍了可复用的概率对象/片段及层次组合。不能把模板复用、AND/OR 或共享节点本身当作本项目原创。可能的方法贡献仍要落在：MAS 风险知识如何约束证据身份、作用域、时间和模块组合，以及这种编译出的监测结构在独立场景中是否有收益。

新来源索引保存在 `literature/mas_safety_2026-09-11/knowledge_bn_modularity/shared_probabilistic_facts.md`。未下载 PDF 或宣称通读原论文全文。
