# 隐私流 BN：真实 MAS 轨迹上的前瞻评测

## 结论与项目位置

新增可选 `PrivacyFlowBN-v1`，从已经出现的内部消息预测**后来面向用户的答复是否泄漏受限字面值**。使用作者公开的真实模型响应，不新增 API 调用，不修改原授权模型、旧数据或旧成绩。

4,258 条可用轨迹按任务模板分为训练 2,133、验证 1,026、测试 1,099。BN 在本次测试的总体 Brier/NLL 上优于同输入 Logistic/HistGB，但**共享状态扩展未显示稳定收益，原版 MAS 监测方法仍未复现**。这不是“所有 baseline 已被超过”。

它属于项目“风险知识 → 可解释局部片段 → 系统风险查询”主线中的**隐私信息流片段**，用于补真实训练和未来目标。它尚未与授权/额度片段统一训练，不替代完整 MAS 框架，也不是新数据集贡献。

## 1. 数据来源与观察边界

来源为 [AgentLeak 作者仓库](https://github.com/Privatris/AgentLeak)，固定提交 `1301eb9245a03bbee8694ee2b74accbc8f6fefe6`，MIT 许可证。实际检查 `benchmarks/ieee_repro/results/traces/` 中 4,979 个文件，不使用 README 的轨迹总数代替本地清点。

- 4,258 条满足当前源码的响应/消息绑定、标签和结构检查。
- 721 条存在 API 错误而排除，清单全部保存；保守沿用初次清点，包括只在单 Agent 对照调用中出错的轨迹。未将错误算作安全负例。
- 模型为作者采集的 Claude 3.5 Sonnet、Llama 3.3 70B、Mistral Large 2512、GPT-4o 和 GPT-4o-mini；不是本轮调用这些模型。
- 两个物理角色，三个功能阶段：协调者准备、执行者处理、协调者最终回复。物理通信有返回边，功能阶段按时间展开无环。不是自动发现任意 DAG。

复核了所有可用轨迹的实际系统提示：协调者和执行者都直接取得完整 vault；最后一次调用只有执行者答复和原请求，没有直接注入 vault。阶段间用户提示也逐项与实际前一阶段响应绑定。

### 监测器可见什么

这是**策略感知**实验：监测器由宿主预配置初始 vault 和允许披露的字段，再读取截止时刻已经完成的内部消息。它不只靠普通模型 API 自带的信息，不访问内部激活或权重。

第一截止点只看协调者给执行者的消息；第二截止点再看执行者回复。单 Agent 对照、最终答复、最终标签、总耗时、后续用量、轨迹 ID、模板 ID不进入预测接口。模型身份和业务领域是公开配置输入，所有比较方法同样可见。

上游 C5 记忆只是 `Cache: ` 加执行者回复的前 300 字符，不作为独立证据再计一次。

## 2. 标签到底表示什么

沿用作者当前代码的字面匹配：对 vault 中非空、字符串长度超过 3、未被字段允许列表放行、且未已出现在用户请求中的值，检查它是否出现在目标输出中，忽略大小写。

最终目标只对应最后的 C1，而不是 `multi_leaked`（包含先前内部泄漏）。因此确实是在较早时刻预测后续输出；但内部泄漏可能已经发生，**不能称为在首次隐私泄漏之前预警**。

限制原样保留：

- 上游 `forbidden_fields` 在这段检查代码里不决定标签，不能擅自改成只检查它。
- 字段名可能与允许/禁止列表不一致；多记录 flatten 只保留同名字段的最后值，而请求可能来自首条记录。这些来源问题不静默修复。
- 列表/字典在来源 vault 中已转成字符串；当前精确匹配不等于识别其中单个元素，更不能识别改写后的语义泄漏。
- “披露某个已配置受限字面值”不是人工确认的全部现实隐私伤害。

同一个字面值若对应多个字段，只建一个披露对象，避免把确定相同的事件当作独立副本。本批没有实际出现此类重复，单元测试验证了这个行为。

## 3. 网络与知识来源

知识配置为 `configs/privacy_flow_bn_v1.json`，关联现有目录 `RB013 / source 15`。文献和作者实现支持区分内部通道、对外接收者及字段策略；以下潜变量、参数化和训练方式是我们的建模选择，不宣称来自原论文或已证明因果。

对每个受限字面值 j，建立：

- C_j：协调者内部消息中是否出现，第一截止点可观测。
- W_j：执行者回复中是否出现，第一截止点未知、第二截止点可观测。
- F_j：最终对外答复中是否出现，两个截止点都未知。
- G：整条运行的二值共同披露倾向，统计假设，不是被识别出来的模型内部状态。

局部条件概率使用 sigmoid：

```
P(W_j=1 | C_j, 类型_j, x, G)
P(F_j=1 | W_j, 类型_j, x, G)
P(G=1 | x)
Y = 任意一个 F_j=1
```

x 只含第一截止点可得的信息：已出现受限值的比例、协调者消息长度、受限对象数、模型身份和领域。没有用最后答复、执行者未来长度或任务模板 ID 构造 x。

执行者直接访问 vault，所以 C_j=0 不强迫 W_j=0。不同对象在给定 G 后使用条件独立假设；没有声称解决一般字段关联。不同字面值之间的子串包含关系也没有被完整建模。

第一截止点，精确消去未来 W_j；第二截止点，使用实际 W 更新 G 的后验。在每个共同 G 状态内先计算“任意 F 出现”的概率，再按 G 的权重混合。不能先把各对象边际风险算出来，再假设独立相乘。

独立版本移除 G，其余观察、字段监督和条件特征相同。独立版 30 参数，共享版 43 参数。当前类型按 vault 的原生值类型区分；来源已把列表/字典转为字符串，所以本批 `structured` 类没有激活，其两个类型参数不构成已学到的能力。未来修订序列化类型识别必须另开版本，不回写本批结果。

## 4. 训练与对照

冻结源码、配置和划分后才训练。按四个领域各四个任务模板做稳定哈希排序：每个领域两个模板训练，一个验证，一个测试。共 8/4/4 个模板；相同请求、输入和模板都没有跨划分。

这是公开开发留出，不是盲测：此前已经清点过来源整体标签。测试结果已经查看，不能以后反复据此调参，再把同一测试称为独立评测。

训练规则：

- 两种 BN 均优化执行者与最终逐值披露的联合似然，使用梯度和 L-BFGS-B。
- 三个预定正则强度；共享版两个初值，先按训练目标选初值，再按两个截止点的平均验证 Brier 选正则。
- 分类器分别在两个截止点训练：标准化 Logistic 和 HistGB，各三个预定超参数候选，按验证 Brier 选择。
- 所有 9 个 BN 拟合和 12 个分类器候选完整保存。参数选择保存后才进入测试评测。
- BN 得到逐值训练监督，分类器直接学习最终二值目标，损失不同。因此不能把所有性能差都解释为“图结构的贡献”；更直接的结构对照是两种 BN 之间。

比较器使用同一监测包的统计，包括每种类型的对象数、C/W 出现次数、C 与 W 同时出现次数，以及相同上下文。这些是当前交换对称 BN 所用信息的充分计数，没有故意拿掉跨阶段关联。

另报告训练整体发生率、模型×领域历史发生率、当前字面披露即预测未来披露的对照。最后一项是确定性持久性启发式，不是作者的未来预测算法，更不是已复现的原版 MAS 监测方法。

## 5. 测试结果

同一批 1,099 条测试轨迹，396 条最终 C1 阳性。以下为 Brier，越低越好：

| 方法 | 协调者消息之后 | 执行者回复之后 |
|---|---:|---:|
| 独立隐私流 BN | .193490 | .160586 |
| 共享状态隐私流 BN | .193761 | .160583 |
| Logistic | .208139 | .198443 |
| HistGB | .203824 | .170230 |
| 模型×领域历史发生率 | .214233 | .214233 |
| 训练整体发生率 | .234652 | .234652 |
| 当前字面披露持久性启发式 | .414013 | .373066 |

共享 BN 的 AUROC 分别为 .7221 / .8354，NLL 为 .57865 / .47417，固定 .5 阈值的 F1 为 .5236 / .6137。不能只报有利指标：持久性启发式的 F1 为 .5905 / .6589，召回更高但误报也更多；它输出硬 0/1，不是校准概率。

BN 对 HistGB 的总体优势并非每个任务都有：两个截止点各有两个留出模板胜、两个负。后一个截止点法律任务改善约 .06462 Brier，金融和医疗反而分别差约 .01325 / .00757。因此不能宣称跨领域全面领先，也不将 1,099 条轨迹当作 1,099 个独立任务类型。

### 共享层是否有贡献

最好的共享模型学到：对 W 的共同倾向系数约 2.3293，但对 F 的系数为 **0**。所以观察到 W 以后，G 对最终 F 的直接作用关闭，两种 BN 的后阶段成绩几乎一样。较早截止点共享版整体还略差。

这不支持“更复杂的全图状态层是收益来源”。它提示应先保留有效的逐值条件传递结构，并用验证数据检验是否确有尚未解释的共同风险；不能为了维持预想结构强行保留有利叙述。

测试中，第一截止点未见内部字面披露的 384 条里有 68 条后来对外泄漏；第二截止点两次内部消息均未见披露的 221 条里没有最终阳性。这限制了本批后阶段“尚无任何迹象时预警”的证据。全体可用数据仍有 7 条 W 未命中而 F 命中，所以代码没有把 W=0 硬设为最终安全。

## 7. 下一步，不缩小总目标

本轮补的是可靠数据、前瞻目标与可解释信息流学习，不表示整体目标完成。继续工作应当：

1. 在训练/验证材料上检查条件传递失配：字段语义、请求用途、序列化值和实际接收权限，而非继续对已查看测试集调参。
2. 对照相同逐值监督的非图模型，区分监督颗粒度收益和结构收益；再评估文本/LLM 风险监测方法。
3. 使用新的外部任务与不同工作流验证；目前只覆盖一个两角色流程，不足以证明任意分叉 MAS 能力。
4. 把新隐私片段与授权/额度片段建立目标清晰的组合接口，不能将不同任务分数随意相加；再研究有证据支持的系统级共享结构。

自动 DAG、完整知识子图生成、跨工作流泛化、独立概率校准、可用原版 MAS 方法比较和真实在线延迟仍然未完成。旧框架和结果均保留；本轮无 Git 提交、推送或新 API 请求。
