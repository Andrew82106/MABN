# paperAlpha 研究材料

本目录保留知识底座和历史研究记录。唯一活跃实验方案见 [submission/README.md](../manuscript/README.md)；下列记录中的“当前”、离线状态、版本与分数只代表各自撰写时的情况，不是新的默认指令。

## 与项目主线的关系

本目录是 `paperAlpha/README.md` 所规定主线中的**风险知识层**：它为后续 DAG 节点、局部风险模板和分层贝叶斯网络提供文献依据。它不是最终图结构、训练集、因果图或已完成的监测器；任何新 Agent 进入本目录时，应先阅读上级项目宪章。

固定主线：风险知识库 → 知识驱动的分层图构建 → API Agent 运行时风险监测。
