# 联合BN：知识模板与可执行图

## 本轮改变了什么

之前69参数模型的局部结构和条件表布局写在Python里，知识链接仅作为配置备注。现在 `configs/joint_risk_templates_v1.json` 实际定义条件变量、状态、共享概率表的参数名称/初值、事件绑定、更新规则、知识来源、正常对照和覆盖缺口。

`joint_knowledge.py` 校验并编译这些规范。模型的69个参数位置、初始化、角色枚举和条件表选择从它生成；`JointEventCompiler` 根据当前可见事件选择表项，并检查表项与证据语义一致。参数仍由任务级训练联合学习，文献没有替我们提供风险概率或先验数值。

这一步是把知识规范接入运算，不是新增性能提升，也不是“新增一篇文献就自动更准”。为隔离改动，本轮保留原先的参数顺序、数值和模型方程。

## 实际图结构

`joint_graph.py` 将当前轨迹前缀编译成时间展开的概率DAG：

1. 观察节点：角色、输入分类、权限检查、实际消息类型等当前证据。
2. Bernoulli门：选择知识模板中的共享条件表行。
3. 节点/来源状态：接收上一状态与门的影响；跨Agent传播额外连接发送方当时状态。
4. 系统风险节点：连接这一前缀的节点状态和可见全图统计，使用原先的可学习输出层。

每个门都有模板、参数、条件状态、事件序号、知识条目与覆盖边界。来源状态由明确ID共享，因此同源分叉后汇合不会变成两个独立源。

图对象不是仅用于画图：`CompiledJointGraph.predict(theta)` 直接解释图中的门与状态更新规则，按时间消去中间门、维护完整联合状态，再计算各前缀输出。它不调用原模型的 `_forward`。模型 `explain(..., include_graph=True)` 返回此图及其独立重算的概率。

这是针对当前 `seed_or` / `carrier_or` 模型的精确解释器，不是任意BN通用求解器。图结构体现建模假设，不能证明真实因果关系。

## 文献依据及没有借用的结论

2026-09-19重新核对以下原文相关方法章节：

- [Prompt Infection，§3.1–3.2](https://arxiv.org/html/2410.07283v1)：展示跨Agent转交和与角色、工具相关的攻击分工。我们据此区分入口、接受影响与转交，但消息存在不代表已经采纳；文献未给出我们的Bernoulli参数化。
- [AuthGraph，§3.2–3.4](https://arxiv.org/html/2605.26497v1)：把轨迹中的来源记录与独立生成的授权规范分开。我们保留授权机制，不从“信息流经某人”推出授权。当前实现没有复现其参数来源检查，而且原文把跨Agent追踪列为现有架构外的问题。
- [From Spark to Fire，§6.2–6.4](https://arxiv.org/html/2603.04474v1)：使用声明谱系并区分确认、冲突与未解决信息。我们借鉴来源共享，尚未实现其声明拆解、外部验证和纠错流程。

RB008/RB009/RB011等链接继续保留已有目录的来源关系和局限；本轮没有将这些条目全都实现，也没有宣称重新核读了所有来源全文。

## 已验证的范围

- 当前全部方法测试162项通过（包含新增图/模板测试及阈值诊断测试）；知识规范错绑来源、重排解释变量、错误表项和证据不一致均被拒绝。
- 图解释器、原可微模型的前缀输出一致；图损失的数值导数与训练代码的解析梯度一致。
- `results/joint_knowledge_equivalence_20260919/`：4000条已有轨迹×4种可见性，共148,648个前缀。图解释器相对训练前冻结源码的最大概率差异为0；在线实现差异最多 `1.11e-16`，联合状态差异为0。
- 比较使用同一个既有参数向量，不读取标签、不重新训练，因此不构成新的准确率结果。
- `results/joint_knowledge_graph_examples_20260919/graphs.json`：按测试ID排序选第一条 `ind-v3-000012`，导出1/7/10条事件时的三个图，分别有10/44/53个节点；不使用标签挑选例子。

旧的性能实验仍来自运行前的源码快照，新知识规范的接入通过独立等价性检查与旧结果关联，不能把新文件倒算成旧运行的一部分。

## 与最终目标的差距

目前解释器支持四种明确绑定：来源首次出现、来源进入节点、敏感动作首次出现、实际消息。新增完整风险机制，仍需要补条件变量、事件适配和检验；不能只新增目录条目就自动执行。

各角色现在共享同一种二值状态结构，仅条件表不同。多风险类型、不同角色的专属子结构、共享记忆、预算/资源组合约束、独立授权核验、风险恢复、原始文本语义提取和自动职责/DAG生成仍未完成。精确推断的10变量限制也未改变。

因此目前可以说“当前四类知识模板已驱动两层概率图的编译与计算”，不能说“完整文献知识已经自动生成通用MAS安全网络”。
