# 知识模板驱动消息子图编译：从固定适配到可变工作流

日期：2026-09-20。主线位置：风险知识库 → 局部消息模板实例化 → 可学习事件/策略联合风险图。它不是新一轮提高准确率的结果，也不替代已冻结的模型。

## 1. 为什么先补这个环节

连续两轮任务语义扩展没有超过计数版。在固定AgentLeak流程里继续增加分类特征，不能完成“根据不同MAS工作流生成局部子图”的原始目标。本轮把消息事件创建从具体阶段名称中分离，接入已有可训练BN；保持知识来源、运行记录与概率假设的区别。

## 2. 编译输入与输出

输入均为显式材料：

- 工作流DAG及每个功能阶段的实际主体；主体可在多个阶段重复出现。
- 逐阶段模板选择、追踪信息集合及有出处的职责定义。
- 每条工作流边的传递说明，包括实际/预定传递、所追踪的信息项和依据；不从排列顺序猜边。
- 已完成消息的原文，或者明确记录“过去消息存在但正文缺失”。没有记录的节点视为未来，不能视为已观察到0。
- 可选的字段用途线索，每项绑定阶段、字段与初始材料；未提供即unknown，不能当授权。

输出为标准`ObservableEventDAG`以及编译清单。每个阶段的字段事件来自模板实例化，每条字段边只能连接同一信息；清单记录模板、知识来源、输入/原文摘要与生成图的绑定。该事件图交给现有消息BN后，由概率层创建整消息G和字段联合分布，可直接训练、推断及导出显式BN。

不是只有可视化图：链式和分叉汇聚构造流程均执行了联合推断，与独立显式图枚举一致；两种拓扑混合的8个构造流程可以共享参数拟合。构造标签只检验训练接口，不是安全检测成绩。

## 3. 知识模板现在覆盖到哪里

`configs/message_workflow_templates_v1.json`目前有五类：已配置资料源、准备消息、工作消息、审核消息、发布消息。知识引用解析到现有RB013/RB014及来源15/16。每个模板明确说明其消息事件含义，选择已有prepare/work/review/publish条件参数组；消息概率形式仍由BN指定。

这些文献支持跟踪信息流、接收方和用途的研究动机，不证明我们的逻辑回归条件函数，也不证明工作流边是因果边。

特别需要区分：

- 审核消息中出现某项内容，不代表审核通过。
- 内部处理需要某字段，不代表允许对外提供。
- 某条路线允许追踪某字段，不代表字段已实际出现。
- 空的字段传递集合表示该路线上没有声明的追踪依赖，不表示下游绝不会生成该字段。

本版仍是**同一种字面消息机制的多功能实例化**，不是五套已验证的异构风险机制。工具动作、共享授权、累计额度、禁止组合仍由既有策略组件处理；不把它们宣称为本轮已自动从任意职责说明生成。

## 4. 接入实际API记录

新增AgentLeak可选适配器`agentleak_message_compiler.compile_prefix`，只接收初始材料及已完成协调者/执行者调用的四个字段：调用ID、system prompt、user prompt、response。原始最终答复、风险标签、模型身份等不能作为这个入口的额外输入。

适配器核对真实输入与资料库、前序回复的对应关系。执行者可直接读资料库的通路继续保留。同一协调者的准备和发布仍是两个功能阶段，物理主体相同不产生DAG环。

编译时进一步发现旧路线依据是初始构建器说明，尽管已完成阶段的边标成了observed_delivery。新适配器把已完成阶段的实际API输入作为传递依据；未来阶段仍明确标记预定。时间使用已有功能阶段序号，不伪称测到了实际送达时间或历史在线提取延迟。旧图、哈希、预测和实验不改写。

## 5. 验证状态

26项专项测试通过，覆盖链/分叉、共享参数训练、原文与缺失状态、任务线索、实际输入绑定和原策略概率/梯度兼容性。初次专项运行3个断言因测试端使用错误的图输出键和list/tuple比较失败，修正测试后26项全部通过；没有通过放宽概率容差或更改模型来掩盖差异。

实际3159条既有开发流程、6318个前缀全部重建，比较291456个事件节点的定义、观测和父依赖，完全一致。路线证据更新291456项，因而新图/样本哈希有意改变；不会伪称旧、新输入字节相同。

预设选取每个任务模板按ID排序的第一条，共12条流程；两个时点、三种冻结BN共72组预测和全参数梯度对照，最大差均为0。其余流程只声称完整结构/观测核对，不声称全部重新算过概率。原权限证明和目标绑定保持不变。完整运行采用初始输入和已完成API调用，没有新API、拟合或旧测试集读取。

## 6. 仍然没有完成的范围

- 职责/工作流发现尚未由LLM或其他算法自动完成，编译器接收显式DAG；不叫任意MAS自动建图。
- 一阶段一条完整消息。多次回复、同阶段多人、循环，需要先形成明确的阶段/记录映射，不能盲目合并。
- 延续最多12功能节点、128事件和推断因子宽度限制；这不是大规模图推断方案。
- 不从原文自由发现敏感信息集合，不覆盖改写式泄漏；未知或省略的追踪对象不保证安全。
- 不推翻本轮语义模型未领先的结果，不根据看过的验证结果改阈值，也不新增MAS专用方法领先结论。
- 未完成全部知识模板、跨任务真实标签、原生MAS全面基线以及新的独立测试。

下一步应把这个入口用于不同真实工作流并补齐角色/传递提取与策略对象绑定，而不是继续把固定流程的特征数量当作框架贡献。
