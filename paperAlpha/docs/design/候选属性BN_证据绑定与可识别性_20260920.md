# 候选属性BN：证据绑定与可识别性

本轮继续“知识驱动图构建 → API Agent运行风险监测”，补上真实训练中发现的候选特征混同。不是更换研究对象，也不是宣布完成多风险、自动DAG或MAS全面领先。保留所有旧模型和冻结结果，不更换默认模型。

## 1. 实际结构升级

新增 `AttributeChoiceWorkflowRiskBN-v1`，继承既有互斥派发/共享授权/预算/禁止组合图，只替换选择概率的输入与条件函数。每个应用强制执行的采购槽位仍为“放弃或选一个”，不可能的多选状态概率严格为0；政策公式不参与学习。

此前均衡任务下两个候选都只有 `[1,0,0]`，无论如何训练也不能区分。新适配器只接收两名买方调用之前的前缀：原始规划回复、每名买方将收到的原始 assignment、候选动作和已有政策。报价必须逐项匹配候选SKU、金额、主体、资源、单次可见限额；属性记录保留来源、模型截止位置、记录摘要、目录路径及保修文字位置。

独立审查指出原先把准备态输入标为visible不准确。修正后记录明确为 `intended_recipient` 与 `delivery_status=prepared_for_next_call`，不声称截止前实际送达。**本轮预测以原样投递及合法命令协议完成为条件**；API失败、解析失败、审批拒绝和选择后取消未建模。日志复核证明完整样本中后来实际投递内容一致，不把后来投递事件倒灌为截止前的观测。

选择函数为标准属性条件logit：候选得分是系数与特征的内积，放弃为零基准，经softmax得到互斥选择概率。属性条件logit及最大似然是已有方法，参见[Berkeley SST 的离散选择与最大似然说明](https://eml.berkeley.edu/sst/max.like.html)。本项目新贡献不能是把它改名为BN，而应另证知识编译、关系组合和监测收益。

十个行为特征：执行偏置；经济/质量优先两项（均衡为基准）；报价除以买方可见单次额度；目录保修年数除以固定3年；保修未知标记；两种优先级分别与价格、保修的四个交互项。另保留3个共享授权先验，共13个参数位。

SKU、主体名称、领域ID、验证结局不作为数值特征。共同预算及当前撤销事实只进入政策层，不进入买方选择概率。不同槽位在已观察规划回复条件下仍独立；未来共享规划变量尚未加入。原始work_order的其他语义仍未利用。

保修量表示目录中的明确文字，不表示真实质量、有效法律保证或Agent内部认知。初次任意位置匹配和随后只匹配最后分句，都可能忽略前面的条件。最终版本只接受整段纯保修断言，或紧随与assignment.need绑定的两种原始目录固定前缀；其他前置文字一律unknown，并拒绝显式否定/条件/另购/可选、多个提及和不支持格式。`Coverage availability varies; three-year warranty.`、`Eligibility determines coverage; three-year warranty.` 均为unknown。**这是已知来源的受限语法，不是通用语义属性抽取器**；新来源应提供结构化属性或另建并验证语义抽取模块，不能沿用本解析器宣称广泛覆盖。来源摘要不是来源真实性证明。

输入还明确要求一名actor的一份目录恰好属于一个互斥槽位；禁止把同一目录拆成多个单候选独立组。未来若一名actor需要多次采购，必须新增按槽位绑定的证据契约，不能直接绕过此检查。可执行图同时带属性程序、参数快照摘要，并说明候选间的顺序CPT边只是分解顺序，不是时间或因果边。

## 3. 更重要的新证据：可区分不等于解释可信

训练的24个槽位全部购买，无放弃；经济优先8次选基础款，均衡/质量优先各8次选增强款。新特征没有同槽位完全相同的候选，但：

- 10列完整选择设计矩阵秩9，未知保修没有训练变化。
- 给定“已经决定购买”，只比较两候选的特征差，矩阵秩只有3。
- 每次增强款相对基础款都贵30元、保修都长2年；成本比例差为1/3，归一化保修差为2/3。

因此，把成本系数增加1、保修系数减少0.5，**给定购买时的两候选相对概率完全不变**；这个具体方向已数值核对，特征差乘积最大残差5.56e-17。放弃概率可能改变，不宣称完整联合分布也不变。

仅价格和仅保修在弱正则下都能拟合所有训练选择，也是同一问题的实证表现。模型不能据此解释“Agent看重保修而不是价格”。当前均衡成本系数甚至为正，更不能据此推论提高价格会使Agent更愿意购买。它们是相关目录上的条件预测，不是因果偏好发现。

这要求下一批数据将价格和保修信息拆开变化：同价不同保修、同保修不同价、低价长保修与高价短保修，且候选使用中性标签、位置做预定平衡；覆盖真实放弃行为和缺失属性。需在新采集前冻结模型/提示/划分，保留API真实选择和失败，不能用BN采样标签或挑选符合预期的回复。本轮尚未采集这一新队列。
