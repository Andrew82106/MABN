# 论文工作目录

本目录统一存放《情报杂志》项目的最终论文与可编辑图件。2026年9月30日已按用户要求清理历史 Word、PPT 及稿件预览。

## 最终文件

- [正式论文 Word](面向开源情报问答的大语言模型事实风险监测与定位研究（正式论文）.docx)，由 FRML 结语调整稿归位，包含已确认的全部修订。
- [图1可编辑 PPT](图1_FRML总体框架（可编辑）.pptx)，1页，文字、边框和线条均为原生可编辑对象。

## 配套材料

- [tmp](tmp/)保留图表源文件、生成脚本、实验分析与整理记录，也用于后续临时修改稿。
- [官方投稿模板](../reference_papers/journal_requirements/情报杂志官方投稿模板.docx)集中存入参考资料目录。
- [写作风格](WRITING_STYLE_CN.md)和[工作约定](AGENTS.md)适用于后续论文工作。
- `PAPER_HANDOFF.md` 与 `PAPER_WRITING_PROMPT_CN.md` 是早期交接材料，当前方法、数据与结果以正式论文为准。

正式论文后续仍由用户直接编辑，助手的修改建议另存于 `tmp/`。
