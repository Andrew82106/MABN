# 两篇方法论文全文核查笔记

核查日期：2026-10-09。只读论文，不改论文正式稿。页码均为 PDF 文件页序；第一篇含网络首发封面，PDF 第2页对应正文第1页；第二篇 PDF 第1页对应期刊第91页。

两篇均已阅读全文及参考文献；第一篇重点视觉核对第5—9页，第二篇重点视觉核对第5、7、11页。以下严格区分原文事实与针对 FRML 的判断。

## 一、基于多智能体的生成式科技情报幻觉信息检测研究（武朋等）

来源：同目录《基于多智能体的生成式科技情报幻觉信息检测研究_武朋.pdf》，共10页，《情报杂志》2026-08-04网络首发。

### 1. 怎样扣住科技情报

- 研究对象明确为大模型生成的科技情报分析报告，而非任意聊天回答。报告围绕特定主题搜集资料，产出研判性结论，其特点是“论点—论据”结构。（PDF第3页）
- 将情报价值定位于技术趋势、潜在威胁、战略动向的推理分析；因此真实性检查不足以覆盖引用真实却曲解语境、论据不能支持论点的问题。（第3—4页）
- 图2的示例是特朗普2.0背景下美国国防采办政策的研判，抽取论点、三条支撑论据，再把论据拆为可核查事实。该图体现具体情报工作对象，但不能据此断言整个数据集均属国防科技。（第5页）

### 2. 数据是什么，怎样构造

- 基础语料：搜集科技领域新闻资讯、研究报告等多源非结构化文档；经过清洗、去重、语言识别、元数据标注，形成300余篇、150余万字的科技语料库。（第7页）
- 评估报告：用 DeepSeek-V3.2、Qwen-Max 等生成30余份结构化分析报告，要求具有明确论点及支撑论据。人工核查自然生成的事实一致性、语义一致性幻觉，并人工撰写部分幻觉内容。（第7页）
- 逐句标注：论点与论据的结构解构、事实一致性幻觉、语义一致性幻觉。后者含“意图与语义曲解”“过度推断”“论证结构”三类。（第7页表2）
- 表3报告总计900条：论点200、论据700；幻觉500（论点100、论据400）；事实幻觉200（40、160）；语义幻觉300（60、240）。正文说两种幻觉没有交集。表述中的“余条”与表内整数并存，引用时保留其统计口径。（第8页）
- 未披露具体来源名单、全部主题分布、数据公开地址、标注员人数及一致性、人工注入比例、训练验证测试划分。文中列出的 DeepSeek/Qwen 是报告生成工具，不能据此确认检测端模型版本。（第7—9页及全文核查）

### 3. 算法和评测粒度

- 输入生成报告，先抽取主观论点及关联客观论据，再把论据拆成原子事实；同时保留论点—论据关系。（第5页）
- 证据轨：多源检索定位新闻、政策、研究报告原始出处；把原子事实改写成问答对，从原始资料抽取答案作一致性核查。（第5—6页）
- 语义轨：检查原文的语义角色、逻辑指向和信息权重。假设、反例、传闻、次要背景若被改成确定性的核心支持，可能构成幻觉。（第6页及表1）
- 决策：证据核查、语义解析、逻辑评估分工；另设支持方与反对方辩论，由裁判整合。（第6—7页）
- 数据标注为句级论点/论据，报告样本级 Accuracy、Precision、Recall、F1；检测内部使用原子事实及结构单元，没有 token 跨度定位指标。（第5、7—8页）
- 基线：单次检索增强判断、SelfCheckGPT、FactScore。主表事实/语义 F1 为0.783/0.750；FactScore为0.696/0.469。（第8页表4）
- 消融：论点—论据结构对事实类收益不明显，语义类召回率从0.610升至0.743；去掉语义核查，语义F1从0.750降至0.509；多智能体辩论优于分组讨论，最终最高为0.806/0.775。（第9页图6、表5、表6）

### 4. 对 FRML 的启示（对照判断）

- 可借鉴的是“情报工作对象→错误类型→具体核查任务→资料与报告评估”的完整对应关系，不只是标题引言换成科技情报。
- FRML已有D/Q/A、白盒信号、ModernBERT资料对照及4-token窗口融合，主要支撑资料忠实性和错误片段定位；本篇强调原出处检索、语境角色及论据对论点的支撑，二者不是同一任务。
- FRML可定位“情报生成中的证据忠实性核查”或“资料依托内容的细粒度风险识别”；没有相应实验时，不应扩大到完整论证有效性、决策可靠性或外部世界事实真伪。
- 本篇支持补充科技资料和生成报告的场景评估，不能证明现有英语Wikipedia数据本身已经代表科技情报任务。其数据披露不足也不宜照搬。

## 二、基于混合检索增强生成大语言模型的网络舆情多任务分析（王润周等）

来源：同目录《基于混合检索增强生成大语言模型的网络舆情多任务分析_王润周.pdf》，共13页，《情报杂志》2025年第44卷第5期，第91—103页，DOI 10.3969/j.issn.1002-1965.2025.05.012。

### 1. 通用公开数据是否出现于已发表论文

是。该文明确使用英语影评IMDB及酒店、网购、外卖评论等通用公开数据，将情感分类对应为公众情绪识别。同时使用虚假新闻数据及突发事件关系抽取数据。它还加入真实舆情事件新闻构成的自建资料与问答，因此属于“公开基准＋场景资料”组合，不能表述为“只用通用数据也已证明足够”。（PDF第5—6、9、11页）

### 3. 方法与场景怎样对应

- 动机：舆情变化快、模型知识滞后导致错误；逐领域微调又成本高。方法是检索领域资料，同时融合多轮问答历史与少量任务演示。（第2—5页）
- 文档转文本、清洗；350字固定切块并设置重叠；m3e-base编码，Faiss索引，余弦相似度取Top-k；将检索内容、上下文、演示组成提示输入LLM。（第3—5页）
- 此处“混合”指检索内容、上下文信息、提示样例的结合；文内不是以稀疏检索＋稠密检索混合为核心。（第4—5页）
- 五个任务明确给出舆情作用：过滤虚假新闻、形成事件总结、回答事件查询、抽取事件关系、分析公众情绪。图3给出各任务输入输出样例，将一般NLP任务接回舆情业务。（第5页表1、第7页图3）
- 假新闻检索库由文本与标注标签拼接；情感分析也按任务构建带情感标签的本地向量库。全文没有明确交代检索库与测试集如何隔离，不能确认是否存在标签泄漏，也不能把它当作排除泄漏的规范范例。（第7、11页）

### 4. 基线、指标与结果

- 基线为微调BERT/RoBERTa、Llama3、ChatGLM-4、GPT-4，及各LLM加混合RAG；BERT/RoBERTa不用于报告生成和问答。（第6—7页）
- 分类/抽取用Accuracy、Precision、Recall、F1。报告考查生成时间、长度、GPT-4与硕博人工评审质量均值、专家审查有害性。问答列准确率及满意度，但结果表7主要列答对数量和准确率。（第6—7、9页）
- RAG-GPT4假新闻平均F1为0.831（GPT4为0.808）；情感分类为0.909（GPT4为0.881）；信息抽取0-shot F1为0.918，3-shot为0.954。（第7、9、11页）
- 情感消融移除演示，平均F1从0.909降为0.889；去上下文为0.903。提示数量0—3的实验表明匹配任务类型的示例有益，但错配类型可能使性能下降。（第8、10—11页）
- 自建问答表7标RAG-GPT4准确率0.941，同时列564/600；两者不完全对应（564/600=0.940）。不宜在自己的报告中直接采用该表推导更精细结论。（第9页）
- 结语称生成速度也优于基准，但表6中RAG三模型时间均增加，例如GPT4由14.6秒到18.3秒；正文表6解释为以速度换质量。引用应采用表格及相应正文，不复述结语这一过度概括。（第9、12页）
- 论文多以任务准确率提升说明减少“幻觉”，未建立与FRML相同的幻觉片段标注或token级定位评估；虚假新闻分类尤其不等于生成模型的资料忠实性检测。（第7—12页）

### 5. 对 FRML 写法的启示（对照判断）

- 已发表先例说明期刊并未排斥英文、通用或公开NLP数据；领域契合可以来自清楚的工作任务映射，而非所有训练数据必须属于情报领域。
- 但本篇有80余篇真实事件资料与600道问答，提供了通用基准之外的场景抓手。不能据此推出FRML只把RAGognize/Wikipedia重命名为情报数据就充分。
- FRML可以保留通用基准作为方法有效性证据，再用少量可核查的情报资料/生成结果展示风险定位与资料对照流程；应明确这是场景补充验证，不把小案例包装成领域全面泛化证据。
- 与上一篇合看：可选窄而真实的定位是“面向情报资料问答或报告生成的证据忠实性检测”。这与D/Q/A及细粒度定位直接一致，也避免未经验证地承诺多任务舆情治理或完整研判逻辑核查。
