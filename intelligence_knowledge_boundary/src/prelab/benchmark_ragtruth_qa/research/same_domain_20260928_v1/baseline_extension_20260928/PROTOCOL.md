# 六种基线追加评测

用户于 2026-09-28 授权：适配并运行 Lookback Lens、RAGognizer、ReDeEP、LUMINA、LettuceDetect、MiniCheck，汇报回答检测及局部定位结果。

## 固定数据与比较对象

- 沿用父目录已冻结的 RAGognize 来源组划分：fit 1292、validation 271、test 279。主评测为 no_hint validation 135 / test 155；全部样本另报。
- 输入为原问题、检索资料和原始 Llama 回答；本轮不重新生成回答、不修改标注。
- 我们的方法沿用已冻结的 HGB 主模型，不根据新增基线成绩重新选模型。
- Lookback 默认版与调参版属于同一基线；主比较采用之前验证选定的调参版，默认版保留作补充。RAGognizer 沿用本轮已完成的同域 NF4 训练。复用冻结预测须先核对来源和哈希，再重新评分，不重新随机训练已有模型。

## 新增四种方法

1. ReDeEP(Token)：复用已审计的论文公式迁移实现。头/层选择和归一化只拟合 fit；保留原 token 风险公式。实现身份、参数、精度和源码差异由 whitebox/ 记录。
2. LUMINA：作者默认公式和权重，替换资料来自 fit 的固定随机抽样，不读取供体标签。无需训练分类器，只推理 validation/test 并校准阈值。
3. LettuceDetect：锁定官方 v1 实现，从通用 ModernBERT-large 初始化，使用当前 fit 的风险范围训练；遵守原模型、输入组织、损失。训练配置在运行前落盘，检查点只由 validation 选择。
4. MiniCheck：官方 MiniCheck-Flan-T5-Large 公开权重固定推理，使用官方资料分块、句子核查。风险为 1−支持概率；原生句分数通过文本偏移映射到 Llama 词元。它属于公开模型迁移，不伪称已在本轮 fit 重训，也不把句分数映射描述为原生逐词元检测。

## 共同评分

所有新方法提交每条回答的完整 token_scores，与父目录 data 中的原 Llama BPE 坐标逐个对应；高分代表风险。保留原生分数和转换记录。

复用父目录 metrics.py：4 BPE、步长 1、排除全非字母数字窗口；任一有效风险词元落入窗口即为正例。每个基线的 mean4 与 lexical max4 两种适配只在 validation no_hint 比较，按既有 selection_key 选定，并列选 mean。回答风险为最高窗口分数；回答和窗口阈值分别由验证 F1 选择，并列按精确率、高阈值排序。

在接触新方法测试成绩前保存验证选择与预测文件哈希。当前测试标签已经揭晓，因此本轮属于固定测试集上的追加比较，不称为新的盲测。完整保留所有方法的实际分数。
