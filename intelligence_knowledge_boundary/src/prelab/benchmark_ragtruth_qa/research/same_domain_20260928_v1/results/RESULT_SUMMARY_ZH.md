# 同数据训练与测试：算法优化结果

2026-09-28。本轮主方法在预先规定的主测试中，两项 F1 均高于所测基线；尚不能据此宣称稳定的 SOTA。

## 数据与比较方式

使用 RAGognize 官方训练部分的 1842 条原始 Llama-2-7B-chat 回答，按来源分组重新划为训练 1292、验证 271、测试 279。所有方法共用这一划分；训练与测试样本不重叠。同一目标资料合并分组后再划分。

主测试使用原始提示中没有“资料不足”暗示的 155 条回答，来自 75 个来源组。其余样本纳入完整测试的补充结果。标签来自数据集发布的自动标注。

全部模型、阈值和预测先固定，再统一打开测试标签评分。主方法由验证结果选定，测试后未更换。

## 算法改了什么

1. **资料对照分支**：训练 ModernBERT，联合阅读资料、问题和回答，判断回答内容是否得到资料支持；比较 base 与 large 两种容量。
2. **白盒分支**：从冻结的 Llama 提取注意力、词元概率及内部激活，训练局部风险探针。
3. **学习融合**：加入词语、短语及数字是否出现在资料中的辅助特征，学习两个分支如何配合。融合训练使用三折按来源分组的折外预测，避免直接使用分支已经记住的训练答案分数。
4. **比较融合结构**：保留直接平均、线性融合和四档小规模非线性融合。最终按验证集选中 17 个输入特征的非线性窗口融合，名称为 `Fusion-window-HGB`。

定位单位为连续 4 个原始词元，步长为 1；窗口覆盖有效风险标注即视为正例。回答风险分数取各窗口分数的最大值，回答和窗口的判定阈值分别在验证集确定。这里评测的是完整回答生成后的分析。

## 主测试成绩

下表为风险类别的 F1，不是准确率，也不是验证分数。

| 方法 | 回答 F1 | 4词元窗口 F1 |
|---|---:|---:|
| Lookback 原默认参数 | 0.6849 | 0.5027 |
| Lookback 验证集调参 | 0.7297 | 0.5216 |
| RAGognizer 同域重训 | 0.8000 | 0.6240 |
| 仅资料对照 large | 0.8140 | 0.6293 |
| 仅白盒探针 | 0.7374 | 0.5362 |
| 线性词元融合 | 0.8402 | 0.6439 |
| 线性窗口融合 | 0.8362 | 0.6431 |
| **主方法：非线性窗口融合** | **0.8439** | **0.6458** |

共评测 12 个方法，完整精确率、召回率及其余对照见 `TEST_RESULTS.md`，完整两组测试结果见 `TEST_RESULTS.json`。

与最强外部基线 RAGognizer 相比，主方法的回答 F1 高 4.39 个百分点，窗口 F1 高 2.18 个百分点。按来源组配对重采样 2000 次，95% 差值区间分别为 [-1.21, 11.07]、[-3.22, 7.73] 个百分点，均包含零。因此可以写“本轮比较分数最高”，还不能写“稳定显著优于最强基线”。相对调参后的 Lookback，两项差值区间均大于零。

## 这轮说明了什么

- **资料对照是主要增益来源**：large 分支明显好于仅白盒探针。增加白盒信息后的学习融合又有小幅提升，直接平均则没有提升。
- **复杂融合收益很小**：非线性主方法比线性词元融合仅高 0.37 个回答 F1 百分点、0.19 个窗口 F1 百分点。完整 279 条补充测试中，非线性为 0.8247/0.6613，线性词元融合为 0.8267/0.6614，非线性并非处处更好。
- **定位尚未达到 0.7**：主方法验证分数是 0.9080/0.7575，主测试为 0.8439/0.6458，仍存在泛化差距。

RAGognizer 保留其 LoRA 与检测头结构，从通用基座重新训练五轮；受本机显存限制使用 NF4 基座，并采用连续五轮学习率调度，不能称为作者原精度与原训练运行的完全复现。已发布检测器权重见过这批官方训练样本，因此未用于本次同划分比较。

这是一轮已知官方训练数据的内部划分实验。下一步应优先增加独立来源的人工复核测试数据，检查资料对照分支的错误类型；不宜继续依据本次测试分数调参数。正式论文未修改。
