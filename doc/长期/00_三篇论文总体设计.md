# 多智能体风险传播研究：三篇论文总体设计

> 当前版本：研究规划稿 v0.2  
> 总体主线：**事实 → 信念 → 行动**  
> 总体目标：形成三篇问题独立、方法独立、实验闭环独立，但共享同一研究基础设施的论文。  
> 论文一详细方案：[因果测量与预实验设计](./01_论文一_因果测量与预实验设计.md)

## 0. 总体决策

整个研究计划拆为三个递进问题：

1. **事实层：风险是否真的沿协作关系传播？**
2. **信念层：日志不完整且带噪时，系统当前可能处于什么状态？**
3. **行动层：面对这种不确定性，下一步应该观察还是干预？**

对应三篇论文：

| 论文 | 核心问题 | 主要产出 | 贝叶斯的主要角色 |
|---|---|---|---|
| 论文一：因果测量 | 风险是否真的沿某条边传播？ | 随机门控协议、因果传播数据和结构规律 | 分层因果效应估计 |
| 论文二：传播重建 | 谁受到影响、来源和路径是什么？ | 状态、源、边、路径和未来危害后验 | 潜变量推断与不确定性量化 |
| 论文三：防控决策 | 应该先检查还是立即控制？ | 预算约束的观察—干预策略 | 贝叶斯决策与信息价值 |

三篇共享同一个多智能体安全沙箱、日志规范和危害定义，但必须使用不同的确认性假设、主要指标和留出测试集。

## 1. 共同研究基础

### 1.1 共同的总问题

一个由多个 AI Agent 组成的团队中，错误或恶意信息可能经由消息、委派、共享记忆和工具调用逐步扩散。系统只能观察不完整且可能误判的日志，同时防御预算有限。

本研究区分四类对象：

1. **设计通信图**：系统允许哪些 Agent 相互通信；
2. **实际交互图**：实际发生了哪些消息、委派、记忆写入和工具调用；
3. **潜在影响图**：哪些上游输入真正改变了下游 Agent 的判断或行为；
4. **危害执行图**：哪些影响最终进入秘密泄漏或未授权操作的执行链。

核心原则是：

> 通信图不等于潜在影响图，潜在影响图也不等于最终危害执行图。

### 1.2 共享实验平台

三篇论文共享以下基础设施：

- 8–32 个具有不同角色、社群和权限的 LLM Agent；
- 消息、委派、共享记忆和工具调用四类通道；
- Canary secret、mock 数据库、受限文件和 mock API；
- 可回滚、无真实外部副作用的沙箱；
- 可复现的任务、拓扑、攻击、模型和采样随机种子；
- 统一的事件级日志与策略执行记录；
- 统一的安全、任务效用、token、延迟和干预成本定义。

共享基础设施不等于共享确认性数据。每篇论文必须预先冻结自己的训练集、开发集和确认性测试集。

### 1.3 共同状态语言

传播重建和决策阶段使用四种潜在状态：

\[
S\;(\text{安全})
\rightarrow
E\;(\text{已暴露})
\rightarrow
A\;(\text{已采纳且具传播能力})
\rightarrow
C\;(\text{已受控}).
\]

其中：

- “隔离、撤权、切边和回滚”是动作；
- “已受控”是动作产生的潜在状态；
- “恢复”是受控后的后续过程。

## 2. 论文一：多智能体风险传播的因果测量

### 2.1 暂定题目

**中文**

> 通信不等于影响：LLM 多智能体系统中不安全行为传播的因果测量

**英文**

> Communication Is Not Influence: Causal Measurement of Unsafe Cascades in LLM Multi-Agent Systems

### 2.2 一句话卖点

> 发生过通信不能证明产生了影响；本文通过随机消息门控和图结构随机化，测量哪些交互真正导致了下游采纳、跨社群扩散和可验证危害。

### 2.3 核心研究问题

**RQ1.1**

通信图在多大程度上高估、遗漏或错误定位真实风险传播关系？

**RQ1.2**

删除或安全替代一条候选消息后，下游采纳、继续传播和真实危害是否下降？

**RQ1.3：次要机制问题**

跨社群桥接位置与高权限是否产生超过二者单独作用的风险放大？

**RQ1.4**

这种因果效应是否随任务、模型、传播通道和社群混合度而变化？

### 2.4 核心方法

#### 随机消息门控

对候选传播边随机分配：

1. 原始消息；
2. 删除消息；
3. 语义和任务信息量尽量匹配的安全替代消息。

删除组用于估计该通信是否必要；安全替代组用于区分“风险内容被移除”和“任务信息整体被移除”。

#### 配对反事实重放

同一任务条件尽量保持：

- 图结构；
- Agent 角色和模型；
- 初始上下文；
- 温度与采样种子；
- token 和轮次预算；
- 风险入口；
- 除目标消息以外的环境状态。

#### 次要扩展：桥接位置 × 权限的 2×2 随机实验

该实验不与随机消息门控并列为论文一的第一主假设。论文一首先验证“安全替换能否识别危险内容对下游危害的因果总效应，同时保留正常任务能力”。只有该主效应通过预实验，且预算允许时，才将桥接与权限作为预注册的次要效应修饰；如需升格为确认性主问题，应另行开展完整的析因实验。

| 条件 | 桥接位置 | 权限 |
|---|---|---|
| 00 | 非桥接 | 低权限 |
| 01 | 非桥接 | 高权限 |
| 10 | 跨社群桥接 | 低权限 |
| 11 | 跨社群桥接 | 高权限 |

桥接位置通过度保持或近似度保持重连产生；权限在角色兼容的候选 Agent 间随机分配。

主要交互 estimand 为：

\[
\tau_{B\times P}
=
E\left[
Y(1,1)-Y(1,0)-Y(0,1)+Y(0,0)
\right],
\]

其中 \(Y\) 是秘密泄漏、未授权操作、跨社群传播或级联规模。

### 2.5 贝叶斯在本篇中的作用

本篇采用层次贝叶斯因果模型：

- 估计风险差、风险比和交互效应的后验；
- 对任务、模型、图结构和风险入口进行部分汇聚；
- 描述效应异质性；
- 在稀有危害条件下稳定估计不确定性。

必须明确：

> 因果识别主要来自随机化设计；贝叶斯方法负责估计效应和量化不确定性，不能代替随机干预。

### 2.6 实验闭环

论文一的执行结构冻结为：

1. P0 工程准入：只验证权限、日志、状态隔离和重放，不作为论文因果证据；
2. P1–P4 串行准入：依次验证良性任务、风险强度、路径排他性和安全替换等价性；
3. P5–P7 Pilot：完成焦点消息三条件实验、无关边负对照和最小外部复核；
4. M1 确认性三条件实验：同时回答危险内容的因果效应与安全收益是否来自任务停摆；
5. M2 多边影响图实验：对预注册通信边逐边干预，比较通信图与危害影响图；
6. M3 泛化实验：依次扩展任务、模型、风险表达、图结构和至少一种不同危害类型；
7. P8 桥接位置 × 权限只作为可选机制分支，不占用核心主线的准入预算。

P1–P4 是硬门槛：上一项未经验收通过，不派发下一项。Pilot 数据只用于校准和
Go/No-Go，不与确认性主实验数据合并。

#### 当前执行状态（2026-08-01）

P0 已完成。冻结的 P1 来源批次 `P1-BENIGN-PILOT-QWEN3-20260731T132033188154Z`
在主 Agent 验收后**未通过 P1 gate**：虽然良性任务和泄漏终点达到相应数值门槛，但
出现 1 次解析失败、179/180 结构化输出，且源 validation 未通过。因此 `p1_go=false`，
它不能作为进入 P2 的依据；P2 及后续阶段继续锁定。此处的 No-Go 仅指“不得以该冻结
批次进入下游”，不表示论文一、良性任务能力或不安全传播命题被否定。后续若继续，只能
先获批独立的新 P1 设计，不能重跑或改写该来源批次。完整证据和边界见
[论文一 P1 路线状态记录](./01_论文一_因果测量与预实验设计.md)。

主要场景：

- Canary secret 泄漏；
- 未授权 mock 数据库写入；
- 受限文件访问或修改；
- 违规 mock API 或工具调用。

主要终点：

- 下游 Agent 是否采纳风险信息；
- 是否继续向邻居传播；
- 是否跨越社群边界；
- 是否产生可验证危害；
- 正常任务成功率是否下降。

LLM Judge 和检测器只作为带误差的测量工具，不作为真实危害的唯一判定者。

### 2.7 主要贡献

1. 提出区分通信图、潜在影响图和危害执行图的实验问题；
2. 建立随机消息门控和安全替代重放协议；
3. 将桥接位置与权限作为预注册的次要效应修饰，并为后续确认性析因实验提供依据；
4. 形成可复用的多智能体风险传播数据和实验基准；
5. 总结风险传播的结构性规律及其适用范围。

### 2.8 明确边界

本篇不把以下内容作为主要贡献：

- 完整潜在状态和传播路径后验；
- 贝叶斯传播源定位；
- EVSI 或自适应防御策略；
- 动态社群发现；
- 仅由文本相似性得到的“因果边”。

### 2.9 Go/No-Go 标准

满足以下至少一项时，本篇适合独立投稿：

- 通信图和随机干预识别出的影响图存在稳定、可重复的差异；
- 安全替代对真实危害产生具有实际意义的稳定效应；
- 桥接位置 × 权限存在跨场景复现的交互效应；
- 数据集和随机化协议本身具有明显的复用价值。

若桥接 × 权限效应不稳定：

- 不事后寻找显著子组；
- 将该结果作为有价值的零结果；
- 主线退回“通信不等于影响”和随机门控基准；
- 若整体因果结果过弱，则将本篇并入论文二，作为外部验证模块。

### 2.10 可能的投稿气质

- NLP/Agent 安全：ACL、EMNLP、NAACL；
- 安全威胁模型和实验系统足够扎实时：USENIX Security、CCS、NDSS；
- 多智能体与机制实验：AAMAS、AAAI、IJCAI。

## 3. 论文二：部分观测下的贝叶斯传播重建

### 3.1 暂定题目

**中文**

> 部分可观测多智能体系统中的贝叶斯风险传播重建

**英文**

> BayesTrace: Bayesian Reconstruction of Latent Risk Propagation from Partial and Noisy Multi-Agent Logs

### 3.2 一句话卖点

> 从带噪、缺失的日志中恢复谁真正受到影响、风险从哪里来、经过哪些路径，并给出校准的未来危害概率。

### 3.3 核心研究问题

**RQ2.1**

日志部分缺失、检测器存在误报漏报时，能否恢复 Agent 的潜在风险状态？

**RQ2.2**

能否联合推断传播源、父传播边和路径可信集？

**RQ2.3**

角色、社群、消息类型和权限的层次结构能否改善小样本及跨任务泛化？

**RQ2.4**

后验概率能否保持校准，并对未来真实危害提供有效预测？

### 3.4 核心方法

建立多层时序贝叶斯传播模型：

- 节点：Agent；
- 图层：消息、委派、共享记忆、工具调用；
- 潜在状态：\(S,E,A,C\)；
- 潜在变量：风险源、暴露时刻、采纳状态、父传播边和传播路径；
- 协变量：模型、角色、社群、权限、桥接位置、内容风险和动作历史；
- 观测模型：日志缺失、检测器灵敏度、特异度和 LLM Judge 误差；
- 层次先验：任务、模型、角色和社群的部分汇聚。

主要输出：

- \(P(X_{it}=x\mid D)\)：节点状态后验；
- \(P(s=i\mid D)\)：传播源后验；
- \(P(z_{ji,t}=1\mid D)\)：边级传播后验；
- 路径可信集；
- \(P(H_{t:t+k}=1\mid D)\)：未来危害概率。

### 3.5 实验闭环

#### 有真值模拟

在 SBM/DC-SBM 图上系统改变：

- 节点数和社群数；
- 社群混合度；
- 单源与多源传播；
- 日志缺失比例；
- 检测器误差；
- 模型错设；
- 角色和权限异质性。

主要检查：

- simulation-based calibration；
- 参数恢复；
- 可信区间覆盖；
- 状态和源识别；
- 路径恢复；
- 预测校准；
- 计算扩展性。

#### 真实 Agent 外部验证

- 使用论文一的部分随机门控数据作为因果锚点；
- 预留未参与建模的任务、模型家族和图结构；
- 用沙箱中的真实违规动作锚定最终危害；
- 不使用模型自身生成的潜在状态预测验证模型自身。

### 3.6 基线

- 固定阈值；
- Degree、PageRank、Betweenness；
- HMM 或不含层次结构的动态贝叶斯网络；
- 独立级联、Hawkes 或传统传播模型；
- 非贝叶斯 MLE；
- GNN 或时序图异常检测；
- 只输出点估计的传播模型。

### 3.7 主要指标

- Brier score；
- log score；
- expected calibration error；
- 可信区间覆盖；
- 传播源 Top-\(k\) 与可信集大小；
- 节点状态 F1/AUPRC；
- 传播边 AUPRC；
- 路径覆盖；
- 未来危害预测校准。

### 3.8 主要贡献

1. 将多智能体风险传播表述为部分可观测的潜变量问题；
2. 显式建模日志和检测器误差；
3. 联合推断传播源、节点状态、父传播边和未来危害；
4. 利用角色、社群、权限和图层进行层次化部分汇聚；
5. 提供完整后验及其校准检验，而非单一异常分数。

### 3.9 明确边界

本篇：

- 固定或预先指定社群结构；
- 不同时推断动态 SBM；
- 不把后验传播边直接称为因果边；
- 不求解完整防御 POMDP；
- 最多使用简单阈值策略展示预测的下游价值；
- 不以危害减少量作为主要方法指标。

### 3.10 Go/No-Go 标准

适合独立投稿需要满足：

- 在模拟阶段通过基本 SBC 和覆盖检查；
- 在高缺失或高噪声条件下明显优于点估计和异常检测基线；
- 在真实 Agent 留出集上保持合理校准；
- 至少能稳定恢复“状态、传播源、边/路径、未来危害”中的两个以上核心对象。

若完整路径不可辨识：

- 输出路径后验集合，不声称唯一真路径；
- 将边际传播概率作为主要结果。

若参数无法稳定恢复：

- 聚焦状态、来源和未来危害预测；
- 缩小模型规模或减少层次；
- 通过模型错设实验明确适用边界。

### 3.11 可能的投稿气质

- 贝叶斯与不确定性方法较强：UAI、AISTATS；
- 算法和理论贡献足够强：ICML、NeurIPS；
- LLM 多智能体实验是主要贡献：ACL、EMNLP、AAAI。

## 4. 论文三：有限预算下的贝叶斯观察—干预决策

### 4.1 暂定题目

**中文**

> 先检查还是先隔离？多智能体风险级联的预算约束贝叶斯防御

**英文**

> Observe or Intervene? Budgeted Bayesian Defense for Multi-Agent Risk Cascades

### 4.2 一句话卖点

> 防御的关键不是找出风险分数最高的节点，而是判断下一单位资源应该用来减少不确定性，还是立即阻断风险。

### 4.3 核心研究问题

**RQ3.1**

什么条件下应该先调查，什么条件下应该立即隔离、切边或撤权？

**RQ3.2**

在相同预算下，完整后验是否比点估计和中心性排序产生更好的安全—效用权衡？

**RQ3.3**

哪些 Agent、消息或工具调用具有最高的决策信息价值？

**RQ3.4**

策略对后验失准、模型错设和环境变化是否鲁棒？

### 4.4 信念状态接口

论文三把风险信念写成统一接口：

\[
b_t
=
\left\{
P(X_{it}\mid D_t),
P(z_{ji,t}\mid D_t),
P(H_{t:T}\mid D_t)
\right\}.
\]

论文二的后验是主要输入之一，但不是唯一输入。实验还必须使用：

- Oracle belief；
- 校准但较弱的风险模型；
- 只使用后验均值的模型；
- 故意失准或模型错设的 belief。

这样可以区分收益来自“推断器更准确”还是“策略本身更合理”。

### 4.5 动作集合

#### 观察动作

- 获取更完整的日志；
- 重复检测某条消息；
- 调用独立 verifier；
- 审查 Agent 的上下文或共享记忆；
- 在沙箱中重放候选输入。

#### 干预动作

- 降低消息信任权重；
- 延迟或阻断消息；
- 阻止共享记忆写入；
- 暂停一条边；
- 隔离 Agent；
- 撤销工具或外发权限；
- 要求双重授权；
- 回滚记忆或环境状态。

### 4.6 决策目标

综合损失包括：

\[
L(a)
=
\lambda_H H(a)
+\lambda_U[1-U(a)]
+\lambda_C C(a).
\]

确认性比较优先使用约束形式：

\[
\min_{\pi} E[H(\pi)\mid D]
\]

满足：

\[
P\left(
U(\pi)\ge U(\text{无防御})-\epsilon_U
\mid D
\right)\ge 0.95,
\qquad
C(\pi)\le B.
\]

同时报告完整的 harm–utility–cost Pareto 前沿，避免结论只在某组主观权重下成立。

### 4.7 方法贡献要求

一步 EVSI 可以作为原型，但不足以自动构成独立论文。论文三至少需要形成一项独立算法贡献：

- 图结构上的可扩展 EVSI 近似；
- 观察与干预的联合预算分配；
- 风险约束的 1–3 步 receding-horizon rollout；
- 利用社群或条件独立性的动作剪枝；
- 对策略 regret、近似误差或适用条件的理论分析；
- 关于“何时观察优于立即干预”的结构性判据。

### 4.8 实验闭环

系统改变：

- 防御预算；
- 日志缺失和检测噪声；
- 危害概率和严重度；
- 误隔离成本；
- 任务中断成本；
- 社群混合度；
- 高权限节点分布；
- belief 的校准程度。

主要基线：

- 不防御；
- 随机动作；
- Degree/PageRank/Betweenness 优先；
- 后验风险最高优先；
- 最大熵节点优先调查；
- 固定安全阈值；
- posterior-mean greedy；
- 只干预、不观察；
- 只观察、不干预；
- 知道真实状态的 Oracle。

主要指标：

- 最终危害率；
- 级联规模；
- 遏制时间；
- 正常任务成功率；
- token、延迟和审查成本；
- 错误隔离数量；
- 相对 Oracle 的策略 regret；
- 安全—效用—成本 Pareto 前沿。

### 4.9 主要贡献

1. 将传播后验转化为可执行的风险管理动作；
2. 在一个框架中比较购买信息和直接干预；
3. 在预算和任务效用约束下分配防御资源；
4. 证明概率校准能否带来实际决策收益；
5. 给出策略对 belief 错设和环境变化的鲁棒性分析。

### 4.10 明确边界

本篇：

- 不重新提出传播模型；
- 不重新声称发现因果传播边；
- 不同时优化推断器和策略的确认性参数；
- 不声称求得一般 POMDP 的全局最优解；
- 不把后验风险约束称为形式化安全保证。

### 4.11 Go/No-Go 标准

只有满足以下条件，论文三才独立投稿：

- 方法明显超出教科书式一步 EVSI；
- 在相同预算下优于风险最高优先和 posterior-mean greedy；
- 优势在不同 belief 输入下仍然存在；
- 正常任务性能满足预注册非劣约束；
- 能解释何时观察有效、何时应立即干预。

若 EVSI 基本不优于简单风险排序：

- 给出“观察有价值的条件图谱”，而不宣称普遍优势；
- 缩短为一步或两步策略；
- 若仍无独立算法贡献，将决策部分并入论文二，不单独投稿。

### 4.12 可能的投稿气质

- 多智能体决策：AAMAS；
- 不确定性和决策：UAI；
- 通用算法贡献足够强：AAAI、IJCAI、ICML、NeurIPS；
- 以安全系统和部署策略为主：安全或可信 AI 相关会议。

## 5. 三篇之间的贡献防火墙

| 内容 | 论文一：事实 | 论文二：信念 | 论文三：行动 |
|---|---|---|---|
| 随机消息门控 | 核心方法 | 外部验证工具 | 环境中已知的可用动作 |
| 桥接 × 权限 | 核心因果问题 | 模型协变量 | 决策情景变量 |
| 潜在状态后验 | 不作为主要结果 | 核心贡献 | 冻结的 belief 输入 |
| 传播源和路径 | 只报告干预证据 | 核心贡献 | 不重新声称模型创新 |
| EVSI/rollout | 不出现 | 最多简单示例 | 核心方法 |
| 可验证沙箱危害 | 因果终点 | 外部验证锚点 | 决策终点 |
| LLM Judge | 带误差的测量工具 | 观测模型 | 可购买的信息源 |
| 主要指标 | 因果效应与真实危害 | 校准与真值恢复 | 危害—效用—成本 |

### 5.1 禁止出现的拆稿方式

以下做法容易被认为是 salami slicing：

- 三篇都使用同一批 episode，只更换评价指标；
- 三篇都把“贝叶斯传播模型”列为主要贡献；
- 将论文二的后验边直接包装成论文一的因果边；
- 论文三只在论文二模型上运行，并把收益全部归因于新策略；
- 把一篇完整方法的消融实验单独包装成另一篇论文；
- 在看到主结果以后再决定每篇论文的主假设。

## 7. 推荐执行顺序

### 阶段 A：共享平台与 Pilot

目标：

- 完成最小沙箱的 P0 工程准入；
- 按 P1→P2→P3→P4 的顺序完成四项准入预实验；
- 在单一 Canary 泄漏任务上完成 P5–P7；
- 实现消息门控、安全替代和确定性重放；
- 冻结核心日志 schema，并测量事件基准率和模型随机性。

该阶段同时服务论文一和论文二。

**当前阻断（2026-08-01）：**阶段 A 已完成 P0，但冻结 P1 来源批次未通过 P1 gate，
所以本阶段暂停在新的 P1 设计决策之前；不得以该批次启动 P2–P7 或将其数据并入任何
确认性分析。该阻断不改变论文二、论文三的设计性准备工作。

### 阶段 B：论文一主实验 + 论文二模拟

并行推进：

- 论文一依次完成 M1 确认性三条件实验、M2 多边影响图和 M3 泛化实验；
- 只有主因果信号通过且预算允许时，才启动桥接位置 × 权限的可选实验；
- 论文二完成 SBM/DC-SBM 生成器、基础传播模型和 SBC；
- 根据论文一数据确定真实观测模型，但不在确认性测试集上调参。

### 阶段 C：论文二真实验证

目标：

- 冻结贝叶斯模型；
- 在论文一留出数据和新任务上验证；
- 完成模型错设、缺失机制和先验敏感性分析；
- 形成统一 belief-state 接口。

### 阶段 D：论文三策略研究

只有论文二模型冻结后，才启动确认性策略比较：

- 先用 Oracle 和合成 belief 验证策略层；
- 再接入论文二后验；


## 8. 整体风险与降级路线

| 风险 | 影响 | 降级方案 |
|---|---|---|
| 桥接 × 权限效应不稳定 | 论文一结构结论变弱 | 聚焦通信图与因果影响图差异；必要时并入论文二 |
| 安全替代难以保持任务信息量 | 因果处理存在版本问题 | 把多种替代模板建模为处理版本，删除组作敏感性分析 |
| 完整传播路径不可辨识 | 论文二路径主张过强 | 报告路径可信集和边际传播概率 |
| 贝叶斯模型只在匹配模拟上有效 | 外部效度不足 | 增加错设模拟、不同模型族和编排框架 |
| 真实危害事件过少 | 后验宽、比较困难 | 使用层次模型和风险分层采样，但按真实分布校正 |
| EVSI 不优于简单策略 | 论文三贡献不足 | 研究适用条件；若无算法增量则并入论文二 |
| 三篇数据重叠过大 | 拆稿风险 | 预先登记确认性数据切分和每篇主假设 |

## 9. 当前文献位置与需要避开的主张

截至 2026 年 7 月，已有研究已经覆盖：

- 多智能体拓扑安全：[NetSafe](https://aclanthology.org/2025.findings-acl.150/)；
- 图异常检测与拓扑干预：[G-Safeguard](https://aclanthology.org/2025.acl-long.359/)；
- 时序图上的异常传播检测：[GUARDIAN](https://proceedings.neurips.cc/paper_files/paper/2025/hash/0bc795afae289ed465a65a3b4b1f4eb7-Abstract-Conference.html)；
- 级联注入评测基准：[ACIArena](https://aclanthology.org/2026.acl-long.457/)；
- 跨通道在线因果监测预印本：[CASPIAN](https://arxiv.org/abs/2605.19240)；
- LLM 多智能体运行时贝叶斯网络不确定性监测预印本：[Runtime Uncertainty Monitoring](https://arxiv.org/abs/2607.25877)。

因此不应使用以下宽泛主张：

- “首次研究多智能体安全传播”；
- “首次把多智能体系统表示成图”；
- “首次使用贝叶斯网络处理多智能体不确定性”；
- “后验传播概率就是因果传播概率”；
- “所提方法提供形式化安全保证”。

更稳妥的差异化表述是：

1. **论文一**：随机消息干预识别通信、影响和真实危害之间的差异；
2. **论文二**：在测量误差和部分观测下，联合给出源、状态、边、路径和未来危害的校准后验；
3. **论文三**：把传播后验用于预算约束下的主动调查与干预联合决策。

## 11. 下一步需要冻结的决策

在正式开发前，依次冻结：

1. 论文一的三个主要因果终点；
2. 安全替代消息的生成与质量检查规则；
3. 桥接位置 × 权限实验中的焦点 Agent 和随机化单位；
4. 论文二四状态的操作性标注规则；
5. 日志缺失与检测误差的模拟范围；
6. 三篇论文的数据切分和复用规则；
7. 论文三独立成篇所要求的最低算法贡献。

当前最优先的工作不是实现完整 POMDP，而是先跑通：

```text
一个任务
+ 一个可验证危害
+ 一个风险源
+ 一条可随机门控的候选传播边
+ 一次确定性或近似确定性的配对重放
```

这将直接检验整条三篇论文研究线最基础的前提：风险是否能够被定义、操纵、观察和复现。
