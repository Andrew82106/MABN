## 编号约定

- `00_`：总体研究路线；
- `01_`：论文一；
- `02_`：论文二；
- `03_`：论文三；
- `10_` 以后：跨论文共享规范、数据字典和复现实验协议。

长期文档不是实验运行日志：

- 日常进度、普通成功结果和未验收发现不写入本目录；
- 实验结果只有在经过验收并推翻或实质改变研究路线时才写入；
- 触发路线变化时，必须记录原路线、触发证据、新决定和受影响文件；
- 用户明确要求的长期文档修改仍须完成全局一致性检查。

长期文档中的确认性假设、主要终点和 Go/No-Go 标准如需变更，应记录变更时间和原因。
