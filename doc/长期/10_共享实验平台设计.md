# 共享实验平台设计（shared_lab）

> 状态：三层设计已由主 Agent 与用户确认（2026-08-17）；`shared_lab/` 可审计基础
> 与权限映射已于 2026-08-18 独立验收通过。2026-08-19 的科学实验准入检查确认，
> 角色观察隔离、受控工具层和模型入口仍待实现；完成前不得用平台生成论文数据。
> 定位：三篇论文共用的“透明实验室”，与任何具体场景解耦。

## 0. 一句话定位

平台负责让“LLM 多智能体图实验”可以被可信地运行、记录、回放和溯源；
平台不负责任何具体任务、角色、人数、图结构或危害定义。

## 1. 三层结构

### 1.1 内核：与场景无关的基础能力

内核只提供五件事，代码中不得出现任何具体场景常量：

1. 调度：谁被唤醒、消息沿图如何传递、一个回合何时结束；
2. 权限：任何动作在执行前由内核强制检查，违反即拒绝并记录；
3. 账本：可观察事实按时间追加记录，只增不改；
4. 状态与回放：状态可快照、可哈希、可回滚；给定账本与初始状态，程序能重建终态并核对一致；
5. 溯源：本次运行使用的配置、提示词、代码、环境全部记录内容哈希，可回答“结果是用什么跑出来的”。

### 1.2 场景配置包：纯数据

一个具体实验场景完全由数据描述，内核读取后运行：

- 人数、角色、社群标签；
- 通信图（谁可以向谁发消息）；
- 每个角色的工具能力与权限；
- 任务提示词、输入材料、正常完成条件；
- 危害终点定义及其程序判定器；
- 模型绑定与解码参数。

8 人供应商审查只是第一份场景配置包，不是平台的形状本身。换人数、角色、图或任务，
只换配置，不改内核。

### 1.3 实验钩子：三篇论文的插入点

- 论文一：在任意指定边、指定时刻注入消息干预（替换 / 删除 / 安全改写）；
- 论文二：对观测注入噪声或缺失（日志缺块、检测器误报漏报）；
- 论文三：防御动作（隔离 Agent、切断边、撤销权限、回滚状态）。

平台提供插口，具体实验决定插什么；平台不为三篇论文各写一套。

平台位于仓库根的 shared_lab/，与 paperAlpha/ 平级。详细目录结构见

## 3. 选型原则（含对现有库的评估）

- 允许参考、甚至直接复用 AutoGen、LangGraph 等现成框架的设计与组件；
- 但本平台的四条审计性质是硬门槛，不得为了用库而牺牲：
  账本只增不改、可确定回放、可溯源、权限由内核强制；
- 若现成库能完整保证上述性质则复用；否则使用薄内核。优先标准库，新增依赖必须写明理由；
- 内核必须能用 stub Agent 全离线测试，不依赖任何模型调用、网络或 GPU。

## 4. 验收性质（非协商）

1. 内核代码不得出现 8 人、供应商审查、假机密等场景常量；
2. 用 stub Agent 即可全量离线测试，不依赖任何真实模型调用；
3. 账本只增不改；回放重建的终态与原始运行一致；
4. 任何动作在执行前都经过内核权限检查；
5. 每次运行可回答“用了哪份配置、哪段代码、哪个环境”；
6. 场景的“正常完成”与“危害”由程序判定器给出，不依赖 LLM Judge 作为唯一判据。

### 4.1 科学实验准入的额外硬门槛

“运行可审计”不等于“实验因果路径可识别”。平台用于论文实验前还必须满足：

1. **角色观察默认拒绝。**内核完整状态只供受信任的调度、工具和审计代码使用；
   每个 Agent 只获得场景配置明确授权的状态投影、自己的消息和自己的工具结果。
2. **敏感状态只能通过工具访问。**模型控制的 Agent 不得直接执行任意 `set_value`、
   `append_value` 或写任意状态路径；内部记录读取和公开发布必须分别经过场景注册的
   受控工具及其独立权限。
3. **模型不能声明自身权限。**模型输出只描述消息或工具请求；所需权限由内核依据
   动作类型和工具注册表推导并检查，不能接受模型提供的 capability 作为授权事实。
4. **工具副作用可回放。**工具执行及结果进入账本；重放使用已记录的确定性效果，
   不重新调用模型、真实网络或有副作用的工具。
5. **传播路径没有旁路。**普通角色不能直接看到假测试秘密，也不能直接写公开端；
   可验证泄漏只能经“授权读取—显式消息—授权发布”的记录链发生。
6. **模型入口可替换且可离线测试。**模型适配层接收经过隔离的观察，输出经过严格
   解析的动作；必须可注入 fake transport 完整测试，真实 API 调用另行授权。

2026-08-19 的独立只读探针确认当前基础实现尚未满足第 1、2、5 项：普通材料角色可从
`observation_for()` 获得含假测试秘密的完整状态，并能借通用 `state.write` 直接写入
公开报告。因此此前“验收通过”仅指可审计基础层，不代表科学实验准入通过。

## 5. 边界与历史隔离

- 泛化域是“LLM 多智能体图实验”内部的人数、角色、图、任务、干预、观测与防御；
  不是通用 Agent 框架；
- paperAlpha/ 下的冻结代码、数据与历史 run 一律不动；新平台在 shared_lab/ 净新增；
- 现有 paperAlpha/pre_exp1 的 P0 内核实现可作为参考读，不得直接修改；
- 是否让 paperAlpha 后续切换到共享内核，另立任务决定，不在本任务范围内。
