# 项目文档导航

本目录按文档生命周期分为两个区域：

- [临时](./临时/)：尚在执行、验收、返工或等待整合的任务说明、原始返回和中间材料；
- [长期](./长期/)：经过主研究线整理、需要持续维护的项目设计和论文方案。

每次处理项目任务前，先读取以下指南最开头的“场景路由”；命中场景后，再读取路由指定章节：

- [Doc 工作指南](./Doc工作指南.md)

所有 Python 实现统一使用：

- [项目统一 Python 环境](./Python环境说明.md)

使用原则：

1. 临时材料不能直接作为论文事实依据；
2. 日常实验进展和常规结果保存在代码项目或临时区；
3. 只有经过验收、足以推翻或实质改变研究路线的实验效果，才写入长期文档；
4. 更新前检查全部文档，修改所有受影响文件并保证交叉引用一致；
5. 任务整体验收通过且无后续待办后，完成必要迁移并删除该任务的临时文件；
6. 同一主题以长期文档为唯一正式路线来源，避免多个文件并行漂移。
