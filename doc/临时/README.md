# 临时文档区

本目录只用于：

- 给其他 Agent 的任务 brief；
- Agent 的原始调研或评审结果；
- 尚未验证的想法、表格和草稿；
- 等待整合进长期文档的中间材料。

这里只保留**仍在执行、验收、返工或等待决策**的材料，不保存已经结束的任务档案。

创建或更新任何文档前，先读取上一级 [Doc 工作指南](../Doc工作指南.md) 顶部的场景路由，再按“改文档”场景读取指定章节。实验设计任务同时触发“讨论实验”，默认先回答“证明什么、怎么证明、产出什么”，再进入实现细节。

所有 Python 实施任务还必须引用 [项目统一 Python 环境](../Python环境说明.md)，并在 Prompt 中明确：

```text
Conda 环境：multi_agent_graph
Python：3.11.15
解释器：D:\anaconda\envs\multi_agent_graph\python.exe
推荐命令：conda run -n multi_agent_graph python ...
```

未写明统一环境的 Python 实施任务书不得发送。

推荐命名：

```text
YYYY-MM-DD_主题_任务对象.md
```

例如：

```text
2026-07-31_论文一因果估计量_统计Agent.md
2026-07-31_论文一沙箱MVP_系统Agent.md
```


## 完成任务的清理规则

验收时必须处理临时文件：

1. Agent 声称完成不等于任务完成；
2. 验收未通过、待返工、等待复验或仍有后续待办时，保留相关临时文件并更新状态；
3. 整体验收通过且没有后续待办时，先完成必要迁移和引用检查；
4. 随后删除该任务对应的任务书、Agent 原始返回、验收报告和中间材料；
5. 普通实现证据保留在代码项目的数据、manifest 和 reports 中；
6. 只有推翻或实质改变研究路线的已验收证据才进入长期文档；
7. 删除后重新检查本目录和全部相对链接。

本 `README.md` 是临时区规则文件，不随单个任务删除。不得把未经核验的 Agent 输出直接引用为论文结论。
