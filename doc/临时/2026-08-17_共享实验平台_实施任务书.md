# 任务书：共享实验平台（shared_lab）实施

> 状态：待执行。
> 前置阅读：先完整阅读 doc/长期/10_共享实验平台设计.md。
> 目标读者：接手实施的外部协作者。本文是交接给协作者的唯一权威任务定义。

## 1. 顶层目标

实现三篇论文共用的“透明实验室”，与具体场景解耦：

- 内核提供调度、权限、账本、回放、溯源五类基础能力；
- 任何具体实验（人数、角色、图、任务、危害）通过纯数据配置包注入；
- 论文一的消息干预、论文二的观测噪声、论文三的防御动作做成可插拔钩子。

## 2. 允许写入的路径

只创建或写入仓库根的 shared_lab/。

不得修改 paperAlpha/、doc/、根 README.md 或 .gitignore。paperAlpha/pre_exp1
的旧实现只能读、不能改。

建议目录：

    shared_lab/
    ├── README.md                    # 安装、运行、验收命令
    ├── pyproject.toml               # Python 3.11；内核包名 lab_kernel
    ├── src/lab_kernel/              # 内核：scheduler / permissions / ledger /
    │                                #       state / replay / provenance
    ├── scenarios/
    │   └── supplier_review_8agent/  # 第一份场景配置包（纯数据 + 提示词 + 程序判定器）
    ├── hooks/
    │   ├── message_gate.py          # 论文一：边级消息干预
    │   ├── observation_noise.py     # 论文二：观测噪声 / 缺失
    │   └── defense_actions.py       # 论文三：隔离 / 切边 / 撤权 / 回滚
    └── tests/                       # 内核与钩子的离线测试

## 3. 硬性验收（任一不满足即为返工）

1. 内核代码不含任何具体场景常量（8 人、供应商、假机密等一律不得出现）；
2. 使用 stub Agent 即可全量离线测试，不依赖模型、网络或 GPU；
3. 账本只增不改；由账本加初始状态重放出的终态与原始运行一致；
4. 任何动作执行前都经过内核权限检查，越权必须被拒绝并记入账本；
5. 每次运行可回答“用了哪份配置、哪段代码、哪个环境”，且内容哈希可重算；
6. 篡改账本或配置后，验证与重放必须 fail-closed，不能靠表面哈希自洽蒙混；
7. 8 人供应商审查作为第一份场景配置包迁入，任务成功与危害由程序判定器给出；
8. 三个钩子各有最小可用实现和对应测试；
9. paperAlpha/ 下的一切保持字节不变。

## 4. 技术约束

- 优先标准库；新增依赖必须在 pyproject.toml 与交付说明中写明用途；
- 可参考或复用 AutoGen、LangGraph 的设计与组件，但不得破坏第 3 节审计性质；
- 内核与场景严格分离：场景配置包不得依赖内核不稳定内部接口之外的实现细节；
- 配置包用声明式数据（JSON/TOML），提示词独立成文件，判定器独立成模块；
- 不实现任何贝叶斯模型、SBM、POMDP、EVSI 或论文结论。

## 5. Python 环境

本机统一环境（供主 Agent 验收复跑时使用）：

    Conda 环境名：multi_agent_graph
    Python：3.11.15
    解释器：D:\anaconda\envs\multi_agent_graph\python.exe

外部协作者在自己的机器上按 shared_lab/pyproject.toml 创建 Python 3.11 环境即可；
内核开发与测试不依赖 GPU 或本地模型。交付时报告实际解释器路径、Python 版本、
测试数与新增依赖清单。

## 6. 判定与交付

判定：

- ready_for_acceptance：第 3 节九项全部满足，公开测试命令可复跑；
- rework：任一硬性验收不满足。

交付必须包含：

- 实际 Python 环境与依赖清单；
- 测试数与全部测试命令；
- 每一条验收性质的对应测试证据；
- 场景配置包与三个钩子的使用说明；
- 未实现项与已知限制；
- 明确“等待主 Agent 验收”，不得自行宣布完成，不得生成论文结论。

完成后推到新分支并发起合并请求，把分支或合并请求链接交给主 Agent 验收。
