# Round10 固定特征：软资料对齐与纯文本控制

本文件记录已经实现的 `feature10.py`，不是待测试结果后的候选方案。只增加一个固定 16 维白盒块和一个 8 维文本块；不训练额外编码器，不按新测试调整词典、温度、层段或公式。

## 1. 输入、接口与基线

```python
extract_features(tokenizer, model, visible, generated) -> (arrays, metadata)
```

`visible` 仅复制 `system/prompt/questions/passages[{title,text}]`；实际渲染后的 prompt 必须与 `input_token_ids` 完全相同。`generated` 中实际读取精确输入与回答 token IDs、原始回答及其偏移校验字段；不使用完整解析项的正文、结束位置或标签选证据。

禁止主体元数据、隐藏别名、参考答案、证据标注、类别、完整/缺失条件、风险标签和检测分数进入特征。问题编号路由只读到当前词元为止，单问题始终对应问题 0。

原 Lookback 保持每层每头的比例：

\[
LB_{lhj}=\frac{\operatorname{mean}_{k\in C}a_{lhj}(k)}
{\operatorname{mean}_{k\in C}a_{lhj}(k)+\operatorname{mean}_{k\in G_j}a_{lhj}(k)}.
\]

`C` 是真实 Search results 区，包含来源标题、编号和分隔符；`G_j` 是生成词元 0…j，包含当前词元。它是两个均值的比，不是两段注意力总量的比。拼接顺序为层优先、头次优先，在本地模型上为 28×28=784 维。原论文在 §2.1 定义该比例并将片段内向量平均后训练逻辑回归；本地沿用特征公式，但采用下述读入当前词元后的时点和 Qwen/NF4 适配，并非原论文全设置复现。[原论文](https://aclanthology.org/2024.emnlp-main.84.pdf)

## 2. 资料句与问题的连续相关度

按真实展示正文分句，保留缩写、括号日期等基本结构；句子均为候选，不要求同时命中主体与属性。一个跨句 BPE 只分给非空白字符交集最大的正文句，并列取先出现者。来源标题参与该来源各句的相关度表示，但标题注意力不进入新增正文通道。

令 `S` 为实际非空句数，`B` 为全部正文 token，`B_s` 为句 s 的正文 token，`n_s=|B_s|`。每个句子的表示 token 集合 `U_s` 是正文和其可见标题的并集。

1. 从问题原文抽取 Unicode 单词，只删除代码中固定的功能词；不解析人工指定的主体或属性类别。
2. 对问题词 w，`idf(w)=1+log((1+S)/(1+df(w)))`，其中 df 仅由当前展示的“标题+句子”词面统计。
3. 将每个词的 idf 等分给覆盖该词的 BPE，重叠则累加，最终归一为问题 token 权重 `w_i`；不补完整未来输出词。
4. 从被测模型自己的冻结输入 embedding 表取向量，并作 L2 归一化，得到 `e_i`。
5. 固定计算加权 MaxSim 和软权重：

\[
z_s=\sum_{i\in Q}w_i\max_{k\in U_s}\operatorname{clip}(e_i^Te_k,0,1),
\qquad q_s=\operatorname{softmax}_s(z_s/0.1).
\]

所有真实句子均保留正的软权重，不设阈值、top-k 或主体 AND 属性门槛。没有可用问题内容 token 时明确记录并用**句子均匀**分布；这不是“证据充分”的判定。没有任何正文 token 则显式报错，不能伪造证据。正常情况下无硬候选，也就没有原来的“候选为空”判定，但仍可能把软权重放错位置。

这些是静态输入词嵌入，不是专门训练的语义编码器，更不是已经整合来源的问句状态；实际 prompt 中问题在来源之前。标题承接方便处理省略主体的句子，也可能把后来改谈另一主体的句子过度归给标题主体，必须作为局限保留。

## 3. 固定 16 维白盒块

对每层、每头、当前生成 token j，令 `a(k)` 为该查询的因果注意力，`b(k)=a(k)/sum_{u∈B}a(u)` 为在正文内归一的注意力，`A_s=sum_{k∈B_s}b(k)`，并定义：

\[
r(k)=q_{s(k)}/n_{s(k)},\quad
d_G=\operatorname{mean}_{k\in G_j}a(k),\quad
c_j(k)=\operatorname{clip}(e_j^Te_k,0,1),\quad C_B=|B|.
\]

`sum_B r(k)=1`；`c_j(k)` 只依赖当前 token 的身份与来源 token 的冻结输入 embedding，不依赖未来回答。

| 通道 | 精确公式 | 含义边界 |
|---|---|---|
| `soft_relevance_lookback` | `d_q/(d_q+d_G)`，`d_q=sum_B a(k)r(k)` | 按问题软相关度加权的正文注意力密度，相对生成前缀密度 |
| `question_attention_overlap` | `sum_s sqrt(A_s q_s)` | 正文注意力落点与软相关度分布的 Bhattacharyya 重叠 |
| `attended_embedding_copy` | `m=sum_B b(k)c_j(k)` | 当前 token 与实际关注的来源 token 的静态 embedding 匹配 |
| `copied_source_relative_relevance` | `g/(1+g)`，`g=C_B sum_B b(k)c_j(k)r(k)/m` | 匹配内容落在相对高相关正文位置的程度；m=0 时取 0 |

若 `r(k)=1/C_B`，第一个通道退化为**仅正文**的原式 Lookback，第四个在有匹配质量时为 0.5；句子等概率且句长不等时，r 并非 token 均匀分布。上述通道不是概率校准后的风险，更不证明句子蕴涵了回答。

分别在层 1–7、8–14、15–21、22–28 内对全部注意力头及 7 层等权平均，得到 4×4=16 维，不挑头、不增添最大值或标准差。无法因果路由的 token 置新增块为 0 并记录无效路由，不删除该 token；全局 Lookback 与隐藏状态仍保留。

## 4. 固定 8 维纯文本块

此块不读取 embedding、注意力或模型隐藏状态，用于检查收益是否仅来自词面重合或资料长度。词面句相关度是问题词 idf 加权的精确覆盖比例，统计时包含当前可见标题。当前 BPE 片段仅单独解码、NFKC/大小写规范化和去两端空白，不读取其后字符；含替换字符或没有字母数字的片段不作词面匹配。

| 顺序 | 特征 |
|---|---|
| 1 | `log(1+正文token数)` |
| 2 | `log(1+句数)` |
| 3 | 当前问题内容词在任一“标题+正文句”中的加权覆盖率 |
| 4 | 最大词面句相关度 |
| 5 | 第一与第二词面相关度之差；仅一句时第二值为 0 |
| 6 | 当前 token 片段是否在任一正文 token 中出现 |
| 7 | 当前片段所匹配正文句的最高词面相关度；无匹配为 0 |
| 8 | 当前片段是否在问题 token 中出现 |

第 6–8 项可能只匹配到名字或数字的一小段，不能称为完整答案匹配。词元坐标仍来自原始生成 BPE，展示时不得将部分命中扩大为全词。

## 5. 输出、计算与验证

主要数组：`new_features[R,16]`、`surface_features[R,8]`，均为 float32；同时返回 `lookback_features[R,784]`、`hidden_21/hidden_28`、`token_nll/token_entropy`、精确 `token_ids/token_start/token_end`、`response_token_offsets` 和因果路由信息。额外基线数组供审计或复用，不改变预先指定的特征对照。

metadata 保存特征名、固定温度、真实句子及 token 分配、问题内容词及权重、每句原始相似度与软先验、源码/可见输入/精确 token 哈希、缺省情况和耗时。旧数据、原句和固定输出坐标不因新特征改变。

一次 SDPA backbone 重放，以 hook 获取实际 Q/K 和 RoPE/GQA，每次仅重建 8 个回答 query 的注意力行；不存完整序列平方注意力。embedding 计算只产生问题×句内来源及回答×正文的相似度块，不新增模型 forward。NLL/entropy 每 16 个预测位置计算一次词表 logits。8GB 显存下的实际数值与耗时由根任务统一 GPU 核对，不能把本文件的计算量说明当成实测延迟。

新注意力/hidden 是读入 j 后的 `P+j` 状态；NLL/entropy 用 `P+j-1` 预测已观察的 j。当前 token 的风险监测无未来回答，但不等于提前预测该 token 将出错。问题级头平均完整短回答项的特征；将其风险广播回词元是事后对照，与当前词元因果定位分开。

已完成 7 项 CPU 检查：手工张量公式及均匀先验退化、软相关与空问题缺省、隐藏字段不变性、真实 prompt 不一致/空正文处理、BPE 半词前缀不补未来、tiny Qwen eager 注意力/隐藏状态/NLL 对齐，以及同形状未来扰动/截断前缀不变性。测试只证明实现和信息时点，不证明检测有效。

## 6. 固定比较与局限

按 [PLAN](PLAN.md) 比较 `LB`、`LB+文本`、`LB+白盒`、`LB+白盒+文本` 和 `LB+旧binding`，主方法预先固定为两块都加入；不能测试后换成最高分组合。问题级与词元级分别训练、校准和评测，不能混用其分母或将原论文的片段监督称作本项目首创。

弱 embedding 无法可靠理解否定、角色交换、时间/统计口径、近似与精确数量；MaxSim 缺少关系顺序，BPE 碎片相同会使相似度虚高，来源标题承接也会引入错误归属。软先验总会分配权重，故高相似或高注意力不能直接判为有据，更不是知识调用的因果证明。是否改善、是否由白盒提供额外价值，只能由冻结新数据和文本控制对照判断。
