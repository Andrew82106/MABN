# Round10：针对 Lookback 的改进与双粒度测试

状态：实现与来源审核中；在新测试生成、模型拟合之前写定。目标是检验改进是否有效，不预设达到 0.7 或 SOTA。

## 问题与改进依据

[Lookback Lens 原论文](https://aclanthology.org/2024.emnlp-main.84/) 使用各注意力头对上下文与生成文字的注意力比例训练线性分类器。比例反映读资料的程度，不直接验证读到的内容是否支持当前事实。原论文已有片段检测，不能把细粒度监督本身称为本项目独有创新。

本地 Round7 的项目适配在主集回答项 F1 达 0.934，但数据以年份题为主，外部为 0.720；完整资料下的两条计算错误均漏检，正常拒答也常得到高风险分。Round9 的细标签训练提高词元定位，但新增硬规则候选特征的增益区间包含零；完整资料也会因主体与属性的双重词面门槛匹配失败。这是本地适配的诊断，不等于原方法在全部设置中必然如此。

本轮固定一个改进方向：用模型自身词嵌入计算问题与可见来源句子的连续相关程度，再结合输出时的注意力与复制位置，补充“关注的是哪条资料”的信号。没有必须命中主体加属性的硬门槛，也不下载额外语义模型。

## 数据与隔离

- 训练、验证复用 Round9 的 120、40 个问题组，共 320 条原始回答、原始来源和标签；逐字复制并记录哈希。Round9 已看过的测试集只作已公开的失败诊断，不进入本轮训练或独立测试。
- 从同一公开来源快照池另建 60 个未使用题组，时间、数量、地点、关系、行动各 12 个。每题有完整和局部缺证据两种输入，共 120 条新的模型回答，全部作为测试。
- 新测试来源须经初筛和独立来源复核，排除旧主体、目标事件和来源重合；不根据生成答案是否错误来挑题。候选源不足时先公开调整原因，不按模型成绩补选。
- 继续正常提问，单问题、两段来源、一段短回答，不提示资料不足，不提示可以拒答。目标主体背景保留，只替换所问事实的证据，配套来源两条件固定。保留原文、来源身份和限定条件。
- 新测试输入及来源冻结后才生成；标签在任何新测试检测分数产生前盲标、独立复核、裁决并冻结。

## 方法与公平对照

被测模型固定本地 Qwen2.5-7B-Instruct NF4 四位量化，不微调。原样保留模型生成 token IDs 和字符偏移。特征只读取真正展示的问题、来源文字和到当前 token 为止的生成信息，不读取隐藏主体、参考答案、资料条件、类别、标签或未来回答。

固定五组特征：Lookback 784 维；Lookback 加 8 维纯文本控制；Lookback 加 16 维新白盒信号；Lookback 加上述两者；Lookback 加旧版 32 维 binding 特征。**主要改进方法预先指定为 Lookback 加新白盒和文本控制两者**，不能在测试后换成分数最高的组合。

每组训练两个独立逻辑回归头，共 10 个主头：

1. 问题级头：平均该短回答项内全部 BPE 特征（包括标点），用回答项风险标签训练。Lookback 基线沿 Round7 的项均值聚合方式；不是 Round9 把项标签广播给 token 的训练方式。
2. 词元级头：使用当前 token 的特征、具体风险位置的标签训练。严格原始 BPE 字母数字交集计数，不把分数平移或扩成整句。

另外将 5 个问题级头的固定分数与固定问题级阈值广播给整项，只作非因果、事后的定位对照，不另选定位阈值。

五组使用同一数据、同一分类器、C={0.1,1} 的同等预算。缩放及类别权重只由训练数据决定。问题头按验证问题 F1、词元头按验证词元 F1 选参数及阈值；同一头的阈值并列时优先精确率及更高阈值；不同 C 的验证 F1 和精确率相同则选较小 C。层段、相关度温度及特征公式固定，不按测试选取。不增加 MLP 或随机种子搜索。

## 两种评测必须分别报告

“问题级”在本轮特指每次输入只有一个问题、输出一个短回答，不等于长篇研判报告级。任何独立事实断言无依据或与资料矛盾，整条记风险。主问题级分母包含有依据断言、风险断言，以及经过审查的正常拒答：正常拒答没有编造内容，记无风险；这不代表它完成了问答任务。未决或缺失输出排除并公开数量。另报与 Round7 更接近的仅事实断言子集，避免分母差异被误读成算法差异。

复用的 53 条训练/验证明确拒答已由 root 逐条读取原文和审查理由确认，作为问题头负例。新测试拒答仍须逐条审查，不能用“出现资料不足词样”自动打标签。含虚假拒答理由或另外编造事实的回答仍算风险。

词元主分母沿 Round9：仅对具体风险位置已裁定的事实回答评分，保留正常回答全部可评词元以及风险回答内的非风险位置；拒答和未决不自动变成逐词元事实金标，单独报告其报警。0 表示不在圈定风险表达内，不是每个功能词经过事实核实。已知训练/验证各一例 `[1]` 编号数字计入负词元的旧例外原样保留，不能暗改开发分母。

两级均报 P、R、F1、TP/FP/FN/TN、样本数量和缺失预测。词元另报句内 AUROC、风险片段覆盖和正常回答误报；问题另报正常拒答的误报。两级分母不同，放在并列表时显式标注。

按完整题组进行 2,000 次配对 bootstrap，固定种子 20260912。主要比较分别是两个粒度下“固定新方法减 Lookback”；新方法减 Lookback+文本控制检验白盒额外贡献。公开所有五组及消融结果，不用只看风险回答子集的高分替代主成绩。区间只包含固定模型、标签条件下的题组抽样变化。

## 执行与结论边界

根任务统一使用 GPU，开发材料新特征可先提取，新测试必须来源冻结后才运行。代码、依赖、来源、生成、标签、训练参数及两类阈值都有哈希记录；测试评分一次，之后仅复算与诊断，不回头改阈值。

本轮不改复查或抑制策略。仍为英文短回答的模拟检索、一个量化模型、助手标注和人工挑选来源的预实验。最终报告必须明确“新特征有效/无明确收益/变差”，不能把标注或任务粒度改变包装成胜过 Lookback 的证据。
