# Round10 标签与复核

沿用 Round9 的精确风险片段规则和原文坐标。标签对象是模型真实生成的回答与本次真正展示的资料，而不是资料条件、完整参考或来源池中未展示的其他内容。现实正确但当前资料无法支持的新增事实也属无依据风险；问题给定的前提可以复述。

每条保存 stance、evidence_relation、risk、rationale、最小风险表达的精确引文；初标与独立复核在检测分数未知时完成，分歧在正式评分前裁决。所有标签绑定完整生成记录的 SHA256。正常子句不要跟随错误细节一起涂红；不同条件不能互借证据。保留否定、估计、条件、时间范围和归属关系。

明确只是不提供所问值的回答标为 abstained/excluded；包含无依据事实的“拒答”仍按 asserted/risk=1 判，不按关键词判断。含独立有据事实的部分回答可标 supported，即使它没有完全回答问题；这是无依据陈述检测，不是问答任务完成度评测。无法可靠裁定的断言标 unresolved，不硬补标签。

问题级评分由预先规定的规则导出：resolved asserted 使用 original_risk；复核确认没有风险断言的明确拒答记无风险；未决/缺失不强行赋 0。词元评分仍使用精确风险范围，拒答没有自动生成全零事实标签。两个层级必须公开不同的覆盖分母。

标注由助手执行，不称研究者人工金标。所有原始输出、初标、复核和裁决保留，最后冻结后不能按预测结果回改。
