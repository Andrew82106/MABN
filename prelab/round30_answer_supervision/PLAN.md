# 增加整答监督：准备完成，尚未训练

本轮只检验一个问题：已知正常拒答是整答负例，但没有可训练的词元标签，把这些整答标签加入训练是否有帮助。

两个网络结构、初值、输入和训练顺序相同：`769 → 32 → SiLU → dropout 0.1 → 1`，24,673 参数。A 只用原窗口损失；B 再加整答损失，系数固定 1。不把拒答或未知窗口补成负词元标签。

## 损失和批次

窗口损失只读取原 `main_eligible` 训练窗口，权重与 R29 完全相同，全局总质量 3,854。窗口标签未知时保留 -1，直接跳过其 BCE，不先计算再乘零。

整答风险 logit 为该回答**全部原候选窗口** logit 的最大值，包含不能用于窗口监督的那些窗口。整答 BCE 只读取本折 fit 组中原本已 resolved 的答案；安全拒答使用已有整答负标签，未 resolved 的答案不进入整答损失。

整答基础权重先按来源组等权，再按组内 resolved 回答等权。只用 fit 答案估计正负类系数 `0.5 / 该类基础质量`，乘后重新使各有效来源组等权，最终整答权重总和为 1。最后的全局类别总质量不强制各为一半，组均衡优先顺序与原流程一致。

每批包含八个完整 fit 事件组，末批使用实际组数 B。G 为本折**全部 assigned fit 组数**。两模式均前向传播该批全部回答和候选窗口；同组、同答都不拆，也不删除零窗口监督的拒答。

```text
批损失 = G/B × [Σ批内窗口(w × BCE)/3854 + λ × Σ批内整答(a × BCE)/1]
A: λ=0；B: λ=1。
```

全局两个分母固定，不按批内正负比例或可评窗口数量重新归一。两个模式使用相同批次顺序和更新步数。AdamW 的权重衰减另算，不把它误认为无标签样本的数据梯度。

## 固定训练与评测

- 复用同 raw769 数据和 R29 每折已拟合的标准化器，不重新拟合 LR、PCA 或编码器。
- CPU 四线程；AdamW lr=0.001、wd=0.01；十轮；无 scheduler、无梯度裁剪、无提前停止。每折两模式从 `20261008+fold` 相同初值及随机状态开始。
- 每模式每轮 21 次更新；每折每模式 210 次。保存 epoch 0–10 的模型、优化器、随机状态、完整概率和两个损失分量。
- 每模式先用原 calibration 规则，从 epoch 1–10 选择一个轮次同时服务窗口和整答；epoch 0 只诊断。然后该轮次分别与 Lookback、R26 对应折分数进行同六档 alpha 融合。每模式 60 个候选，合计 120 个，不为不同融合对象重新挑轮次。
- 五折两模式和全部选择冻结后才计算外层指标。原 R29 LR / R28 PCA 控制保留，不重训。

## 已完成的 CPU 检查

合成例子实际验证：没有窗口监督的已知负答，A 对其直接 logit 的数据梯度为 0，B 对最大候选窗口产生降低风险的梯度；未知答在两模式中都没有数据梯度。整答 max 确实包含窗口标签为 -1 的候选。八组加一组的末批缩放可还原固定模型的全局目标。两个实际结构的小网络初始输出、dropout 随机消耗一致，梯度有限。

真实五折已核：每折保留 64–76 条仅整答监督的安全拒答；1–3 条未知答没有整答权重；所有候选窗口保留。窗口总质量均为 3,854，整答质量均为 1，标准化器与 R29 一致。详见 `results/CPU_SELFCHECK.json`。
