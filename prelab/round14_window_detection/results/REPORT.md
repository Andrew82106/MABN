# Round14：定位可疑小段

**4词元窗口和8词元窗口的直接训练 F1 均约0.66。4词元窗口命中76处风险片段中的65处，正常回答误报16/128，标记文本约占19%。在当前样本上，它比8词元直接窗口更节制，适合优先继续验证。**

用户接受粗定位后，本轮目标改为“这个短窗口里是否含有风险”，不再要求窗口内每个词元都判对。下列窗口F1与旧逐词元F1含义不同，不能把数值增加当作精确定位算法的提升。

## 训练和对照

从已有原始BPE词元构造1、4、8词元窗口，步长1；在原回答项内切分，标点计入长度，不根据风险边界切窗口。窗口内至少一个可评词元有风险即标1；少于窗口长度的回答可整项为一个短窗口，但本批没有这种短窗口。纯标点、未决与拒答不补成正常窗口。

直接训练方法对窗口内全部BPE的784维Lookback特征取平均，再训练LR。公平对照使用同一个窗口及金标，将原词元探针对窗口内可评词元的分数取最大值；标点没有进入原词元探针的监督训练，因此不参与这个max。两种方法都只用校准组选择窗口阈值。

沿用Round13的5折题组划分：每折72组拟合、24组校准、24组评测。C固定0.01，各窗口的损失总质量统一到同折1词元拟合样本数；题组、条件、回答的相对权重保持一致。新训练15个窗口模型，复用5个原词元模型；没有重新生成文本或使用GPU。

C=0.01受到前轮同一批训练来源成绩启发，所以本轮仍是探索，不是完全未参与方法选择的新题独立确认。没有读取原验证或原测试标签，也没有修改旧标签、模型或成绩。

## 窗口效果

全部可评窗口来自195条已裁定断言，其中67条风险、128条正常，共3,854个原可评词元；37条正常拒答、8条未决断言不纳入本次窗口主指标。

| 窗口 | 可评窗口 / 风险窗口 | 直接训练 P / R / F1 | 原词元分数取max P / R / F1 | 始终报警 F1 |
|---|---|---|---|---:|
| 1词元 | 3854 / 339 | 0.618 / 0.593 / **0.605** | 0.618 / 0.593 / **0.605** | 0.162 |
| 4词元 | 3721 / 490 | 0.612 / 0.714 / **0.659** | 0.608 / 0.661 / **0.633** | 0.233 |
| 8词元 | 2941 / 566 | 0.614 / 0.710 / **0.658** | 0.632 / 0.719 / **0.673** | 0.323 |

窗口变大时，“窗口里至少有一处风险”的正例比例也变大，因此始终报警的基准会随之升高。直接训练与max对照只在相同窗口内比较：4词元时差+0.0257，题组配对95%区间[−0.0209,+0.0724]；8词元时差−0.0143，区间[−0.0611,+0.0327]。两者都没有形成稳定优于对照的证据。

最高观察窗口F1为8词元max的0.673，来自对现有词元探针的简单汇总，不能宣称新训练结构胜出。未达到0.7。

## 实际会标出多少文字

重叠报警窗口合并，以下文本覆盖按原可评词元的并集计数，不重复累计重叠区域。正常回答误报是该回答至少出现一次报警。风险片段命中是至少覆盖原标注片段中的一个词元，属于宽松命中，不能当成片段全部正确定位。

| 配置 | 标记文本占比 | 正常回答误报 | 风险片段命中 | 风险片段完整覆盖 |
|---|---:|---:|---:|---:|
| 1词元 | 8.4% | 18/128（14.1%） | 61/76（80.3%） | 30/76 |
| 4词元，直接训练 | **19.4%** | **16/128（12.5%）** | **65/76（85.5%）** | 60/76 |
| 4词元，token-max | 18.0% | 15/128（11.7%） | 60/76（78.9%） | 52/76 |
| 8词元，直接训练 | 29.0% | 20/128（15.6%） | 64/76（84.2%） | 61/76 |
| 8词元，token-max | 26.7% | 15/128（11.7%） | 60/76（78.9%） | 58/76 |

4词元直接窗口与8词元直接窗口相比，标记文字更少、正常回答误报更少，风险片段命中并没有下降；8词元完整覆盖片段略多。这只是当前样本上的使用取舍，不是对不同窗口的统一准确率排名。

窗口分数在其右端词元生成后才可得到。合并后的标记表示“这一带需要检查”，不表示这里每个词都错，也不表示模型提前预测了尚未生成的错误。

## 检查与限制

独立检查已通过：1词元的样本、标签、特征、阈值与判定逐行复现Round13的C=0.01探针，3854项的最大分数差约4.4×10⁻¹⁶。原始BPE窗口、任一风险标签、窗口均值、词元max、15个模型的分组与权重、合并覆盖及配对区间均已另行核验，见[独立审计](INDEPENDENT_AUDIT14.json)。

本轮依旧使用英文百科片段构造的模拟检索短回答和已有助手标注，并非真实联网长篇情报研判、人工专家金标或新测试集。重叠窗口高度相关，区间按题组抽样2,000次，而非把每个窗口当作独立样本；区间以当前固定模型和阈值为条件。

拟合与评分内部计时约3.98秒，不含数据构造、核验、区间、审计和报告时间。
