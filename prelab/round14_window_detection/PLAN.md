# Round14：可疑小段检测

用户接受比逐词元更粗的定位。本轮主目标改为发现含有至少一处风险的短窗口，分别比较1、4、8个原始BPE词元。不同窗口大小的F1分母和正例比例不同，不当作同一精确定位任务的算法增益。

在回答项边界内按原始BPE连续滑动，步长1；标点占窗口长度，短于窗口的回答整项作为一个短窗口。只使用已裁定断言；纯标点窗口、拒答和未决内容不补零标签。窗口内任一原可评词元为风险，窗口即为风险；切分不参考风险边界。

直接窗口探针平均窗口内全部BPE的784维Lookback特征，再训练LR。对照是在完全相同的窗口上，对已有逐词元探针分数取最大值，只在原可评词元上取max。两种方法都在校准组按窗口标签选阈值。

沿用Round13的5折72组拟合、24组校准、24组留出，C固定0.01。每组、条件、回答的训练总权重规则不变，并将每种窗口的总损失质量统一到同折1词元拟合样本数。复用旧token探针作为max对照；1词元直接训练必须复现旧模型分数与阈值。

报告窗口P/R/F1、始终报警的基准、同窗口直接训练与max对照的差、按题组抽样的区间。辅助报告合并可疑窗口后的文本覆盖率、正常回答被报警的比例及风险片段的宽松命中率。回标整窗只能在窗口右端生成后完成，不是提前获知每个词元的风险。

这是已研究过的训练来源内的新目标探索，不是新数据独立验证。无新生成或GPU，保留旧标签、旧模型和旧评测结果。
