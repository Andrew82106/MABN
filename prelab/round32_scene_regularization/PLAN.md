# R32：固定场景内的正则强度对照

只使用已反复开发的 R16 原训练部分：602 回答、301 问、278 事件组。沿原五折的三份拟合、一份校准、一份留出；共 12,222 候选窗口，9,526 可评窗口、598 可评回答。117 份已审安全拒答计入整答负例，4 份未决排除，拒答窗口不补零。原 R16 validation/test 和公共 QA test 不读取。

比较 R29 的 raw hidden768+z（769 维）和 R31 的 raw hidden1024+z（1025 维）。窗口表示、分组、训练权重、fit-only StandardScaler、LR liblinear、seed 20261008、质量 3854 均不变。每条输入支路固定 C=[.001,.01,.1]。原 C=.01 的各五个模型、全部概率、校准阈值及六档融合控制精确复用；只有另外两个 C 新拟合，共 20 次，不做 PCA 或新神经推理。

每条支路分别给出单语义、与固定 LB 联合、与固定 R26 联合。单语义只在校准组选择 C；联合各在 3C×6α（0,.2,.4,.6,.8,1）中选择同一个候选，窗口和整答各自选阈值。选择顺序：两个 F1 的较小者、窗口 F1、窗口 precision、较小 α、较小 C。单语义忽略 α。同一候选同时用于两粒度，不能分别挑两个模型。

沿原联合公式 sigmoid(logit(prior)+α·logit(semantic))，clip 1e-12；α=0 精确回到对应折的原先分数。整答始终取该候选所有窗口的最大值，不用金标挑窗口。全部十份分折选择写入冻结清单后，独立 evaluate 阶段才汇总留出指标。全部候选模型、分数及校准表保留；失败保留，不加预算或换求解器。

这是同一反复开发场景中的正则适配，human_gold=false，不是独立人标验证。R29 与 R31 还同时改变骨干、维度、上游辅助→QA 与 QA-only 训练，不能将跨支路差异只归因于规模或 C。增加校准搜索也不保证留出提升，更不能据此声称达到目标。
