# Round12：两分支条件交互实验

**回答级从原 Lookback 的0.778到0.800，但无交互的两分支融合也达到0.800。词元定位加入交互后为0.554，低于原 Lookback 的0.568。此次没有发现交互项带来提升。**

这是对已经查看过的 Round10 测试题的探索性复测，不是新的独立验证。训练与验证规则在评分前冻结，没有根据本次测试结果重选参数或阈值。

## 实际做法

冻结 Qwen2.5-7B-Instruct NF4，复用相同输出的784维 Lookback 与当前词元 NLL（−log p）缓存。本轮没有重新生成文本、调用外部大模型或使用 GPU。

注意力分支先把784维变成一个分数 a；概率分支提供 n。把 a、n 按训练统计量标准化，加入单独标准化的乘积 a×n，训练融合逻辑回归。它相当于允许 NLL 的系数随注意力分数变化。

为避免融合层利用底层模型对训练题的记忆，训练120题组分成5折。每折的底层探针只在其余96组训练，为留出的24组打分。融合层只使用这些折外分数；底层标准化、类别与题组权重也在各折内计算。部署时底层在全部120组重拟合，融合层保留折外训练结果。

底层 C 固定0.1。各融合层只在 C={0.1,1} 中用40组验证集选配置及阈值，最后六个融合头均选0.1。原 Lookback 与直接拼接按原来的相同两项 C 搜索重新训练，作为复现对照。回答级和词元级分别训练；回答级先平均项内原始 BPE 特征，词元级只看当前位置。

## 同一批测试数据

60题组、120条短回答，来自英文百科片段构造的完整/局部资料输入，属于模拟检索场景。回答级计115条：34风险、66有据、15正常拒答；5未决排除。词元级计100条已裁定断言中的1,683个 BPE，其中164个风险词元；不把正常拒答和未决内容补成全零标签。

标签沿用助手标注及独立复核，未由人工专家重新标注。风险按当前可见资料的依据与原有裁决定义，并不等于每条陈述都已经独立核实了世界事实真伪。

## 改变了哪些判定

回答级，有交互与无交互的主评测判定逐条一致。两者相对原 Lookback 多检出两条风险回答，也新增一条正常回答误报：

- RoboSense 的回答依据其已经上市，断言它在指定月份没有 IPO 融资；从漏检变为检出。
- Mark Freeman 的回答根据现有资料，断言他与妻子没有共同经营业务；从漏检变为检出。
- Cecelie Williams 在完整资料下正确复述孕妇离婚法律倡议；新增误报。

词元级，有交互相对无交互共有10处主评测判定变化：新增检出1个风险词元、漏掉原先检出的2个风险词元；新增6个正常词元误报、取消1个误报。净结果是少检出1个风险词元、多5个误报。相对原 Lookback，则净少检出2个风险词元、多2个误报。

“折外注意力分数单独使用”与原 Lookback 的主判定一致，符合它只是对原分数做单调变换的设计。交互模型的乘积系数确实非零：回答级0.0644，词元级−0.3426；交互参与了评分，但没有转化为本次定位收益。这些系数不能当作因果重要性或真实幻觉概率。

## 差异是否稳定

按60题组整体配对抽样2,000次，保留每题两条件及全部词元：

| F1差值 | 回答级差值及95%区间 | 词元级差值及95%区间 |
|---|---|---|
| 有交互 − 无交互（主比较） | 0.0000 [0, 0] | −0.0144 [−0.0400, +0.0074] |
| 有交互 − 原 Lookback | +0.0222 [−0.0215, +0.0767] | −0.0135 [−0.0375, +0.0113] |
| 有交互 − 直接拼接 | +0.0329 [0, +0.0834] | −0.0106 [−0.0320, +0.0117] |
| 无交互 − 折外注意力单独使用 | +0.0222 [−0.0215, +0.0767] | +0.0009 [−0.0347, +0.0353] |

回答级0.800是观察到的分数，尚不能认定稳定超过原 Lookback；交互对回答级没有额外收益。词元主比较的差值区间跨零，不应据此断定交互普遍有害，但本次也没有改善证据。区间仅针对固定模型和当前标签，不能消除测试题已暴露的限制。

## 实现与检查记录

融合层没有使用全量底层模型的训练内分数。作为预先约定的分布诊断，回答级底层分数的标准差在折外训练集为3.531、全量重拟合后的验证集为3.687；词元级分别为2.974与3.329。折外与部署分数存在分布差异，但不能凭该差异认定它是性能变化的原因，本轮没有据此改结构或重调测试阈值。

拟合与验证预测内部计时约8.40秒；完整运行还包含文件核验、指标与区间计算、独立检查。全部使用已有缓存，时间不代表重新生成大模型输出的成本。

独立检查已通过：[INDEPENDENT_AUDIT12.json](INDEPENDENT_AUDIT12.json)。原 Lookback、直接拼接的验证与测试分数完全复现，最大差为0；232条训练回答项、3,854个训练词元的折外分数、折内标准化、组隔离、类别与题组权重、融合预处理均核对一致。10个头的指标、验证阈值与 C 选择、4组对照的配对区间及实际判定变化也已独立复核。

**结论：这次两分支加法融合在回答级有小幅观察性改善，乘法交互没有带来额外收益，逐词元定位仍未改善。不能将本次交互版本作为升级成功或 SOTA 的证据。**
