# Round12：注意力与词元概率的条件交互设计

状态：设计完成；已检查旧模型的特征贡献，尚未训练或评测本轮新模型。

## 要检验什么

Round11 直接把 784 维 Lookback 与 1 维 NLL 拼接。逐维标准化已经处理尺度差异，因此不能直接认为 NLL 只占 1/785 的权重。各维数量、相关性、正则化与预测价值仍可能影响拟合，不能凭维数判定失败原因。

旧模型在验证集上的 NLL 加权分数波动约为注意力分支的 6.24%（回答级）、4.00%（词元级）。这是两项线性贡献的标准差之比，不是重要性百分比、因果归因或可提升幅度。计算只使用旧模型及训练/验证数据，见 [诊断结果](results/contribution_diagnostic.json) 和 [诊断代码](src/diagnose_existing.py)。

本轮假设：NLL 的用途取决于注意力模式；固定相加不足以表达这种关系。注意力与 NLL 都只是风险线索，不直接代表证据支持或事实真假。不能人为把两个分支强制设为同等权重。

## 新结构

大模型仍冻结，输入资料、输出、标签与逐词元坐标沿用已有定义。

1. 注意力分支：784 维 Lookback → 原形式的逻辑回归 → 一个未经过 sigmoid 的分数 a。
2. 概率分支：当前词元的 n = −log p。回答级使用项内全部重叠 BPE 的平均 NLL。
3. 融合：按训练数据标准化 a 与 n，加入乘积 a×n，再把乘积按训练数据标准化，交给小型逻辑回归。

忽略标准化的可吸收常数后，其作用可以写成：

`风险分数 = sigmoid(b + αa + (β + γa)n)`

旧结构中 NLL 的作用是固定系数；新结构中它的系数随注意力分数 a 改变。也保留 a 自身的直接作用，避免把“选词概率高”强制当成安全。该结构在 a、n 上包含乘法关系，只需少量融合参数；不是额外堆一个大网络。

例如，罕见名称导致低词元概率、但注意力信号支持使用资料时，与模型脱离资料却流畅输出时，可以形成不同的风险响应。这个行为由标签学习，不预设交互项符号，也不保证两类信号一定互补。

## 怎么训练

- 训练120题组、验证40题组；相同问题的全部条件、回答与词元必须在同一折。
- 训练组按固定种子20260912划成5折。每折只用其余4折拟合注意力分支，包括该折的标准化、类别与题组权重；底层 LR 固定 C=0.1。
- 用每折未参与底层拟合的题组获得折外 a。融合头只在这些折外分数上训练，不能使用底层模型对自己训练样本的拟合分数。
- a、n 的标准化使用折外训练数据及不依赖标签的题组基础权重；先中心化再相乘，乘积项另用训练统计量标准化。各融合头的损失沿用原题组和类别权重。
- 回答级和词元级分别训练，不把回答标签广播成词元标签；拒答和未决的处理沿用原口径。回答级先平均原始特征再进分支；词元级只使用当前词元信号，不加窗口或未来内容。
- 底层 LR 在全部训练组重拟合，供验证和测试使用；融合头不再用训练内分数重训。记录折外、全量拟合后验证集分数的尺度，明确两者可能发生分布变化。若观察到问题，本轮如实报告，不临时切换部署结构追成绩。
- 融合头只搜 C={0.1,1}，阈值按本粒度验证 F1 选择；并列规则沿用 Round11。底层和融合头都不使用测试标签。

## 对照与评测

固定五组，分别评回答级与原生词元级：

| 组别 | 用途 |
|---|---|
| 原 Lookback | 保留原基线，核对是否复现 |
| 784+1直接拼接 | 复现 Round11，判断本次改动是否有收益 |
| 只用折外 a 的融合头 | 检查压缩、折外训练及重新缩放本身的影响 |
| 折外 a+n，无乘积 | 检查概率加入后的加法收益 |
| 折外 a+n+a×n | 主方法，检验条件交互是否有效 |

主比较是“有乘积”减去“无乘积”，并同时报告与原 Lookback、直接拼接的差。报告 F1、精确率、召回率，按题组配对计算区间，并检查哪些词元从误报变正确、哪些错误被漏掉。单看总体分数不能证明交互机制有用。

已看过的 Round10 测试只能用于探索性比较，不能称为独立确认。此文档不代表新一轮数据与参数已经冻结；实现完成、检查通过后另存运行协议和冻结记录，再训练与评分。若探索结果值得继续，正式确认需要未见过的新题组，仍单列回答级与词元级，不能承诺达到0.7或 SOTA。

本轮先检验条件交互，不同时加入窗口、实体识别、熵或 MLP，以便看清改动来源；更复杂的网络留待本次假设验证后再决定。
