# Round 8：逐词元定位诊断

2026-09-11。用户要求：继续检验具体错误位置，不改复查策略；先比较现有方法，再决定如何改算法。

## 目标与范围

回答“这句话有问题”已经测过，本轮进一步检查“高分能否落在具体的无依据或错误片段”。复用Round7全部验证40题组、主测试40题组、外部50题组的原始回答：260份回答、580个预定项。原模型、回答、题目划分、标签和结果不变。

这些题目的回答项成绩已经看过，所以本轮是已有数据上的新定位诊断，不能当全新的独立测试，更不能仅凭本轮称SOTA。新的算法与更丰富数据需要另建留出集，统一比较后再判断是否优于现有方法。

## 标注

在已有回答项标签基础上，补齐每一个风险项的最小风险表达。风险仍包括“当前材料不支持”和“与材料矛盾”；是否符合完整参考另外保留。原正常事实项的风险片段为空，复用已核查的回答项标签；原拒答、假设或未决项不进入主定位分母。

每项保存原回答全文、全局半开字符范围、生成文件哈希、完整断言范围、一个或多个风险片段、当前材料依据和理由。边界无法明确的风险项单列未决，不能悄悄变成正常项。片段标注人员不查看新token风险分数或热图；助手互审后冻结标注，人工金标准仍待研究者复核。

片段以实际生成的Qwen BPE token映射，不对文本重新分词。只计算与回答项重叠且含Unicode字母或数字的token；纯空白、标点、编号和项外token排除。数字被拆成多个token时全部保留。token与风险片段的交集中含字母或数字即为正例。非风险位置的0只表示“不在标注风险片段里”，不表示每个功能词都已被当作独立事实核验。

具体边界规则见ANNOTATION_GUIDE.md。范围重叠、文本坐标、生成哈希、同一项不同片段重复覆盖均程序核验。

## 方法

- 内部状态线性探针：沿用Round7最终第28层状态、标准化器、分类头，改为每个token读入后的状态。
- 三个MLP探针：沿用第21层状态与各自冻结权重，分别评估并报告均值/波动。
- Lookback：使用缓存的每token注意力比例向量，沿用原冻结线性分类器。
- ReDeEP：使用缓存的每token ECS/PKS，沿用原头、层、缩放和权重。
- LUMINA、NLL、熵：使用缓存的对应token分数，严格保持预测前状态与目标token对齐。
- 为各方法保留“Round7整项分数广播到该项所有token”的对照。表面特征、自评、直接核查只作为这种整项广播对照，不宣称有新的句内定位能力。全部报风险/正常也保留。

需要补提取的只有第21/28层逐token隐藏状态，其余直接复用已核验缓存。隐藏状态、Lookback、ReDeEP是读入当前token后的信息；概率类与LUMINA按其原算法预测该token的位置对齐。原生词元分数不使用之后的回答内容；整项广播对照使用原回答项末分数，属于事后定位对照。新提取状态须与原项末状态一致。因果位置检查保留截断前缀余弦相似度，同时以相同长度下仅改写后续token检查当前状态不变；量化计算在不同长度下可能有数值差异，不能将前者声称为逐值完全相等。

分类器不重训。分别报告两种设置：A沿用原回答项阈值；B仅在validation词元标注上，以风险类micro F1选择一个阈值（并列取较高精确率，再取较高阈值），冻结后才计算test/external。不得混选两套结果或只挑最好随机种子。对照广播法使用同样两种阈值规则。

## 指标

1. 全部可判定回答项的token micro P/R/F1、AUROC、AP及原始TP/FP/FN/TN。
2. 仅在包含风险片段的回答项内计算同样指标，直接检验句内定位，避免只是分清正常句和风险句。
3. 含风险回答的macro F1；全正常回答单列token误报率。
4. 每个错误片段至少命中一个token的召回，以及片段内token覆盖率；同时报告非风险位置的额外报警，防止整句全标红获得高命中率。
5. 主集与外部分开；所有原拒答/未决文字的报警仅作附加描述，不改复查策略，也不把它们悄悄计作正常事实。

主指标采用严格同位置比较，不按测试峰值平移分数，不加入事后容忍窗口。置信区间以原题组为抽样单位，同题两个条件及其所有token一起抽取。

## 数据局限与下一轮

主200组中出生年份题147组（73.5%），输入较短；外部也有明显主体出现/资料完整线索。本轮定位结果必须分年份与其他属性描述，外部不能补足真实搜索场景的全部多样性。

下一轮候选构成：时间、数量/金额、地点、主体关系、事件行为五类，避免任何一类占多数；增加同主体仍出现但关键属性缺失，以及资料完整却关系错配的样本。先以本轮结果确定改进方向，再设计新的训练和独立测试，不为SOTA预设结论。
