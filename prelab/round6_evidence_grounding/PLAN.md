# 搜索资料不完整时的事实项风险监测：第六轮预实验方案

日期：2026-09-10。状态：设计稿 v1.1，已核对数据结构及真实样例；尚未生成实验回答、训练探针或计算效果。运行前需根据入选数据生成独立的冻结协议。本文件不是已完成实验报告。

本次按用户要求修改生成提示：正常提出任务并提供搜索结果，不提示“资料不足可以不答”，也不加入“不要编造”等额外提醒。观察模型在这种正常提问下的回答；模型若自行承认不知道，按实际行为记录。

## 1. 要验证什么

给开源模型一个问题和一组模拟搜索结果。搜索结果只支持问题的一部分。观察模型自行生成的回答，并检验：模型写完某条事实时的内部状态，能否帮助识别这条事实缺乏材料支持、需要复查。

最小任务是“两个主体分别是什么情况，再比较二者”。每份回答有三个预定事实项，可同时出现有依据和无依据的内容。之后可扩展到五个主体的信息汇总。当前不研究搜索策略本身，也不把历史百科问答直接当成真实情报研判效果。

判断依据分两层：

- 数据层：资料不足时，模型实际是否给出了无依据的具体陈述，而不是承认未查到。
- 方法层：在未用于训练的新问题上，内部状态探针是否比简单对照更能找出风险事实项；误报有依据内容的比例是多少。

高风险分数只表示统计上的复查优先级。不能凭一个探针分数或注意力数值证明模型内部“正在猜”。

## 2. 具体使用的数据

### 2.1 首轮主数据：HotpotQA 的比较类问答

选择 HotpotQA 的 `distractor` 数据中 `type=comparison` 的问题。这个公开数据包含问题、标准答案、相关段落，以及支持答案的句子位置。优先使用其英文原文，避免首轮混入翻译误差。[官方数据与许可说明](https://hotpotqa.github.io/)

首轮筛选规则：

1. 涉及两个真实主体，可以拆成“主体 A 的一个属性、主体 B 的同一属性、比较结论”三个事实项。
2. 优先选择年份、国籍、地点等有明确答案的属性；排除观点判断、预测、指代不清、日期冲突和无法明确比较的题目。
3. 两个属性都能在完整材料中找到依据，比较结论可以由这些属性推出，且与原题标准答案一致。
4. 移除其中一个主体的关键资料后，剩余材料确实不能推出该主体属性及相应比较结论。逐段检查，不能只删除官方标出的那一句就认定证据已经消失。
5. 能保留另一主体的有效资料，形成同一回答内的局部对照。
6. 筛选在生成回答之前完成，不按模型是否容易犯错筛题。

现已通过公开预览接口核对 5 条原始记录，字段和真实例子见 [数据核对记录](planning/source_audit.json) 与 [原始预览](planning/hotpotqa_preview.json)。这 5 条及共享材料的题组只作开发参考，不进入之后的独立测试。尚未证明有多少条满足上述完整筛选规则，30 题和扩展规模均为采样目标。

原始下载入口的 HTTPS 连接本次超时；公开预览接口可访问。正式取数时保存下载来源、数据版本、文件哈希与 CC BY-SA 4.0 许可；预览不是已冻结的正式实验数据。

### 2.2 RAGTruth 在这一轮的用途

本地 RAGTruth 有 989 条 QA 来源记录，其 `source_info` 包含 `question` 和 `passages`，没有统一的标准答案字段；已有回答的人工错误标注不能直接转给 Qwen 新生成的答案。它保留为后续自然问答验证材料及标注规则参考，本轮不把它和 HotpotQA 混合计算主指标。[RAGTruth 官方说明](https://github.com/ParticleMedia/RAGTruth)

### 2.3 一个真实来源的设计示例

HotpotQA ID：`5a8b57f25542995d1e6f1371`。原题询问 Scott Derrickson 和 Ed Wood 的国籍是否相同，标准答案为 yes。原始依据是两人各自条目中的第 0 句，均说明其为美国人。这些内容来自数据集记录，本轮没有另行核验现实世界事实。

将任务明确为三个回答项：

| 回答项 | 问什么 | 完整材料中的参考答案 |
|---|---|---|
| 1 | Scott Derrickson 的国籍是什么？ | American |
| 2 | Ed Wood 的国籍是什么？ | American |
| 3 | 两人的国籍是否相同？ | Yes |

完整条件提供两人的有效资料；缺失条件拿走 Ed Wood 的有效资料，并加入一段不回答该属性的背景资料。以下是说明标注规则的假设回答，不是已经取得的模型输出，也不作为提示或示例展示给生成模型：

| 缺失条件下的假设输出 | 对当前材料的判断 | 相对完整参考的判断 |
|---|---|---|
| Scott Derrickson is American. | 有依据 | 正确 |
| Ed Wood was American. | 无依据的具体陈述 | 正确 |
| Ed Wood was Australian. | 无依据的具体陈述 | 错误 |
| Ed Wood's nationality cannot be determined from these results. | 承认资料不足 | 不作事实对错判定 |
| They had the same nationality. | 比较所需证据不完整 | 正确 |

这里必须保留“无依据但答对”的情况。它仍属于本研究的复查对象，不能自动说成现实事实错误。

## 3. 如何构造完整与缺失资料

每个问题产生两个输入版本；同题的提问、回答要求及解码设置相同。

| 条件 | 模型看到的资料 | 作用 |
|---|---|---|
| 完整 | 两段有效资料，加两段不直接回答问题的背景资料 | 检查有依据时是否仍会乱答或误报 |
| 缺失 | 保留其中一段有效资料；另一段换成背景资料，合计仍为四段 | 模拟搜索只覆盖部分主体 |

背景资料优先从同一原始题目的其他段落选择。检查全部四段是否有直接、同义或可推导的答案，避免答案藏在另一段中。替换段与原段的长度差目标不超过 `max(20 tokens, 原段长度的20%)`；不能满足时换候选题并记录原因。所有选材与排除在观察模型输出前完成。

拿走主体 A 还是 B 由固定种子分配，尽量各占一半；材料顺序在题目之间打乱，同题两种条件保持对应位置。模型输入中不出现“完整组”“缺失组”“缺哪条资料”、参考答案或标注。

这同时控制资料条数、输出项数和大致长度，减少探针仅凭文本变短就报警的可能。替换仍会改变材料内容，不能声称所有因素都完全相同；另报告长度、主体名称匹配与位置对照。

## 4. 模型如何回答与如何保存内部状态

### 4.1 被测模型与提示

- 使用已有本地 `Qwen2.5-7B-Instruct-bnb-4bit`，NF4 量化，模型权重全程冻结。
- 输入、回答均先用英文；不给模型标准答案，也不调用外部付费模型生成回答。
- 主设置：`do_sample=false`，`max_new_tokens=256`，单请求运行。每题每种资料版本生成一次；后续多次采样另设实验，不把重复生成当作独立问题。
- 问题与资料合计不超过 3072 个 Qwen token；完整材料超限时在生成前排除，不截去关键资料。
- 超长输出截断、缺项、额外事实和格式偏离均保留日志，不选择性重试到得到满意答案。

共同系统提示固定为 `You are a helpful assistant.`。用户提示只包含正常任务、搜索结果和便于逐项监测的输出格式。完整模板见 [正常提问模板](prompts/answer.txt)，核心要求如下；正式运行保存填入内容后的全部提示及哈希：

> Please answer the following questions using these search results. Write one short sentence for each numbered item.

其后依次放三个问题和四段搜索结果。不会告诉模型材料是否充足，不提供拒答措辞或拒答示例，不加入“只能使用有依据的信息”“不要编造”等额外行为提示；也不要求模型必须给出具体答案。该规则覆盖系统消息、用户消息与示例，两个材料条件使用同一模板。

如果模型在正常提问下主动说不知道、表示不确定或没有回答某项，原样保留并单独计数。评测侧仍判断资料支持情况，但不会把这个判断提前告诉生成模型。

三个子问题在生成前根据原题确定，每项只询问一个属性或一个比较结论。全体回答项都进入监测，不先用旧探针筛选几个可疑句子。

### 4.2 监测单位和时刻

主单位是一个预先规定的事实回答项，通常对应一句简短陈述。模型写完该项后即可打分，不依赖后面的回答。这里的 F1 是“事实项风险分类 F1”，不是逐 token F1，也不是整份回答 F1。

保存实际生成的 token ID、字符偏移与每项范围。探针读取该项最后一个内容 token 已被模型读入后的状态；跳过尾部空白和单纯格式符。边界按预定编号与换行解析，不读取错误标签决定边界。

如果返回结果把多个事实写进同一项，原样保留并逐条记录依据，主标签为“这一项是否含风险陈述”，同时报告这种情况的比例。不能把该项分数冒称每个词的风险。若编号解析不可靠，则记录监测失败，并在端到端结果中计入；人工边界结果只能另列作诊断。

### 4.3 特征提取的关键检查

Qwen 共有 28 层，每层隐藏状态 3584 维。预留第 7、14、21、28 层的状态；层编号按完成的 Transformer 层数计，第 28 层的最终归一化处理需记录清楚。

生成 API 返回的某一步状态可能对应预测下一个 token，不能直接当成当前 token 已生成后的状态。实现时保存模型自己的生成序列，必要时用相同提示和这些 token 做因果重放。用逐前缀前向计算核对至少两个样例，验证位置、logits 与特征一致性。重放的是该模型本次自己的输出，不能换成数据集里其他模型的回答。

只保存候选层和所需状态，避免在 8GB 显存中保留所有历史中间量。统计量与判定阈值的数值容差在工程检查中确定并记录。

## 5. 标签怎样得到

建立两份材料：模型可见输入和评测侧完整证据表。完整证据表在生成前写好，记录每个目标事实的参考值、来源标题、句子位置，以及每种资料版本支持哪些目标事实。

生成后对实际回答重新标注三个字段：

| 字段 | 取值 | 含义 |
|---|---|---|
| `stance` | asserted / tentative / abstained / missing | 作出事实陈述、明确假设推测、承认不足、没有回答 |
| `evidence_relation` | supported / unsupported / contradicted / unresolved | 当前提供的全部资料是否支持这项实际内容 |
| `reference_correctness` | correct / incorrect / unresolved / not_applicable | 与完整参考资料及原题答案是否一致 |

主二分类限于实际作出的事实陈述：

- `risk=0`：asserted 且 supported。
- `risk=1`：asserted 且 unsupported 或 contradicted；两种子类分别报告。
- 明确拒答、缺项不混入“正常事实”负类，单独统计，以免探针只学会识别“我不知道”。明确标为假设的内容与无法判清依据的内容另报，不当作已知正常。
- 对“可能”等表达按句子实际含义判断是否只是明确假设，不能用关键词规则自动豁免其中的事实断言。

资料缺失的标志只用于记录实验条件，不能直接充当输出风险标签。有依据的推导可以标 supported，不要求逐字复制；材料未出现同一个词也不等于无依据。

标注时隐藏探针、置信度和核查模型分数，记录可追溯的证据位置。确定的数字、日期及名称可以按事先维护的别名表辅助核对，复杂改写需逐条复核。若首轮由本助手辅助标注，明确标为“助手按证据核对”，不能冒称独立人工金标准；供论文使用的测试标签及训练标签抽样需由研究者独立复核，分歧保留到裁决。

## 6. 怎样训练探针

### 6.1 30 题试跑

先构造 30 个不共享关键来源的题组，每题两个资料版本、三个回答项：共 60 份回答，最多 180 个事实项。拒答等不进入主二分类，实际可训练数量可能更少。

试跑固定第 21 层，使用单个事实项结束处的 3584 维状态。训练一个逻辑回归分类器：StandardScaler、L2 正则、`C=0.1`、`class_weight=balanced`、`solver=liblinear`、`max_iter=2000`、随机种子 `20260910`。只有这个小分类器被训练，Qwen 不更新。

| 子集 | 题组数 | 回答份数 | 最多事实项 | 用途 |
|---|---:|---:|---:|---|
| 训练 | 18 | 36 | 108 | 学习状态与标签之间的对应关系 |
| 验证 | 6 | 12 | 36 | 选择报警阈值 |
| 留出检查 | 6 | 12 | 36 | 一次性检查流程和错误类型 |

划分在生成前固定，同题两个条件一起划分。若共享主体、关键来源、展示背景段落或替换段落，合并为一组；不能为凑数拆开同组。样本量按独立组计，事实项之间不视为独立采样。

这 6 个留出题组只提供小样本检查，不能据其 F1 声称可靠达到 0.7。若某子集缺少正例或负例，相关指标写无法估计，不伪造或移动样本补齐。先报告拒答率、类别数量与分数分布，再判断是否需要增加自然生成样本。

### 6.2 扩大阶段的预定方案

待试跑证明数据可标、状态可正确提取后，目标另取 300 个新题组，分为 180 训练、60 验证、60 测试；试跑和设计预览题组不进入新的独立测试。共 600 份回答、最多 1800 个事实项。实际合格数量和标注成本不足时如实调整计划，不声称这些数据已经建好。

扩大阶段候选仅为 4 层 × 3 个 C 值，共 12 种：层 `[7,14,21,28]`，`C=[0.01,0.1,1.0]`，其余不变。每种只使用一个层，不先拼接、PCA、复杂网络或多轮选句。

StandardScaler 和分类器只拟合训练集。用验证集风险类 F1 选层、正则参数与阈值；并列时依次选精确率较高、C 较小、层编号较小者。同一候选阈值并列时选较高阈值。阈值候选为验证分数的不同取值，并包含全报与全不报的端点。冻结后评测测试集一次，不根据测试 F1 重选方案。

内部状态之外的参考答案、删除标志、证据覆盖标签、问题 ID、人工标注说明均不得进入探针输入。

## 7. 和哪些基线比较

所有方法使用同一份生成回答、同一事实项边界、同一标签与划分。需要拟合的方法只看训练集；阈值均由验证集确定。

| 方法 | 使用的信息 | 目的与成本 |
|---|---|---|
| 全部报风险、全部报正常 | 不读模型状态 | 判断类别比例本身能带来多高的 F1 |
| 表面信息分类器 | 项目长度、位置、三种项目角色、资料长度、词语重合率、主体名是否出现在资料中 | 检查是否只学到了格式、位置或关键词线索；无额外模型调用 |
| 生成不确定性 | 实际答案 token 的平均负对数概率、平均预测熵 | 比较常见“模型生成得不确定”的信号；无额外调用 |
| 模型自评把握 | 给同一本地 Qwen 当前问题、当前材料及截至该项的回答，要求评价该项有依据的把握，0–100 | 对照口头自信；每个已作答事实项增加一次短调用 |
| 直接核对资料 | 同一 Qwen 看当前资料与事实项，三选一：有支持／资料不足以支持／与资料矛盾 | 三选一相对概率中后两项之和作为风险；每项一次前向计算 |
| 内部状态探针 | 原始生成过程中该事实项结束处的隐藏状态 | 主方法；特征提取外只增加小分类器计算 |

表面信息分类器使用与试跑探针相同的固定逻辑回归配置。扩大时允许同样的三个 C 值。生成不确定性的两个单分数分别评测，不能按测试结果择优报告。

自评与直接核查都使用同一个 Qwen，属于额外调用，不是另一个外部评审模型。先完成并冻结主回答，再以独立请求运行这些基线；核查提示中的分类选项与核查结果不进入原始回答的上下文，也不触发重新生成。它们的结果不能参与制作标签。直接核查只取相对候选分数，不能把它叫作校准后的幻觉概率。

首轮只比较这些方法，不先训练融合器。若探针没有超过直接核查，应报告“未证明内部状态带来额外检测优势”，也可比较成本差异；不能只挑较弱基线宣布成功。

## 8. 怎样测试与解释

### 8.1 主指标：事实项风险类 F1

测试集每个有效事实项只产生一个风险分数和一次判定。所有项都检查，不存在先选三个高风险句子的入口。

- TP：无依据或冲突的事实项，被报为风险。
- FP：有依据的事实项，被误报为风险。
- FN：无依据或冲突的事实项，被漏掉。
- TN：有依据的事实项，被正确保留。
- Precision = TP / (TP + FP)；Recall = TP / (TP + FN)；F1 = 2TP / (2TP + FP + FN)。

同时给出上述原始计数、正例比例、假阳性率、PR-AUC 和 AUROC。无正例、无负例或分母为零时注明不可估计的原因。不要把 AUROC 写成 F1。

### 8.2 必须分别看的结果

1. 完整材料与缺失材料各自的表现。
2. “无依据但与完整参考一致”“无依据且与完整参考不一致”“与当前材料冲突”三个子类的检出率。
3. 同一份回答内同时存在正常和风险事实项时，风险项是否排得更高。
4. 只复查风险最高 20% 的已作答事实项，能找到多少风险、误查多少正常项；相同分数按固定次序处理。
5. 资料缺失对拒答、实际作答、正常正确内容和无依据断言数量的影响，按所有预定回答项计分母。
6. 格式解析失败、证据标签 unresolved、多事实项等的数量，以及端到端监测覆盖率。

完整／缺失的两个回答可能内容不同，所以先按同一问题的目标事实项对齐。未受删除影响且两种条件均有依据的事实项，是检查整体风险是否无差别升高的重要对照。不要把这种行为干预结果直接解释成内部机制的因果证明。

扩大阶段按题组进行 2000 次配对 bootstrap，报告 F1 及相对基线差值的 95% 区间；同一题的所有事实项和两个条件一起重采样。分开报告自动解析可用部分与把解析失败算入漏检的端到端结果。主结果覆盖所有可判定事实项，不能只保留出错回答或分数好看的句子。

### 8.3 怎样判断值得继续

30 题阶段先回答：是否出现足够的自然风险陈述、标注能否稳定、模型状态是否有区分迹象。若大部分缺失项都明确拒答，这是生成行为的结果；不能强迫乱答来凑主实验正例。可以按预先确定的候选顺序增加问题，并如实报告自然类别比例。

扩大阶段的目标是风险类 F1 > 0.70，同时检验是否超过全报风险及其他基线，并观察误报和区间。F1 超过 0.70 本身不充分：当风险比例很高时，全报风险也可能达到这一分数。

若没有优势，分别检查样本量、标签一致性、置信度校准和信息来源对照，保留负结果。不得重用已查看的测试集调参后继续称其独立测试。

## 10. 与论文和旧实验的关系

[Sufficient Context，ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/file/33dffa2e3d2ab74a783d1a8c292f66d9-Paper-Conference.pdf) 提供“材料是否充足与答案是否正确分开评估”的设计依据。这一轮新增的待验证问题是局部事实项的生成状态能否用于风险监测；本方案不是该论文全部算法的复现，也不预设创新性已被证明。

前五轮主要是新闻摘要既有回答的重放与后续核查。这一轮更换了问题、生成方式、标签含义和评价单位，旧的 F1、阈值和探针权重均不作为本轮效果。事实项级结果成立后，再独立设计逐词定位、中文公开情报材料和真实联网搜索验证。
