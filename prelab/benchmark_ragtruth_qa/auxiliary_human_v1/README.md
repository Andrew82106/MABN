这批数据已导出并完成词元对齐，**尚未用于训练**。目的在于补充不同资料和更多事实冲突；最终评测仍使用原问答场景，不把新闻概括的成绩当作问答成绩。

来源为已经下载的 RAGTruth 官方训练部分，沿用完整人工字符标签，包括全部四类错误及原标记。六个模型对同一资料的回答始终同组，不能把9,678份回答称为9,678个独立问题。生成器身份不作为检测输入。

隔离规则在导出前执行：按连续20个相同规范化单词连接资料；商家资料额外按名称、地址、城市、州连接。任何连接到官方测试资料或原QA非训练资料的辅助训练来源都隔离，共62个来源。没有解析这些隔离来源或官方测试回答的正文、质量字段和标签；资料内容与身份元数据仅用于隔离。该规则能检查直接材料复用，不能证明所有改写、实体别名和事件完全独立。

仅保留原 `quality=good`，另外6份非good只保留排除索引。原标签与原回答字符全部匹配；没有修补、缩短或重新生成标签。全部9,678份都保留，未依据检测成绩选择样本。

输入准备复用现有Llama分词和标签映射规则：1,994,830个回答词元，其中79,320个风险词元；描述性4词元窗口1,965,108个，其中112,125个风险窗口。完整资料＋原任务指令＋原回答经ModernBERT分词后最长2,629词元，无截断、无异常。该数值只说明可组成输入，尚未证明最长输入能通过本机GPU训练。

后续采用前需要固定辅助任务权重与训练轮数，让需要比较的方法使用同一份数据；原QA校准和封存测试不变。当前QA-only的训练继续按原方案完成，不中途加入辅助数据。
