# 原场景迁移评测

已准备原 R16 **训练部分**的602份回答，来自301个问题、278个资料组。完整/局部资料、原生成回答和原标签均保留。QA-only选中模型的推理及计分已完成，辅助迁移模型尚未完成训练。

这些问题原本使用正常提问方式提供搜索结果，没有额外提示模型可以回答“资料不足”。当前每份回答只有一个待答项，不能把本数据描述成已覆盖五主体综合研判。

先按公开 QA 开发数据的既定规则选定检测器，再冻结模型用于这里。分别报告：

1. 原 QA 阈值直接迁移的成绩。
2. 在已有五折划分里，仅用各折校准组选择阈值、在各折评估组计算成绩。这里不重新训练神经网络。

仍按原 Qwen 词元坐标计算4词元窗口；共12222个候选窗口，其中9526个参与局部定位评测。整答评测598份，包含117份正常拒答作为负例；4份未决答案保留未决状态。

对照保留 Lookback、ReDeEP 及现有最强组合 `local_slots_fusion_smooth_global`（原开发定位F1为0.7090，整答0.8000）。几何检查文件中的 `slots_base_smooth_global` 是另一个较弱的回放检查对象，不是最强组合。

原 R16 标签是助手标注与独立助手复核，`human_gold=false`。本迁移使用已反复查看的训练开发数据，不能称为新测试。原 R16 验证/测试和 RAGTruth 官方测试继续封存。

材料检查未发现本数据与公开 QA 训练材料、9678份辅助数据存在连续20个规范化词重用；这不证明实体或事件完全独立。见 `../results/r16_material_reuse_check_v1/REPORT.md`。

执行入口：`../src/run_control_scene_transfer.py`。上游模型未完成时直接退出，不加载GPU；上游完成后仍须按唯一GPU队列安排推理。
