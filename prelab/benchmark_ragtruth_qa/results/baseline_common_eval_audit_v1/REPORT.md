# 三项正式基线统一评测独立审计

审计日期：2026-09-12。本轮只读检查代码、冻结清单和已有结果；未运行 GPU、未读取官方 test、未重训或改写任何模型与分数。

## 结论

Lookback Lens、LUMINA、GHOST 的**正式主比较已经按本项目口径**完成，不再拿各自论文指标直接排位。三者共同使用同一 cal159、154 个材料组、42,241 个 4 原始 BPE 步长 1 窗口、100 个风险回答和 5,984 个风险窗口；窗口与整答分别用同一 `F1 → precision → 较高阈值` 规则选阈值，并统一报告 F1、AUROC、AP。作者原生指标只在单独一列复核。

统一映射均为模型外、确定性、零参数，映射位置不读取金标：

| 方法 | 冻结原生输出 | 统一映射 | 是否改变模型/原生分数 |
|---|---|---|---|
| Lookback Lens | 8-BPE 滑窗风险概率 | 覆盖某 raw token 的 8-BPE 分数求均值，再对 4-BPE 窗求均值；整答取窗最大值 | 否 |
| LUMINA | 每个回答 token 的固定 `0.5×IPR−0.5×MMD²` | 4-BPE 窗求均值；整答取窗最大值 | 否 |
| GHOST | 一个整答 RF 风险概率 | 原值广播到该回答全部 4-BPE 窗 | 否；原生无定位能力 |

独立复算得到的统一开发成绩与正式表完全一致：Lookback `0.600882 / 0.845455`，LUMINA `0.331299 / 0.785047`，GHOST `0.320361 / 0.772201`，依次为窗口 F1 / 整答 F1。16 个冻结实现哈希全部匹配，六组完成文件的清单哈希无异常。

## 仍需保留的限制

1. **GHOST 不是完整作者训练流程复现。** 当前实现固定使用论文最终 750 树 RF 参数，但没有重跑论文的 50 组五折随机搜索，`random_state=42` 也是本地约定。因此它只能称“论文最终结构/参数迁移”。若把“作者训练方式完全不变”理解为连超参搜索和随机种子都必须复现，这一项尚不满足。
2. 三项都使用本地 Llama NF4 教师强制重放及当前输入模板，Lookback/GHOST 的上游抽取还有本地读取位置约定。它们不是端到端、逐数值官方复现；正式文档已经以“结构迁移/公式迁移”命名。
3. GHOST 统一适配器保存的 fit 侧诊断只覆盖原 634 条 fit，而其 RF 实际用扩充后的 3,680 条 fit 训练。正式表只比较共同 cal159，所以已报告分数不受影响；GHOST 的 fit 侧适配指标不能拿来做统一比较。
4. cal159 已反复用于开发并同时选择、报告 F1 最优阈值。三项当前都是开发成绩，不能写成封存测试结论。

没有发现适配器给基线增加学习头、融合本项目特征、按金标选择映射位置，或为了压低基线而改写分数。若论文只展示正式统一结果，应引用 `FORMAL_BASELINE_RESULTS.md`；各论文原生尺度只作附录复核。
