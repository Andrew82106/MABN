# PsiloQA → QA 迁移入口：CPU 已准备

**准备、CPU 小模型循环检查和冻结检查均 actual exit 0。尚未启动 GPU、正式模型训练或分数组合。** 入口为 `src/run_psiloqa_transfer.py`，产物独立保存在本目录；旧源码、旧实验、训练数据和三份总状态文档未改。

固定流程是 fresh generic ModernBERT-base（原 seed 20261005、两类头）先训练 **15,847 条 PsiloQA 一轮**，再接原 **3,680 条 QA 三轮**。不是从任何已拟合的 QA、NLI、FAVA checkpoint 开始，也不混入 FAVA 数据。CUDA 前向/梯度检查点用原 BF16；参数、梯度、AdamW 状态、logit 差、字符映射和 BCE 保持 FP32。

辅助按 **6,862 个材料组 → 组内答案 → 答内 lexical 词元** 等权，再用辅助训练内二类因子、最后按组重归一，总质量 **1,101,613**。每组 base/loss 质量均为 160.538181288；类别因子为 `[0.94604723, 1.06047876]`。组重归一后不宣称正负总质量仍各半。

635 个无标记答案和 3 个仅句号被标风险的答案均保留。后 3 答的整答原 risk=1、lexical risk=0；权重和 BCE 只读 `risk_mask`，`answer_risk` 不进输入或损失。参考答案、生成器身份也不进模型。辅助 raw BPE 只是共享字符映射，不能称原生成轨迹；标签均为自动银标。

QA 的完整输入与权重文件逐字节复用，前三轮顺序逐值相同。AdamW 固定 lr `1e-5`、wd `.01`、clip `1`、8 答梯度累积、无 scheduler；阶段切换不重建优化器、不重设随机种子。预期更新为 **1,981 → 2,441 → 2,901 → 3,361**，辅助末批 7 答按实际批大小归一。辅助只保存末 checkpoint 和在线损失，不看校准或选轮；只在三轮 QA 中按原双阈值和同一候选的两项 F1 选型，全部三轮保留。

CPU 检查使用真实两层 Tiny ModernBERT，调用同一生产 `train_epoch`，实际完成辅助 15 答（8＋7）及三轮合成 QA。一个 AdamW 的 step 为 `2→3→4→5`，动量持续、骨干与输出头梯度有效、CPU 前向及重算无 autocast、FP32 状态成立。翻转 `answer_risk` 元数据不改变目标或权重；真实辅助索引读取以及原 QA 三项复用检查通过。没有在真实标注上拟合大模型。
