# 局部修复对：训练目标已做CPU原型

已有10040个单处修复银标候选，其中10036对结构可用；最终训练数须等完整词元映射后确定。每个输入只含原资料、空问题和一个版本的回答。作者建议修复视为有噪声的偏好，不是独立核真的整答。

`src/local_repair_pair_loss.py` 实现两个使用相同局部位置的目标：

- 对照：原错误片段风险1、建议修复片段风险0的局部银标BCE，两侧各占一半，不随两侧词元数量改变权重。
- 排序版本：同一BCE加 `softplus(1 - 原片段平均logit + 修复片段平均logit)`，固定系数1。其余位置没有直接真/假标签。

计划在相同配对数据、材料→原答→pair权重、输入顺序和训练预算下比较系数0与1。排序使同一资料下的两个局部风险直接比较；它没有增加新的事实认证，也不保证抗噪或提高F1。通用base初值、辅助一轮接原QA三轮的完整训练协议尚未实现/冻结，不能称已有训练结果。

CPU原型实际exit0，4.63秒：验证未监督位置不直接影响损失、两侧不同目标长度仍等权、系数0还原对照、翻转偏好增加示例损失。真实随机两层ModernBERT对两个合成输入完成前向、反传及一步更新；目标之外的输出logit无直接梯度，资料的嵌入仍经注意力获得梯度。没有读取真实数据或预训练权重、没有GPU、没有改变QA评测。
