仅查看原634份训练回答；不读取测试、不改标签、不增删样本、不重新调阈值。

固定原HARP陈述传播与tail2选中模型的原阈值，两者都没有高亮命中的显性冲突原标注段共79处。按回答ID与段编号排序，读取前4处，涉及3份回答；这是故障样例，不是随机抽样。

看到两种容易遗漏的错误：

- **引用来源不对。** 例如只提供3份资料，回答最后写成依据“资料2至6”；又例如一句内容来自资料1，引用却写资料2。
- **对资料是否足够的判断不对。** 回答先根据资料列出信息，最后又断言资料未提供相关信息。判这类陈述需要同时看问题、资料及完整回答，局部词元片段不够。

进一步只数原训练标签：109处显性冲突中，45处的标注文字含明确的“passage＋编号”。这是文字线索计数，不是新增人工错误分类，也不代表其余64处与引用无关；该线索不作为模型输入或筛选标准。

全资料核查中的“某份资料能支持即可”聚合有明确局限：它未单独要求证据来自回答所引用的资料。它可能把“内容在其他资料中是真的”和“引用位置正确”混为一谈。这是待检验的解释，不能据此断言全部漏报来自同一原因。
