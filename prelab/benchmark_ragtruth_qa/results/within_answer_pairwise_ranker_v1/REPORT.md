# 同答细节成对排序器 v1：开发结果

fit组留出窗口F1：0.897057。fit阈值直接迁移到cal：0.648420；共同评测F1Opt：0.657733。派生整答F1：0.816754；保留的current整答头F1：0.891089。

模型、输入和fit阈值冻结后才读取cal分数；共同F1Opt仅是既定评测指标，不用于回改模型。上游多数fit分数仍非OOF，故本轮不能替代尚缺large fold2的完整交叉拟合。

结论：该候选不能替换当前窗口模型（0.690281），但保留为一次有效的过拟合诊断。即使元分类器按材料组做5折交叉验证，窗口F1仍从fit OOF的0.897057降至cal的0.648420，AUROC也从0.993768降至0.895048；这说明只在最后一层做group-CV不足以消除上游fit内训练分数造成的乐观偏差。完整的端到端判断必须先使用上游OOF分数。

系数审计显示模型主要依赖`nli_init`和`large`的绝对分数及同答排序。它没有新增“具体主张—具体来源”条件下的证据冲突信号，因此不能直接解决显式引用Evident Conflict召回9.77%、coverage-gap Evident Conflict召回1.49%的问题；本轮只应称为定位与过拟合诊断。

下一步：完成large上游交叉拟合，再用完全OOF的上游特征重训；同时增加原子主张与对应来源段落的蕴含、矛盾和缺失覆盖信号。现有整答头继续保留，其F1为0.891089。
