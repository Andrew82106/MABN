# 四维信号的当前词元信息限制

独立CPU干预测试已验证：在固定长度与共同前缀下，替换当前及后续词元，当前位置的四维预读特征仍逐值相同。这是因果性正确的证据，也说明它们尚未包含“实际选中了哪个词”的信息。选中词的NLL依赖该词ID，所以与这些特征不同；既有LB＋NLL和HARP＋LB＋NLL对照继续保留。

后续可检验一个不需要再次调用大模型的明确对照：对于除最后一词以外的词元，下一位置的预读状态就是读入本词后的状态。可从完整四维缓存派生窗口内可取得的读后特征，明确最后一词没有这项缓存；不得伪造其数值、删除该词标签或减少评测分母。若实施，需冻结边界缺失处理，并给所有基线相同特征和固定参数预算。

当前仅记录可检验的信息限制；没有实施派生特征、训练或获得新F1。它不能证明四维特征无用，也不能预先证明读后特征更好。第一阶段仍使用既定四维窗口均值，先获得可比较结果。
