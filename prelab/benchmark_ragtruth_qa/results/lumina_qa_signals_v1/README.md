# LUMINA公共QA薄接口

src/lumina_qa_signals.py只连接已固定作者公式，不另造分类器。输入为两个资料前缀和同一完整回答；每个位置都在读入该回答词元前取状态。IPR仍按原代码处理全部输出层（末层再次norm），MMD仍保留top100未重归一化质量差项，主分数固定为0.5×IPR−0.5×MMD。

输出7列：IPR、MMD、主分数，以及两侧的当前回答词元概率和最大词元概率。后4列仅保留供诊断，尚未加入评分或训练。IPR包含当前所选词元概率校正，因此和GHOST四个纯前缀分布/几何摘要的含义不同。

真实TinyLlama CPU检查已实际exit0：前一位置轴及稠密IPR误差0、稠密MMD误差约4.8e-8；重复、未来后缀干预和相同资料的MMD为0均exact。未载入预训练权重、读取数据、使用GPU或产生实验F1。CUDA真实量化模型检查须另行执行。
