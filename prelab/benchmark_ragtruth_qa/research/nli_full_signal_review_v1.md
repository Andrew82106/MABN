# 冻结 NLI 全量信号：独立方法审查

**定位：这是 ours 的额外语义核查信号，不是原生成模型白盒探针，也不是任何正式 baseline 的改版。** 正式 Lookback/LUMINA/GHOST 等输入、训练、输出和后处理全部保持。本轮只读已有报告/源码；未编码、训练、调用模型或读取 official_test150。

## 已有证据及不能据此作出的推断

- [12例 NLI smoke](nli_ec_smoke_v1/README.md) 直接用金标错误跨度和人工摘录：全摘录拼接时，8个漏检案例中4个 contradiction>.5；取摘录最大值时6个。**这不是无标签检测，且没有安全片段的误报分母**，不可用于训练特征、选阈值或声称增量。
- [EC案例核查](current_ec_case_review_v1/README.md) 的17001/12687/15519确实涉及参与者、因果或比较方向；13575/14229还要追踪跨句/列表来源归属。12例未发现原输入截断或坐标丢失，不能把新方法的收益预先解释为修复旧映射。
- 旧 MiniCheck 句分数广播已出现整句过报风险。[单来源支持差](../results/cited_source_semantic_lr_v1/REPORT.md) 和[标题继承支持差](../results/citation_heading_semantic_lr_v1/REPORT.md) 的匹配改进很小或为负。新方案应检验**明确的矛盾信号是否有用**，而不是再次把任何“不支持”都命名为矛盾。
- 16929的可见资料没有金标解释声称的预热禁令；13575的金标解释还写错正确来源编号。保留原人标计分，但 NLI contradiction 与 EC 人标并非严格同义。

## A. 无标签切分：先检查会不会改变命题

- [ ] 切分器只接收原回答文字；不得读取人标 span、原错误类型、当前分数或上述12例摘录。协议、版本与排序在全量分数生成前冻结。
- [ ] 逐段保存原文半开区间和 exact slice。所有非空白字符都必须有可追溯归属；禁止清洗后直接沿用旧坐标、删除拒答/难句、按“是否像事实”决定评测分母。
- [ ] 最少覆盖：小数/年份日期、缩写、编号列表、冒号标题、跨行句、括号引文、分号、引号、`not … but …`、金额与百分比、单位。不能把句点编号当句末，也不能把比较双方或否定词拆开。
- [ ] “4. Choose the burning speed …” 与它上方“Passage 1”的关系不能因分段丢失；“$35 (target)”也不是脱离前句后仍自足的命题。保存父段/列表标题、指代/片段状态，不能把碎片 NLI 输出直接解释为事实判断。
- [ ] 不应机械沿用旧 MiniCheck 的96-BPE短句上限；它是旧模型资源适配，不是 NLI 必需的命题边界。若采用新的固定长段切分，需单列边界依赖限制，不能依据 cal 正确率决定如何合并。
- [ ] 片段级分数广播并不构成精确 token 定位：同句混合正确与错误事实，会提高召回同时扩张误报。必须保存边界信息供评测分解，不能只展示命中的词。

建议接口以连续原文句/列表项为主，保留原父段及标题关系；没有证据证明必须再细切成独立短语。若想把原上级标题拼入 NLI hypothesis，应冻结为明确的上下文视图，并区分“模型输入文本”和“风险映射回的正文范围”，不能临时手工补主语。

## B. 四个资料视图与三类概率：全部保留

- [ ] 冻结现有 `tasksource/ModernBERT-base-nli` revision `de4ab7e77845098b7fab7f6ab9d370ddff27b19c`、资产哈希、实际 NLI 分类头、tokenizer与精度；核对 `id2label={0:entailment,1:neutral,2:contradiction}`，不能调用此前丢弃 NLI 头的 QA 微调模型来冒充此信号。
- [ ] 对**每个**自动片段运行相同四个 premise：原三份资料的完整拼接、passage1、passage2、passage3。三来源用已有 `build_cited_source_semantic.split_full_sources` 的原始 header/body 边界，三者拼接逐字恢复全资料。不能只给有引用、低原分数或 gold EC 的片段计算。
- [ ] premise 只含实际资料；原问题、回答其他陈述、标准答案都不能冒充事实证据。问题如作为另一个辅助输入，必须明确标为问题而非可信材料。本次无需从 question 推造新事实。
- [ ] 以真正的 premise/hypothesis pair tokenizer 编码；逐项保存精确文本/字符范围、完整 input IDs、输入长度、资料视图ID、模型签名，`truncation=False`。实际超过 checkpoint 2048 上限时停止并报告，不能静默删尾、删例或把分块结果继续称 full-context。
- [ ] 原始输出固定保留 `logits[segment,4,3]` 与同形状 E/N/C 概率（有限、总和约1），不只保存 max-C 或 `1-E`。这是12个概率分量，不是12个独立信息维度。
- [ ] 单来源 neutral 不等于整段无依据；证据可能分布在多个 passage。某一来源 contradiction 高也不等于回答整体错，可能是资料自身冲突、实体指代不同或无关段误判。尤其不能先把3个 C 取 max 当真实风险标签。
- [ ] full-context E高而三个单源E均低，可能提示联合支持；full-context C与单源C不一致，也可能只是长度/干扰效应。保留这些差异供学习，不能预先给出真/假逻辑结论。最终任何归约公式都需在看全量成绩前固定。

## C. 引用作用域：可观察特征，不是自动标签

- [ ] 来源号解析、有效性、显式引用/标题继承/未知状态均只来自原文字；数字1/2/3只用于索引对应资料，不能直接编码为“来源2更危险”的类别特征。
- [ ] 可复用旧直接引用与标题作用域索引。若扩展解析，必须预先说明结束条件、同级新标题、嵌套列表、直接引用覆盖继承、句尾引用的规则；未知语法与纯提及来源保留未知，不能猜错引。
- [ ] 合法候选特征包括：是否有引用、是否继承、scope覆盖比例、有效/无效ID比例，以及三类概率在被引/非被引/全资料间的差异。无引用仍保留四视图原始概率；引用派生量的零值需配缺省标志，不能解释成“没有风险”。
- [ ] 多个被引来源不是单来源最大支持的同义词；若当前只算四视图，不得声称额外检验了每个被引来源子集的联合蕴含。
- [ ] 13575需使正文知道上级来源；14229金标却只标来源标题而错误事实在后面。**只把正文矛盾概率广播回正文，无法自动解决后者。** 可先保留“标题→后续片段”的可见关系及分数汇总作为 ours 特征；不能根据金标把风险搬回标题，亦不能直接把某个子句高C扩散到整篇。
- [ ] 无标签接口检查应覆盖范围引用2–6、列表1/2/3、Passage10、Passage1:2、年份数字；前两者应完整解析，后者不应把10截成1，子节语法须明确支持范围。只重命名资料编号并同步重排索引时，解析/派生映射应保持对应关系。

## D. 何种评测能证明“有增量”

1. **先完整性，后成绩。** 片段及四视图覆盖所有预定 fit/cal 回答；原 token IDs/offsets/window IDs逐值对应。当前原生候选轴为634fit＋159cal、210364窗，其中cal42241窗；若抽取3839答，需明确新增3046的用途，不能悄悄扩大匹配控制训练集。原4-BPE长度含标点、可评性仍沿旧 lexical 规则；正常拒答不删。
2. **同一个候选同时报告两级结果。** 与未改动的当前模型作匹配比较：窗口P/R/F1/AP/AUROC、TP/FP/FN及整答P/R/F1。如使用旧模型原阈值的直接诊断，明确阈值固定；如拟合新组合，只用fit学权重，cal按预先固定规则选阈值/模型。不能拼“某个方法最好窗口”与“另一个最好整答”。
3. **检验新增矛盾信息，而不只检验另一份支持分数。** 等预算对照应共享相同四视图推理和同一组合结构，比较仅支持信号与增加N/C及视图差异后的结果；否则无法把改善归因于三类判断。无需扩大超参数搜索。
4. **重点看完全漏报的跨度和代价。** 保存 EC / 无依据类各自召回，当前漏检→新检出、新增FP、原已检出→新漏检。逐金标跨度报告全漏数、any-hit与词元并集覆盖，再报报警片段中安全词元比例。不能把一个跨界4窗擦到一点错误当作整段正确定位；重叠窗也不是独立样本。
5. **专门检查切分制造的FP。** 按离片段边缘的固定距离、列表/标题、显式/继承/无引用、正常拒答分组报告FP及分母；这些组由文字定义。报告整句广播带来的误报面积，以及高C只出现在碎片而父段不同的情况，不能只展示正例。
6. **区分排名改善、阈值移动与独立泛化。** 新增TP和FP要同时看；只有EC召回上升或少数 NLI>.5 的例子不够。基于材料组重采样给差值区间；不按重采样选赢家。当前cal已反复开发，上游不少fit分数仍是训练内分数，NLI来源追溯也有限，不能将门层/组合层交叉拟合说成全流水线独立测试。official_test150继续封存。

**放行条件：无 gold 的分段与四视图输入可复查，原始三类概率完整保留、全轴不丢例，引用只作显式特征，比较同时计召回与新增误报。** 这些条件满足后，该信号值得作固定的小型 ours 增量实验；12例 smoke 与既有初始化失败，都不能预先决定其全量效果。本轮不修改任何 baseline 或现有结果。
