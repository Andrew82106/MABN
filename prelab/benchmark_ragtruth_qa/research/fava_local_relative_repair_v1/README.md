# FAVA：单处相对修复银标可行

**可以落地，不必把修正文认证为整篇正确。** 用同一错误答案，只应用作者标记中的一处实体/关系替换，可以构成有噪声的局部修复偏好；其他错误原样保留，只监督这一处“修后风险低于修前”。这与现有单边错误BCE是不同的训练目标，效果应靠固定人工QA检验。

## 实际规模

只读取已经隔离并冻结的7482个FAVA训练候选与对应官方原train记录；沿上一轮相同定义统计，不按模型或QA分数筛样本：顶层实体/关系节点，恰有一个mark和delete，无嵌套类型，两侧非空且不同，各1–3个空白分隔词。

| 类型 | 局部替换数 | 涉及原回答数 | 既有材料组数 |
|---|---:|---:|---:|
| entity | **5335** | 3434 | 3418 |
| relation | **4705** | 3057 | 3040 |
| 合计去重 | **10040** | **5275** | **5238** |

1216条回答同时有两类，所以回答/组不能逐列简单相加。所有10040处已在内存中检查：原切片exact、单处替换后前后全文exact不变、反向替换exact恢复原答。没有导出成对文本或新增正式标签。

9541处替换的回答还包含其他非空人造错误标记；499处没有其他非空类型节点。后一数字与旧498“全文编辑投影只含单处更改”口径不同：旧检查另排除了一条在类型标签之外还有全局编辑的记录。本方案只按已核坐标修这一处，根本不应用其他编辑，因此仍可证明10040处单补丁可逆，**不能据此称其语义正确或整答已真**。

## 最小实现边界

1. 从原completion的标记树直接获取错误片段`[s,e)`及作者建议的`repair`；不用`str.find`，避免重复词定位错。令原错误答案为`y`，仅构造`y' = y[:s] + repair + y[e:]`；新监督范围为`[s,s+len(repair))`。完整编辑投影及其他纠正文均不参与构造。
2. 两边分别输入相同五段原资料、空问题、各自待检答案；不能把修正版或纠错标记拼给原版作为提示。标题、资料顺序及其他原答字符完全相同。保留原类型及`synthetic=true`；不冒称找回原始未篡改答案。
3. 只比较对应局部的风险，例如以范围内风险logit均值定义`r`，最小相对目标可写为`softplus(r(y')−r(y))`。这只是计划中的一种固定实现，不是本轮已冻结或拟合的超参。均值需按实际对齐的有效字符/词元定义，避免短改长造成求和偏差。未改位置不增添正确标签，也不对修后整答施加负标签。
4. 每个改动变体、原答其他改动和同材料其他回答保留原共享资料组。多改动原答不能因拆出多个对而任意放大权重；应先材料等权，再原答等权，再该答局部对等分。已有隔离范围继续沿用，不重新依据校准分数选数据。
5. 后续若训练，做预算匹配的单边监督/增加局部相对监督对照，固定同一编码器初值、QA阶段、材料、更新预算和选择规则；先明确如何配比再运行。一次只修一处，使监督直接对应“这个事实的局部变化”，而非让模型用整篇改写风格判断。全部结果和失败都保留。

这适用于额外文本核查编码器。若将来要用被测生成模型的内部状态，两边都须各自重放提取，不能把原错误答案的旧trace冒充修正版trace。新文本重新分词后需字符对齐检查；本轮没做tokenize或模型前向。

## 能保证与不能保证

可保证发布标记出处、原错误文本对应、单处字符补丁及可逆性；**不能保证作者建议必然受证据支持、类型永远准确、修正文是原始历史答案，或其他片段已正确**。已有train例子包含不受支持修复和主观措辞被标成实体，因此它是相对修复银标，而不是认证事实金标。没有独立认证不妨碍检验这个有噪声目标；同样，也不能预先声称必然改善关系反转。

DialSumm提供小规模人工局部修复对，可辅助核查定位学习；其单对话结构不提供多来源编号监督。当前FAVA实体/关系对也不自动覆盖“错引passage1/2/3”，需要分别报告适用范围。[DialSumm补充说明](../../auxiliary_dialsumm_review_v1/SILVER_TARGET_ADDENDUM.md)

本轮CPU统计 actual exit0，约1.6秒；输出仅[计数](COUNTS.json)、[按原回答的数量索引](ROW_COUNT_INDEX.jsonl)和[固定审查协议](PROTOCOL.json)。无新正式训练集/标签、无GPU、无训练、无cal/test读取，旧文件未改。
