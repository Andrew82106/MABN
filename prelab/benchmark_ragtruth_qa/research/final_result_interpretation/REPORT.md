# 当前候选与正式基线的校准集结果解释

## 核对结论

当前候选是同一个冻结组合 `semantic_claim__old_tree__large_weight0.4`，不是把两个模型的最好值拼在一起。其窗口分数固定为 `0.6 × p_old + 0.4 × p_large`；整答分数由同一回答的这些窗口分数取最大值得到。两级只是在同一套统一规则下分别选择 F1 最优阈值：窗口阈值 `0.657469850500832`，整答阈值 `0.4566737821091461`。

两级结果也使用同一个 calibration split：159 个回答、154 个材料组、42,241 个合格 4-BPE 步长 1 窗口；正类为 100 个回答和 5,984 个窗口。阈值规则与正式基线一致：先最大化 F1，再按 precision、较高阈值打破并列，预测条件为 `score >= threshold`。

候选分数文件 SHA256 为 `64b3972dd999c9655a302ad04a8709a1866b169a141e6167042e159bf601645f`，与候选 JSON 和独立复算记录一致。这里的“同一 split”仅指共同评测集；各方法的训练数据量、监督与计算预算并不完全相同。

## 严格限制

- 这些都是反复用于开发的 cal159 结果。候选的上游结构、large epoch、混合权重与两级阈值都曾受该校准集影响，存在选择乐观偏差；不能称独立测试、稳定领先或 SOTA。
- 正式基线也按 cal-F1Opt 取阈值，所以阈值评分规则一致；候选使用的模型选择范围和额外语义组件更多，比较不是等训练预算比较。
- 当前候选是离线复合检测器，包含白盒生成信号、MiniCheck 语义信号、TCN/树以及完整上下文 ModernBERT-large。它不能表述为单一纯白盒探针，也不能把重叠 4-BPE 窗口结果称为精确逐字符定位。
- GHOST 与 ReDeEP 的整答 F1 接近全正基线，单看其约 0.772 的 F1 会高估有效性；应同时看 AUROC、AP 和混淆矩阵。
- 上表是点估计差，没有对这些正式基线做配对置信区间。最终论文结论仍需在新建、开发过程未触碰的独立 holdout 上一次性验证。
- RAGognizer 当前只可作趋势参考。必须等待全 3,839 回答覆盖、身份/哈希核验和正式复算通过后，才能用于“候选未被任何正式基线超过”的最终判定。
