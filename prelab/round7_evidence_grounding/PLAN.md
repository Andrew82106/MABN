# 开源情报搜集中的事实项风险监测：扩大实验方案

日期：2026-09-10。状态：执行方案 v1.2。用户已授权按本方案完成全部方法适配、统一训练评测并汇报；不分批提交基线结果。各项完成情况以实际数据、日志及报告为准。

研究定位：把已有白盒检测方法适配到“搜索只覆盖部分主体，但模型仍需要汇总回答”的场景，比较哪些方法更能找出需要复查的内容。先做固定搜索材料下的监测实验，后续再接真实搜索系统。

本轮贡献落在场景和适配：构造同一问题下证据完整／局部缺失的对照，将不同方法统一到回答项监测，并检验有限复查次数能找到多少无依据内容。现有逻辑回归探针作为我们的当前方案一起比较，不预设它胜过已有方法；是否另加新的结构，由结果决定。

## 1. 本轮具体回答什么问题

模型拿到部分搜索材料后，可能把有依据的事实、凭已有知识答对的事实，以及编错的事实写在同一份回答中。本轮检测对象是其中“当前资料不支持或与资料矛盾的事实陈述”。事实是否正确另外记录。

重点检验：能否找到有风险的回答项，同时保留同一回答中的有依据内容。监测单位先固定为一个简短回答项；每项结束时输出一个风险分数。该分数表示复查优先级，未校准前不解释成真实幻觉概率。

## 2. 数据：200 组主实验，50 组外部检查

### 2.1 主实验：200 组新的双主体问答

继续采用 HotpotQA 的 comparison 问题，因为其问题、原始段落和支持句位置适合检查“删除了哪个主体的哪条证据”。主实验采用英文原文，模型与上一轮保持一致。

保留原题的两个主体；必要时把原来的比较属性改为原始资料明确支持的另一共同属性，例如由职业比较改为出生年份。保存原题、原始答案及 `derived_attribute_changed`，另按原始证据建立新参考答案，不能把旧题答案直接当作改写后的答案。搜索材料可采用原文中的完整句子片段；保存原始文章和句子索引，两个条件按相同规则取句，不编造背景文字。

每组问题拆成三个正常提问的回答项：主体 A 的某个属性、主体 B 的同一属性、二者的比较结论。例如分别询问两家机构的成立年份，再询问哪家更早成立。这里只是题型说明，正式数据必须有真实来源与可核对答案。

筛选条件：

1. 两个属性均有清楚依据，比较关系可以由完整资料推出。
2. 优先考虑机构、地区、公共人物、科技和产业相关材料；记录实际主题分布，数量不足时说明，不把普通百科题包装成真实情报业务数据。
3. 排除带错误前提、指代不清、日期相互冲突及无法稳定标注的问题；筛选发生在看到模型回答之前。
4. 题目覆盖不同数值、时间、地点及比较关系；使用完整事实句作答，减少上一轮只有少数 Yes 句、且恰好全有风险的偶然关联。
5. 先审核 20 组开发样例确定构造规则，再按固定候选顺序取得 200 组新数据。开发样例不进入正式留出测试；200 组是目标，实际合格规模须在取数后确认。

每组构造两个输入版本：

| 输入版本 | 四段搜索材料 | 用途 |
|---|---|---|
| 完整 | A、B 的有效资料，加两段背景资料 | 检查正常内容的误报以及有资料仍答错的情况 |
| 局部缺失 | 保留一方的有效资料，把另一方的关键资料换为不回答该属性的背景资料，仍共四段 | 模拟搜索只覆盖部分主体 |

在能找到合格自然替换材料的候选中，优先平衡缺失 A 或 B 的数量。缺失方在生成前按材料审核确定，不按模型回答调整；固定种子 20260910 用于数据划分及材料顺序。同题两个版本的资料位置对应，替换前后长度差不超过 20 token 或原段长度的 20%（取较大者）；替换资料优先保留该主体的一般背景，降低“名字消失了”这种简单线索。审核所有可见段落、标题及问题本身，确认没有残留的直接或可推导答案。不能把模型自己前面写出的断言当作搜索证据。

规模上限：200 组 × 2 个版本 = 400 份回答；每份三个回答项，最多 1,200 个监测项。自然拒答、未答、未决和解析失败会另行记录，主二分类数量可能更少。

### 2.2 外部检查：RAGognize 的 50 个独立问题

从 RAGognize 选择近期公共事件、机构、科技或产业事实问答，尽量保留同一问题的有证据／无关键证据版本。目标为 50 个独立问题、约 100 份新回答。按原始问题标识去重，不能把成对记录算作不同问题。

它提供问题、资料、参考回答和已有模型回答的错误范围；这些资源用于选题、核对和设计标注规则。我们的 Qwen 重新生成后，重新标注实际输出。

将原始提示中的严格依据资料、拒答提醒换成与主实验一致的正常提问方式。排除明显带错误前提或诱导确认的问法。当前日期下的现实知识不替代数据集时点的资料；记录材料版本和时间，防止把后来变化当成原回答错误。

这部分通常是单事实问答，用于检查换到近期材料后方法是否仍有效，不承担双主体局部缺失的主实验结论。保留官方测试来源作外部留出；检测器和阈值均沿用主实验，不用这 50 题重新调参。若合格配对不足，报告实际数量，不自动加入另一数据集凑数。

RAGTruth QA 暂保留为后续扩展来源，本轮不新增第三套正式数据，以控制标注量。

## 3. 模型怎样回答

- 被测模型：已有本地 Qwen2.5-7B-Instruct，NF4 4-bit，模型权重冻结。
- 生成方式：贪心解码，每个输入生成一次；输入上限 3,072 token，回答上限 256 token。完整材料超限的题目在生成前处理或排除，不事后截去关键证据。
- 系统提示：`You are a helpful assistant.`
- 主实验用户提示：`Please answer the following questions using these search results. Write one short sentence for each numbered item.` 后附三个问题及搜索材料。
- 外部检查沿用同样措辞，按其实际问题数列项。
- 不加入“资料不足可以不答”“不要编造”、缺失标记、标准答案或拒答示例。模型自行拒答时原样保留。
- 保存完整提示、资料顺序、实际生成 token、文本及运行配置。超长、缺项、多写和格式错误均记录，不反复生成直到得到理想输出。

本轮的回答生成、状态提取和模型核查均使用同一个本地 Qwen，不依赖额外付费大模型。标注由助手按证据初审，人工复核另见下节。

## 4. 怎样标注

先在生成前建立参考证据表，再在生成后核对模型实际写了什么。对每个实际事实断言保存原文范围、证据位置及以下判断：

| 对当前可见资料的判断 | 主风险标签 |
|---|---|
| 资料直接支持，或可以可靠推出 | 0 |
| 资料不能支持，也没有明确反驳 | 1，子类为无依据 |
| 与资料明确冲突 | 1，子类为矛盾 |
| 自然拒答、没有作答、明确假设或无法判清 | 单列，不伪装成正常事实 |

另记“符合完整参考／不符合完整参考／无法判清”。例如，B 的资料已被拿掉，模型说对了 B 的成立年份，也仍可能是无依据陈述；这与把年份写错分开统计。

一个回答项出现多个事实时，标注各事实的范围和依据，主监测项只要含一个风险断言就记为风险，同时报告混合项数量。本轮分数对应整个回答项，不能据此声称已定位到该句某个词。若后续要测逐词定位，需要另做逐词预测并使用范围标签评测。

标注时不查看任何检测器的分数，也不按完整／缺失条件直接贴标签。助手完成初标与证据说明；论文使用前，安排研究者独立复核全部主测试、外部检查标签和至少 20% 的训练／验证标签。没有实际人工复核时，报告须明确写“助手辅助标注”，不能称为人工金标准。

## 5. 怎样划分和训练

在生成前按原始问题、主体和来源文章建立分组；同题改写、共享关键事实、完整／缺失版本以及共享文章的样本不跨分区。需要合并的关联样本按组一起分配，实际题目数和独立组数分别记录。

目标划分：

| 分区 | 独立题组目标 | 回答份数 | 最多回答项 | 用途 |
|---|---:|---:|---:|---|
| 训练 | 120 | 240 | 720 | 拟合检测器 |
| 验证 | 40 | 80 | 240 | 选择参数、层和风险阈值 |
| 测试 | 40 | 80 | 240 | 最终统一比较 |

上一轮 30 题及本轮开发样例均视为已看过的开发材料，排除其与新测试材料的重叠。类别数量不足时如实报告或在冻结前按预定规则扩大候选池，不按测试结果移样本。

隐藏状态使用第 7、14、21、28 层；层号及最终归一化位置明确记录。读取回答项最后一个内容 token 已被模型读入后的状态，表示该项刚写完时的监测。因果重放只使用 Qwen 本次自己的生成 token，并复用上一轮的位置对齐检查；各项打分不利用后续回答。

训练设置先控制在小范围：

- 线性探针：训练集拟合 StandardScaler 和逻辑回归；候选层四个，L2 正则参数 C 为 0.01、0.1、1.0。
- 小神经网络：同样的单层隐藏状态，分类头为 256→128→64→1，中间 ReLU 与 dropout 0.1；AdamW，学习率 0.0001 或 0.0003，weight decay 0.01，batch 32，最多 100 个 epoch，验证损失连续 10 个 epoch 不改善则停止。类别权重仅按训练集计算。
- 该神经网络是 HalluRAG 风格的“隐藏状态版适配”，未包含其全部 FFN 信号时，不称为原论文完整复现。
- 随机网络采用三个预定种子；报告均值与波动，不按测试集挑最好种子。所有标准化、类别权重与模型拟合仅使用训练集。

参数及阈值选择依据验证集风险类 F1；并列时依次取精确率较高、复杂度较低者。阈值确定后冻结。测试集只用于最终报告。

## 6. 比较哪些方法，以及怎样公平比较

| 顺序 | 方法 | 本轮使用方式 |
|---|---|---|
| 统一比较 | 现有逻辑回归探针 | 作为当前方法基准 |
| 统一比较 | HalluRAG 风格小神经网络 | 比较换分类器是否改善同一种内部状态的利用 |
| 统一比较 | Lookback Lens | 提取来源资料与已生成内容的注意力比例，按回答项汇总并拟合线性分类器 |
| 统一比较 | token 负对数概率、预测熵 | 保留上一轮已较强的简单对照 |
| 统一比较 | 长度、位置、词语重合和主体匹配的表面特征分类器 | 检查是否只学会格式或证据删除留下的浅层线索 |
| 统一比较 | ReDeEP | 适配外部资料利用与参数知识相关信号；参数只在验证集选择 |
| 统一比较 | LUMINA | 保持原回答，替换资料并比较内部预测；不训练检测器，判定阈值仍由验证集确定 |
| 参考 | 同一 Qwen 直接核查、全部报风险、全部报正常 | 提供实际核查成本和类别比例参照 |

另保留同一 Qwen 的自评置信度：单独询问它对原回答项的把握，再换成风险方向。它与直接核查分开报告，不把模型自评当成标签。主要方法均以同一验证集风险 F1 选择阈值；ReDeEP 的头、层与权重也只依训练／验证选择，LUMINA 的公式参数固定。

统一规则：

1. 所有方法检测同一批 Qwen 回答，使用相同的预定回答项范围、标签和划分；每一项都打分，不先挑可疑句子。
2. token 级连续分数默认在该回答项范围内取平均；注意力比例等特征先按项汇总。更换聚合方法只能在开发／验证阶段，需明确记录为适配。
3. 同模型直接核查采用独立请求，不影响原始生成，不用于制造标签。LUMINA 的替换资料取不含答案的独立资料池，并固定选择规则。
4. ReDeEP、LUMINA 和注意力提取先做少量工程样例，按层和位置分块处理显存。若公式或信号需近似，另行标明，不能把近似版本称为原版。
5. 全部方法并行适配、按显存条件顺序运行，全部完成后统一打开正式测试结果。运行故障继续修复；不得以只完成一部分方法替代本轮完整对照，不使用论文中不同模型、不同粒度的分数填表。
6. 分开记录原始生成、特征提取、检测器训练和单项打分的耗时与显存；离线重放耗时如实计入，不当成已实现在线零成本。

## 7. 测什么指标

主指标为“回答项风险类 F1”：

- TP：有风险且检出；FP：有依据却报风险；FN：有风险却漏掉；TN：有依据且未报风险。
- Precision = TP / (TP + FP)。Recall = TP / (TP + FN)。F1 = 2TP / (2TP + FP + FN)。

同时报告原始四项计数、类别比例、精确率、召回率、误报率和 PR-AUC。没有风险项或分母为零时注明不可估计。随机网络报告三个种子结果，按独立题组进行配对 bootstrap 估计不确定范围。

必须分别查看：

1. 完整资料与局部缺失条件的结果。
2. 无依据但符合完整参考、无依据且错误、与资料矛盾三类的检出率。
3. 同一回答中，风险项能否排在有依据项之前。
4. 只复查最高风险的 20% 回答项，可以找到多少风险；相同预算下各方法谁更有效。实际复查指标按全部预定回答项计算预算和排序，不能先利用标注排除拒答或未决项；报告选中项中的已确认风险、正常事实、拒答和未决数量。仅在已判清事实项内排序的结果作为额外分析，明确它使用了标注过滤，不冒充实际复查效果。
5. 未受删除影响的主体是否也被大量误报，用来区分“发现整份资料不完整”与“找出对应回答项”。
6. 拒答、缺项、标注未决、多事实混合和解析失败数量，以及检测覆盖率。失败样本不能无声删除。
7. RAGognize 外部检查单独报表，与主实验不合并成一个 F1。

目标是新留出测试中的风险 F1 超过 0.70，并观察相对预测熵和正式基线的收益与成本。0.70 是实验目标，最终结果按冻结测试如实汇报。

## 8. 执行顺序与交付

1. 审核 20 组开发样例，检查来源、证据删改、正常提问与标签规则。
2. 建立主实验 200 组及外部检查 50 组，保存来源版本、原始标识和分组清单，冻结构造与划分规则。
3. Qwen 自行生成回答，初标和复核实际陈述；保存原文范围和证据说明。
4. 提取内部信号，完成包括 ReDeEP 与 LUMINA 在内的全部方法适配；用验证集选参数和阈值。
5. 一次性统一测试，给出效果、误报漏报例子、成本和外部检查结果。

本轮文件放在 `prelab/round7_evidence_grounding/`：`data/` 保存原始来源、输入、回答与标注；`src/` 保存构造、提取、训练和评测代码；`configs/` 保存冻结设置；`results/` 保存对照表和案例报告。模型复用 `prelab/models/`，环境复用 `prelab/.venv/`。本设计稿不会改变上一轮数据、标签或结果。

完成这轮后，根据结果扩展到 3–5 主体与真正的搜索结果；再研究高风险事实点的追问／补搜。检测效果先单独测清，后续的补充核查另设对照。
