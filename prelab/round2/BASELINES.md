# 基线及本地实现范围

本轮要回答：整段标签能否学出局部错误信号；如果不能，错误位置标签能否使同一批表征有效。所有权重只用训练集拟合，验证集选层和训练步，测试集最后评估。

| 方法 | 训练时需要什么标签 | 本轮实现 | 不能声称什么 |
|---|---|---|---|
| HaMI ori，NeurIPS 2025 | 整段有错/无错 | 直接导入官方两层网络和原 MIL 损失，最高约 10% token 分数汇总；比较生成前后状态 | Qwen、量化、数据和训练预算均不同；未复现论文完整模型、完整数值或语义一致性增强 |
| Lookback-Lens，EMNLP 2024 | 局部片段有错/无错 | 同一注意力比值公式；线性分类器，单独使用局部标注 | 换了模型、提示边界、token 标注和划分；属于本地适配，不是原数据全流程复现 |
| 最后状态／平均状态线性探针 | 整段标签 | 标准化加逻辑回归，层和正则只用验证集选择 | 将整段分类器逐 token 应用只是朴素对照，不保证能够定位 |
| 惊讶度、回答长度、TF-IDF | 前者无需训练；其余整段标签 | 排查只是低概率、长度或用词信号的可能 | 低概率并不等于事实错误 |
| 打乱标签 | 随机整段标签 | 保留特征，打乱训练及验证标签 | 只作流程和偶然拟合对照 |
| 直接监督的内部状态线性探针 | 错误位置标签 | 与弱监督使用同一批状态 | 属于监督信息更多的诊断对照，不能混作公平的弱监督基线 |
| 少量位置标注对照 | 部分训练回答的位置标签；验证只用整段标签 | 注意力线性探针，比较 24／60／120／240 条局部标注训练回答，三种子 | 额外使用了位置监督；不能声称是零位置标注的方法 |
| 位置监督 MLP、增加正常回答最大风险惩罚的 MLP | 训练位置标签；验证整段标签及位置标签 | 相同注意力特征、网络与三种子，损失系数固定 0／0.5；验证低误报下检出率选步数，局部指标破同分 | 原测试结果之后增加的探索对照；另冻结 110 条来源无重叠新闻复核。不是论文原版方法，也未证明新增惩罚稳定改善报警 |

探索项：有／无证据条件下，同一段已生成文字的概率与状态变化，以及注意力特征。它们分别接入整段监督的网络；不把这个组合直接宣称为新算法，也不把弱监督注意力网络称为原版 Lookback-Lens。

另在三事实 RAG 上探索：从输出格式识别三个答案片段，将各片段的特征平均后作为三个候选事实，用整段标签训练最高风险事实的汇总分数。片段边界不读取标准答案。这是在片段间寻找错误，不声称能进一步指出同一个错误事实内部究竟哪一个 token 错了；不预设此方法优于 token 级基线。

## 对齐细节

- HaMI 官方生成特征对应预测 token t 之前的状态 h(t−1)。本轮同时缓存 h(t−1) 与读取 token t 后的 h(t)，保证标注与时刻可核验。前者可用于生成前风险估计，后者用于已经输出内容的监测。
- Lookback-Lens 官方代码将提示末尾的回答分隔符归入生成侧；本轮将完整聊天提示归入上下文侧。公式相同，边界适配必须披露。第一 token 尚无回答前缀，比值设为 1。
- “只用整段标签”的训练分支不读取局部标注。局部标注仅用于最终定位评估或显式开启的监督诊断。
- NLL 和有／无证据的 token 概率对照需要知道已经选出的 token，属于输出后的监测特征；不能因为同时读取 h(t−1) 就称其为生成前预警。
- RAG 问答定位仅评估答案字符串内部的 token，忽略 JSON 标点，以及拒答、歧义内容。自动答案匹配是候选标签，需要抽查。
- 指标分别报告整段分类与同一回答内部的定位。风险分数尚未校准，不能称为真实幻觉概率。

## 补充文献核对（未列入已完成实验）

- [ICR Probe，ACL 2025 主会长文](https://aclanthology.org/2025.acl-long.880/)：考察各层模块对状态更新的贡献。本轮只取四个层的状态，不能冒称已经实现 ICR。
- [Simple Factuality Probes，Findings of EMNLP 2025](https://aclanthology.org/2025.findings-emnlp.880/)：研究长文本中的轻量内部状态探针。这是 Findings 论文；本轮的通用线性对照不等于完整复现它。
- [Max-pooling Network Revisited，2026 年预印本](https://arxiv.org/abs/2605.08863)：重新分析 HaMI，并用内部特征最大汇总构造轻量整段检测器。当前核对到的是 arXiv 版本，未将其标成已录用顶会论文；也不能把“最大汇总加分类器”本身作为我们的新意。

这些文献说明需要明确区分：整段分类有效、局部排序有效，以及能够监测现实情报事实错误，是三个不同的验证目标。
