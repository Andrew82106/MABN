# Round 17：扩充后重训

固定上轮保留的4词元窗口Lookback线性探针（C=0.01），比较旧120道训练题与新旧421道训练题。主比较是同一新测试集上的扩充前后差异。负对数概率单信号和Lookback加负对数概率的线性融合各做相同对照，共六次拟合；不改成新的网络，不搜索测试参数。

回放R16已有Qwen回答的精确词元，提取28层×28头的Lookback比值与所选词元NLL。大模型参数冻结，只训练小探针。特征提取不读标签，旧特征不重算。新数据、旧数据及旧实验均保留原样，R17保存新的特征、模型、预测及报告。

两种训练规模使用相同的总损失权重3854，保持平均损失与正则约束的比例一致；标准化、类别权重只在各自训练数据计算。训练样本按组、条件、回答平衡。R16验证49题用于分别确定窗口和回答阈值；冻结模型与阈值后，R16测试50题（49组）只作最终评测。旧验证和测试数据不参加拟合或调参。

先从实际回答构造全部4原始BPE词元窗口，步长1、短回答允许短窗口，完全不依风险金标选择窗口。回答风险为其全部候选窗口分数的最大值，包括安全拒答。金标只控制训练/评测资格：安全拒答在回答级为0，未决排除；二者均不强行生成全零定位标签。

主报回答级F1、4词元窗口F1、精确率和召回率，另列窗口并集合并高亮后的词元F1及标记比例。分别报告训练内、验证和测试成绩，不把三种粒度混为一谈。按测试事件组配对重采样比较扩充前后差异；不承诺达到某个F1，不把训练差距变小单独解释为解决过拟合。

顺序：特征回放核验与提取 → 固定六次拟合和验证阈值 → 冻结 → 新测试评测 → 独立审计和报告。完整规则见protocol.json。
