# R18：检查输入压缩与分类能力

目标是区分几种解释：已有逐词元信号是否被均值丢掉；线性分类器是否过于简单；增加资料对齐摘要或上下文内部激活是否有帮助。不先认定“输入不足”，不以单个失败方案证明输入与标签无关。

只使用R16的train301题、278个事件组，完整/部分资料的602份固定回答不重新生成。原validation/test不用于本轮选择或评测。五折以事件组划分，每轮一折评测、下一折校准，其余三折拟合；同组的多题、两条件及所有重叠窗口始终在一起。

固定8组方法：均值LB+NLL逻辑回归；保留4位置的同信号逻辑回归；同维度逐窗固定乱序控制；均值信号小MLP（3种固定随机种子等权平均，不挑最好）；分别加入R10文本8维、白盒对齐16维、两者24维；另加入最终层隐藏状态在拟合组内无监督压缩的32维。MLP固定80轮，不用校准折早停。模型、阈值等规则在protocol.json固定，报告全部配置。

R10资料对齐摘要曾在较小数据中尝试，并非新的已证实方法；它用静态embedding和注意力摘要，不能当成直接判断资料是否支持回答。hidden分支是更丰富内部信息的有界探索，PCA32仍会压缩信息。全部分支用相同原始4BPE窗口及金标，新增特征提取不读标签。

所有预处理、PCA、类别权重只由当轮拟合组计算。各方案总损失权重固定3854，LR C=0.01；同数值正则不表示不同网络容量完全相等。窗口和回答阈值仅从该轮校准组选择。报告外层留出预测、分折排序、风险位置命中和标记量，不能只挑F1最高者当成确认结论。

旧数据、R17模型/阈值/成绩均不修改。若某分支有效，只能说对应表示或训练形式在本次探索中有帮助；若均无效，仍不能断言原始模型内部没有可用信息。
