# Round 15：固定小窗口，检查过拟合

定位单位固定为 4 个原始 BPE 词元，步长 1。窗口中有旧标注的风险词元即为正例；特征为窗口内所有词元的 784 维 Lookback 均值。沿用 Round 14 的标签、样本、权重定义和五组 72 题训练 / 24 题校准 / 24 题留出划分。

本轮在拟合前固定以下比较，全部报告，不根据留出结果追加参数：

1. 原探针：直接复用 Round 14 的 C=0.01 线性探针。
2. 更强的权重约束：C=0.003、0.001，其他不变。
3. 减少输入：只用训练题计算每个头与风险标签的加权相关程度，保留绝对相关最高的 64 或 128 个头，再以 C=0.01 训练。这个方法减少维数，并不保证留下的头彼此不相关。
4. 平均多个探针：训练题中按题组随机无放回取 54/72 题，重复 24 次；分别使用 C=0.01、0.003。所有成员的概率等权平均，然后在校准题上为平均分数选择一个阈值。两种 C 使用相同子集。每个成员的标准化、类别权重都只来自该成员训练题。

各变体及集成成员的损失权重总量固定为本折完整训练集的单词元样本数，避免单纯改变样本数量导致约束强度不可比。特征筛选的关联权重使用未做类别重加权的训练基础权重；标准化后计算 Pearson 关联，按绝对值降序、头编号升序打破平局。

比较留出窗口 F1、精确率、召回率、AP、AUROC，同时报告正常回答误报、文本标记比例和原风险区域覆盖。报告各折训练 / 校准 / 留出效果；集成在完整训练题上的分数包含部分未参与该成员训练的题，因此训练差距缩小本身不能证明解决过拟合。另报每成员在实际参与训练的题和共同留出题上的平均表现。

按题组配对重采样 2,000 次，给出相对旧探针的 F1 差值范围；该范围不包含重新拟合的不确定性，也未校正多方案比较。本轮沿用已研究过的训练源，结论仅属探索。原 validation/test 标签不进入本轮。旧实验文件与标签不修改；不将超过 0.7 当成调参停止规则。
