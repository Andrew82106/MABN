# Round11：NLL 联合探针快速对照

用户授权马上比较单独 token log probability、Lookback 和二者联合。使用 `token_nll = -log p`，与 log probability 仅差符号，不增加额外信息。

固定三组输入：NLL 1维、Lookback 784维、Lookback＋NLL 785维。各自分别训练回答项均值 LR 和原生词元 LR，共6个头。不加熵、窗口、MLP或更多候选。

全部复用 Round10 的 train120组、validation40组、test60组，以及原始回答、精确标签、正常拒答审查、词元坐标与缓存。只读旧目录，在本目录写新结果，不重新跑大模型。回答头平均项内全部原始 BPE 的 NLL；词元头直接使用该词元的 NLL。NLL 来自预测该词元的前一个位置 logits，不读未来回答。

训练、权重、标准化、C={0.1,1}、liblinear L2 max_iter=2000、seed=20260912 与 Round10 一致。各头只按各自验证 F1 选 C/阈值；并列按验证 precision、更高阈值，C并列取小。重新训练的 LB 必须逐条复现 Round10 原基线，保证对照一致。主比较固定为 lb_nll−lb。

本轮复用的 test 已在 Round10 被查看，属于**探索性复测**，不是新的独立测试，也不能宣称 SOTA。拟合仍不读取该 test 标签来选参。方法与阈值冻结后仅运行一次探索性评分；阳性、阴性结果均报告，不回调测试阈值。

主回答分母115=34风险+66有据+15审查拒答，5未决排除。原生词元分母1683，其中164风险；拒答和未决不补零金标。独立重建标签、复核计数、核对基线一致性；对60组按同一抽样做2000次配对F1区间，包含两条件及所有词元。区间不抵消测试已暴露造成的选择影响。
